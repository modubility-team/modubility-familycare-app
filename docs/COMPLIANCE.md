# 공모전·Pleos 기준 반영 현황

확인일: 2026-10-29. 차량·휴대폰 0.13.0 로컬 시연 프로토타입의 상태이며 공모전 접수 완료·안전 인증·최종 앱 완성을 의미하지 않습니다.

## 코드에 반영한 사항

| 기준 | 현재 반영 |
| --- | --- |
| 주행 제한 | CarUxRestrictionsManager 현재 값과 변경 콜백 연동. requiresOptimization 또는 활성 플래그가 있으면 상세 UI 전체 숨김 |
| 주행 알림 | Pleos TTS 3.3.1 ON_DEVICE 한국어 합성·재생 완료와 D단 UX 제한 중 요청 안내 검증. TTS_SERVICE 선언, 서버 인증키·마이크 권한 없음. 실패 시 자체 알림음. NOTIFICATION 포커스·거부/상실 처리·자원 정리·반복 억제. 출시 권한 승인, 실제 전화/긴급 경고·실차 음향 검증은 남음. DRIVING-AUDIO.txt 참조 |
| 신호를 알 수 없을 때 | 연결 전·실패·서비스 끊김은 제한 화면 유지. 정차로 추측하지 않음 |
| 문 열림과 주행 | 주행 제한 중 문이 열려도 하차/소지품 목록을 표시하지 않음 |
| 텍스트 제한 | 플랫폼의 문자열 제한 플래그와 최대 길이 적용. 제한 화면에 스크롤·영상·키보드·설정·애니메이션 없음 |
| 화면 크기 | 가로 고정 제거, 창 크기와 종횡비에 따른 배치. 정차 중 화면 전환 버튼, Driving view는 시스템 영역 유지 |
| 생명주기 | 일반 화면은 연결 정리. 사용자가 시작한 이동·상태 확인·동승자 연결은 알림을 갖춘 포그라운드 서비스로 유지. 지도 목적지 요청도 내비 응답/25초 제한까지 일시 유지 후 종료. 강제 종료/전원 OFF 후 자동 복구를 주장하지 않음 |
| 정보 수집 | 전경 GPS로 길안내. 사용자가 이동 기록을 켜면 차량에 최근 20회 기록, 가족 공유도 별도 선택. 공유 시 현재 경로·탑승 유형/아이 나이대는 소유자와 가족에만 전달. 선택 사진 EXIF 위치·시간과 사진은 공유 후 서버 RAM에 최대 12장. 연락처·마이크 수집 없음. 선택 연결한 IP 카메라 JPEG는 소유자·가족에게 같은 Wi-Fi로 전달하며 디스크에 저장하지 않음. 카메라 설정·로그인 정보는 세션 RAM에만 보관. 차량 영상은 P단 정차 중에만 표시. 지도 화면 범위·SDK 요청은 TMAP, 선택한 검색·경로 제공자에는 검색어/필요 좌표 전송. TMAP 키 원본은 PC에 보관하고, 명시적 동의를 받은 차량·소유자·가족 연결에 SDK 인증용으로 실행 중 전달 (현재 HTTP 시연 연결) |
| 저장·전송 | 개발 APK의 신뢰 LAN 시연 연결은 HTTP. 외부 TMAP·지도 API는 HTTPS. 현재 LAN 서버는 인증된 역할별 2시간 세션이며 링크를 가진 기기만 해당 역할 접근. 종료/만료 시 RAM 상태 삭제. 개인 GPS 기록/사진 보관과 공급자 검색 응답은 분리. 검색 결과 캐시 없음. 상용 원격 운영에는 TLS와 별도 계정·권한 서버가 필요 |
| 권한 | 차량 상태 읽기·내비 경로·속도(런타임 허용)·인터넷·알림/포그라운드 서비스 권한. 공조 목표 온도만 CONTROL_CAR_CLIMATE로 승인/정차/지원 범위 확인 후 설정하고 값을 재확인. 문/창문/시동 제어 및 하드웨어 직접 접근 없음. UX는 공개 AAOS API 사용 |
| 제출 준비 | apk 폴더·파일명 예외·release 서명 설정·서명 누락 방지 task 추가. 실제 서명 키/제출 APK는 아직 없음 |

전체 상세 화면을 제한하는 것은 이 프로토타입의 보수적인 설계 선택입니다. 속도만으로 제한을 판단하거나 OS의 주행 규제를 우회하지 않습니다. DO 선언은 플랫폼 심사를 대신하지 않습니다.

현재 에뮬레이터에서 세로 화면은 좌우 여백을 포함한 형태로 관찰했습니다. 가로·세로 앱 내부 배치와 복귀 동작은 시험했지만, 실제 두 앱 나란히 배치와 차량별 창 관리 전환 전체를 검증한 것은 아닙니다.

## 기획과 현재 구현을 구분

- 지도/경로: TMAP Vector Map SDK 3.7 + TMAP POI/자동차 경로 REST. 공개 검색/OSRM은 사용자가 선택. TMAP-MAP-0121.txt에 데이터 흐름과 검증 범위를 기록. Pleos 기본 내비의 지도 공급자 문제는 우리 앱과 별개.
- 현재 구현: 프로필·추천·주행 변화 집계·휴식·뒷좌석 확인·반려동물 타이머·QR 요청/투표·내비 전달·이동 기록. 구체적인 검증 범위는 CORE-TEST-RESULTS.txt 참조.
- 로컬 시연 흐름 구현 완료. 외부 인터넷 운영·실차는 별도 설계 및 검증 대상.
- 검증 필요: 실차 주행·전원 OFF·장시간 부하·통신 장애. 실제 OEM 소유권 인증, 원격 시동·문 잠금, 클라우드 푸시/SMS는 미구현. 휴대폰 알림은 사용자가 시작한 로컬 연결 서비스에 의존.
- 공조 보조는 승인한 온도·시간·정차·전원·배터리 조건 안에서만 동작. 실내 카메라는 0.13.0에서 선택형 IP 카메라 연동을 추가했으며 실물 폰 입력 검증은 대기. 짖음·이상행동 자동 감지는 보류. 외부 API·네트워크는 설명회 49:00에서 허용했으나 외부 카메라 현장 반입 허용은 명시적으로 확인되지 않아 주최 측 문의 필요. 융합 위치 SDK는 지원/수신 진단만 사용하고, 신뢰도 단위를 거리 정확도로 환산하지 않으며 Android GPS를 길안내 기준으로 유지.
- 반려동물 모드는 방치해도 안전함을 보장하는 기능으로 소개하지 않음. 시스템 오류·데이터 미수신 시 보호자가 직접 확인해야 하는 상태로 설계.
- 사용자 정의 임계값과 실제 검증 전의 점수·생체/안전 판단을 확정 사실처럼 제시하지 않음.

- [ ] 공식 접수양식 작성. 별도 기획 PDF만으로 접수 완료라고 간주하지 않음
- [ ] 팀원 전원의 개별 동의·날짜·서명, 대표 이메일과 팀원 CC 준비
- [x] 구현/제약을 구분한 본문 초안 작성. 시장 수치·사업성 실증과 최종 양식 검토는 남음
- [ ] 팀 서명 키 보관/백업, 서명된 release APK 설치·구동 검증, 정확한 파일명과 경로
- [ ] 비공개 저장소의 공지된 심사용 계정 접근 확인. 개인 private collaborator는 쓰기 권한도 가질 수 있음
- [ ] 외부 코드·이미지·폰트·SDK 이용 조건 확인. 공식 샘플은 우리 창작 코드로 표시하지 않음
- [x] 실제 브라우저 요청과 차량의 타이머·기록 시연 녹화. 최종 제출 편집/검토는 별도
- [ ] CPU/RAM 장시간·주행·창 전환·재연결 테스트. 현재 단기 측정만으로 전체 성능 준수 주장 금지
- [ ] 제출 전 최신 공지와 마감 재확인. 수정 제출은 전체 자료·서명 동의서·팀원 CC를 다시 준비

서명, 팀원 초대, 심사 계정 초대와 이메일 접수는 자동으로 수행하지 않았습니다. 팀 정보와 본인의 동의·서명은 실제 참가자가 결정해야 합니다.

## 0.2.0 실행 유지와 알림

사용자가 정차 중 시작한 작업에만 `specialUse` 포그라운드 서비스를 사용합니다. Android 실행 검증과 실제 앱마켓의 서비스 유형·DO 심사는 별개이며 공급자 심사를 통과했다고 주장하지 않습니다. 차 시동이 꺼져도 작동하거나 SMS/전화가 발송된다고 표시하지 않습니다. 온도 30°C·배터리 20%와 주행 임계값은 시연용 직접 확인 기준입니다.
