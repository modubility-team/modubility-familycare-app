차량과 휴대폰 제어 연결 0.16.0
2026년 11월 1일

이번 변경
휴대폰의 차량 관리 화면에 공식 Pleos Vehicle SDK 제어를 연결했다. 서버에 요청을 보냈다는 것만으로 성공 처리하지 않고, 차량이 보고한 설정값이 요청값과 일치한 뒤 완료를 표시한다. 현재 에뮬레이터에서는 24개 추가 제어 항목의 변경과 원상 복원을 확인했다.

사용 순서
1. 휴대폰에서 기존 앱 두 개를 새 0.16.0 APK로 업데이트한다. 기존 앱을 삭제하지 않고 업데이트한다.
   - 02_FamilyCare-내차관리-debug.apk
   - 03_FamilyCare-케어-debug.apk
   차량용 01번 APK는 휴대폰에 설치하지 않는다.
2. 노트북과 휴대폰을 같은 Wi-Fi에 연결한다.
3. 노트북의 시연 보조 페이지 http://127.0.0.1:8770/ 에서 소유자 QR로 '내 차' 앱을 연결한다. 동승자는 가족 QR로 Family Care 앱을 연결한다. 서버 업데이트로 이전 연결은 만료될 수 있으므로 새 QR을 사용한다.
4. 시연 보조 페이지에서 정차한다. 차량 P단, 속도 0, 앱의 차량 응답 정상을 확인한다.
5. '내 차 → 관리'에서 공조 전원과 설정 온도를 적용한다. 차량에서 실제 읽은 현재 설정이 바뀌는지 확인한다.
6. 같은 관리 화면의 '차량 조절'에서 공조 / 문과 창문 / 시트와 열선을 선택한다. 항목을 조절하고 실행을 확인한다. '차량 전달 대기 → 차량 응답 확인 중 → 차량 응답으로 확인' 순서로 처리된다.
7. Family Care는 '요청 → 차량 조절 요청'에서 지원 항목을 요청한다. 차량 내비의 가족 요청 목록에서 운전자가 정차 후 '승인하고 설정 적용'을 누르면 바뀐다. 승인 전에는 실행되지 않는다.

확인한 추가 제어 24항목
공조 8: A/C, 자동 공조, 실내 순환, 좌우 독립 온도, 풍량, 최대 성에 제거, 앞유리 열선, 뒷유리 열선.
문과 창문 9: 전체 문 잠금, 보닛 잠금, 전체 창문 잠금, 뒷좌석 좌우 창문 잠금, 네 좌석 창문 개방 위치.
시트와 열선 7: 네 좌석 시트 온열 단계(앞좌석은 냉방 범위 포함), 앞좌석 좌우 통풍, 핸들 열선.
기존 공조 전원 ON/OFF와 설정 온도 조절도 함께 검증했다.
지원 항목과 범위는 차량이 보고하는 capabilities에 따라 달라진다. 읽기 전용이거나 최신 상태를 확인할 수 없는 항목은 조작할 수 없다.

조작이 안 되는 경우
- 소유자 앱에서 주행 중이면 P단 정차 후 조절할 수 있다는 이유를 표시한다. 정차 조건을 우회하지 않는다.
- 가족 요청은 운전자의 승인이 필요하다. 소유자 QR과 가족 QR의 역할이 다르다.
- 연결됨 표시만으로 충분하지 않다. 차량 최신 응답, 해당 기능의 제어 지원, 유효한 설정값이 필요하다.
- 처리 결과 미확인 또는 시간 초과는 성공으로 표시하지 않는다. 실제 상태 확인 후 새로 요청한다.
- 공조 설정 온도와 현재 실내 온도는 다른 값이다. 설정 변경이 실제 실내 온도의 즉시 변화를 뜻하지 않는다.

원격 시동의 범위
현재 연결한 Pleos Connect Vehicle SDK 2.3.2의 공개 API에서 원격 시동 명령은 확인되지 않았다. 이 버전은 원격 시동을 구현한 것으로 표시하지 않는다. 제조사 계정·차량 소유권 인증이 연결된 공식 원격제어 서비스는 별도 연동이 필요하다. 에뮬레이터 시동 값을 외부 도구로 바꾸고 이를 실제 앱의 원격 시동처럼 성공 처리하지 않았다. 가속·제동·조향·기어를 휴대폰으로 원격 운전하는 기능도 구현 범위가 아니다.
공식 참고: https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/Vehicle/intro

검증 결과
- 차량 및 휴대폰 앱 3종 빌드 통과.
- 기존 Android 단위 테스트 59개 통과.
- 서버 테스트 66개 통과. 제어 범위·잘못된 값·권한 상승·미지원 기능·주행 중 소유자 제어 거부 포함.
- Pleos 에뮬레이터의 24개 추가 항목 변경 24/24, 원상 복원 24/24 확인.
- 소유자 요청 → 서버 → 실제 SDK 변경 → 완료 응답 확인.
- 동승자 요청 승인 전 값 유지, 승인 후 SDK 변경 확인.
- 공조 전원 꺼짐/켜짐, 온도 조절, 승인 기반 공조 보조 기존 통합 시험 통과.
- 휴대폰용 앱을 에뮬레이터에서 실행해 실제 A/C 버튼 클릭 → 차량 변경 → 앱의 확인 완료 표시 → 원래 값 복원까지 통과.
- 사용자의 물리적인 휴대폰은 연결되어 있지 않아 직접 설치·시험하지 않았다. 새 APK 설치와 새 QR 연결이 필요하다.
