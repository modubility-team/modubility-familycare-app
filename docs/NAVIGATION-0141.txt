차량 내비게이션 UI 0.14.1
2026-11-01

주행을 시작하면 상단·중앙·하단으로 나뉜 내비 전용 화면으로 전환됩니다.

상단 전체: 큰 회전 화살표, 회전까지 거리, 도로명, 이어지는 회전
왼쪽: 큰 현재 속도와 GPS 상태
중앙 지도: 진행 방향 추적, 굵은 경로, 큰 차량 화살표
지도 아래: 이번 회전 / 다음 회전 순서
하단 전체: 목적지, 도착 예정 시각, 남은 시간, 남은 거리, 경로 진행률
오른쪽 아래: 기존 Family Care 주행 중 알림

P단에서 안내 중일 때 오른쪽의 내 위치 / 경로 전체 / Family Care / 안내 종료를 사용할 수 있습니다.
정차 후 음성 안내를 누르면 기존 음성 설정을 바꿀 수 있습니다.

참고 사진의 일반적인 내비 정보 배치를 참고했고, 새 안내 화면은 직접 작성한 구성·아이콘입니다.
이번 회전 / 다음 회전은 실제 경로 순서이며 차로 안내가 아닙니다.
실제 데이터가 없는 제한속도·단속카메라·신호등 시간을 표시하지 않습니다.
지도는 TMAP의 진행 방향 기준 2D 지도입니다.

설치 대상은 차량용 앱입니다. 휴대폰 앱 재설치는 필요하지 않습니다.
시연 보조 페이지를 다시 열거나 새로고침한 다음 GPS 주행 시작 / 재개를 누릅니다.
시연 보조 페이지: http://127.0.0.1:8770/

검증
- 차량 APK 및 휴대폰 두 앱 컴파일
- 주행 중 상단 안내의 전체 폭, 지도와 상·하단 정보의 겹침 검사
- 실제 TMAP 경로와 에뮬레이터 GPS를 통한 안내, GPS 단절/회복, 재탐색, 도착 검사
  결과 로그: dist/demo/navigation-cockpit-e2e.log
