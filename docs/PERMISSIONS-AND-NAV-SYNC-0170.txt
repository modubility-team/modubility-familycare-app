Family Care 0.17.0 설치·업데이트 및 새 기능 확인
작성일: 2026-11-01

1. 휴대폰 업데이트
02_FamilyCare-내차관리-debug.apk: 소유자/운전자용 내 차 관리
03_FamilyCare-케어-debug.apk: 동승자용 Family Care
필요한 APK를 휴대폰으로 옮겨 실행하고 [업데이트]를 누르세요.
기존 앱을 먼저 삭제할 필요는 없습니다. 삭제하면 휴대폰에 저장한 정보가 지워질 수 있습니다.
차량용 APK는 휴대폰에 설치하지 않습니다. PC의 차량 에뮬레이터에는 이번 버전을 적용했습니다.
이 ZIP은 PC용 프로젝트/서버가 아니라 휴대폰용 설치 파일입니다.

2. 동승자 조절 권한
① PC 시연 보조 화면 http://127.0.0.1:8770/ 에서 가족 QR 또는 가족 연결 링크 확인
② 동승자 휴대폰의 Family Care 앱에서 연결
③ 처음 연결하면 [권한] 화면이 열립니다. 표시할 이름을 입력하고 필요한 항목만 선택
④ [선택한 권한 요청] 누르기
⑤ 차량을 P단 정차한 뒤 내비 [Family Care] → [요청] → 요청한 항목 확인 → [선택한 권한 승인]
⑥ 휴대폰 [요청]에서 승인받은 온도·에어컨·좌석 등의 기능을 바로 조절
   공조 전원/온도와 에어컨 A/C는 서로 다른 권한입니다. 둘 다 사용하려면 둘 다 선택하세요.
   휴식 요청·음악 줄이기 같은 한마디는 운전자에게 알림을 보내는 기능입니다.
   문·창문, 목적지·경유지 변경, 가족 구성·확인 타이머·공조 보조는 P단 정차 조건을 유지합니다.
   지원하지 않는 차량 기능은 승인해도 생기지 않습니다. 원격 시동 API는 현재 SDK에 없습니다.

현재 Pleos 에뮬레이터는 앱에 시동 상태를 제공하지 않습니다.
사용자가 선택한 방식대로 현재 환경에서는 ‘이번 차량 연결이 종료될 때까지’ 승인 범위를 유지합니다.
휴대폰 [연결 해제], 차량 [모든 동승자 연결 종료], 운전자 [조절 권한 회수] 때 해제됩니다.
차량 서버와 연결이 오래 끊겨도 권한을 해제하고 다시 승인을 받습니다.
시동 신호를 지원하는 차량에서는 시동이 꺼지면 자동 해제하며, 시동을 다시 켜도 예전 승인은 되살아나지 않습니다.
시동 지원 여부를 확인할 수 없는 상태에서는 권한 조절을 허용하지 않습니다.
권한을 바꿔 재승인하면 새 목록으로 교체합니다. 휴대폰마다 별도의 권한을 사용합니다.

3. 내비 목적지 → 시연 보조 프로그램
① 차량 내비에서 원하는 목적지를 검색/선택
② 경로 추천 결과 확인
③ [안내 시작] 누르기
④ 보조 프로그램의 목적지 이름·좌표·표시 점·경로가 자동으로 갱신됨
⑤ 보조 프로그램에서 [GPS 주행 시작] 누르면 그 경로로 자동 주행
경로 추천만 확인할 때는 보조 프로그램의 선택을 바꾸지 않습니다.
GPS 주행은 [GPS 주행 시작]을 눌렀을 때 시작합니다.
화면이 이전 버전이면 보조 프로그램을 새로고침하세요. 서버 재시작 후에는 새 QR로 연결하세요.

4. 확인한 결과
- 서버 검사 80개, 차량 앱 단위검사 61개 통과
- 보조 프로그램 검사 15개 및 지도 화면 동기화 검사 통과
- 실제 Pleos 에뮬레이터: 권한 승인 전 차단 → 차량 화면에서 승인 → 온도 변경 반영
- 같은 승인으로 D단 공조 재조절 성공, 미승인 항목 차단, 권한 회수 뒤 차단
- Family Care 첫 연결 화면에서 공조 권한만 선택해 요청되는 것 확인
- 실제 내비 안내 시작 후 보조 프로그램으로 약 1.06km 경로 전달, GPS 79m 진행 확인
- 시동 꺼짐에 따른 해제는 로직 검사로 확인. 현재 에뮬레이터에서는 시동 신호 미지원이므로 실제 ON/OFF 연동 검증은 하지 못했습니다.

차량은 검증 후 P단으로 되돌렸습니다. 운전 중 차량 화면의 상세 조작 제한은 유지합니다.
