Family Care 0.12.2 — 수정한 기능 바로 확인하기

0. 휴대폰 업데이트
   바탕화면 'FamilyCare-휴대폰앱-0.12.2-수정완료.zip'을 휴대폰에 전달하고 압축 해제.
   02-FamilyCare-navigation-debug.apk = 소유자의 '내 차' 앱.
   03-FamilyCare-care-debug.apk = 동승자 'Family Care' 앱.
   기존 앱 위에 업데이트 설치. 데이터 보존을 위해 먼저 삭제하지 않아도 됨.
   차량용 앱은 PC 에뮬레이터에 이미 업데이트했으므로 휴대폰에는 설치하지 않음.

1. 연결
   PC에서 http://127.0.0.1:8770/ 열기.
   휴대폰을 PC와 같은 Wi-Fi에 연결.
   소유자 앱은 소유자 QR, 가족 앱은 가족 QR → 앱 열기 → 정보 확인하고 연결.
   이번에 서버를 재시작했으므로 새 QR 사용. 연결됨과 차량 상태를 먼저 확인.

2. 에어컨 확인 — P단 정차에서 시작
   가족 앱 홈에서 '시원하게'를 한 번 누름.
   이제 한마디 전달이 아니라 현재 설정 온도보다 0.5도 낮추는 공조 요청이다.
   차량 화면 왼쪽 위 'Family Care' → 요청 카드 → '승인하고 온도 적용'.
   휴대폰의 처리 결과와 차량 공조 설정 온도 변화 확인.
   '따뜻하게'는 반대로 0.5도 올린다.
   가족 앱 '요청'에서 지원 좌석·숫자 온도·공조 켜기/끄기도 사용 가능.
   소유자 앱은 '관리'에서 설정 온도 적용 / 공조 켜기·끄기.
   실내 온도(차 안 센서 값)와 설정 온도(에어컨 목표 값)는 다르다.
   설정을 바꿔도 실내 센서 숫자가 바로 바뀌는 것은 아니다.

3. 검색 버튼 확인
   차량 지도에서 '어디로 갈까요?' 누름.
   맨 위 '주소·장소 이름 검색'에 '양재시민의숲' 입력.
   입력창 오른쪽 파란 '검색' 누름. 키보드의 검색 키도 가능.
   결과에서 장소 선택 → 아래 '우리 앱에서 경로 찾기' → 안내 시작.
   키보드가 보일 때도 검색 버튼은 입력창 옆에 있다.
   '기저귀 교환' 같은 시설은 검색 결과가 없을 수 있으며 오류와 구분해 안내한다.

4. 주행 알림 확인
   조종석에서 경로를 준비하고 'GPS 자동 주행 시작 / 재개'.
   가족 앱 홈에서 '휴식 요청' 누름.
   차량 지도 우측 하단에 작은 알림 카드와 요청 수가 나오는지 확인.
   알림음·한국어 음성이 끝난 뒤에도 미처리 요청 카드는 남아 있어야 한다.
   조종석에서 정차 → 차량 'Family Care' → 요청 확인 또는 보류.
   처리 결과가 가족 앱에도 바뀌면 완료.

5. 반려동물·사진까지 확인하려면
   반려동물: 가족 앱 → 반려동물 → 1분 타이머 시작 요청 → 차량 승인.
   1분 뒤 경고 → 가족 앱에서 직접 확인했어요 → 타이머 종료 요청·승인.
   지난 확인 알림에서 발생·확인·해제 이력 확인.
   사진: 가족 앱 → 추억 → 사진 선택 → 위치·시간 확인 → 가족 지도 공유.
   사진 열기 → 이 기기의 앨범에 저장. 이동 기록과 시간·위치가 맞으면 여행과 연결됨.

   가족의 차량 조절 요청은 운전자 승인 후 실행된다.
