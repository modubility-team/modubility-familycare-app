Family Care 0.12.0 · TMAP 연결 / 개선사항 / 확인 순서
2026-10-28

현재 지도 구성
- 바탕 지도: MapLibre + OpenFreeMap. TMAP 지도 타일 또는 TMAP 앱 화면을 복제하지 않는다.
- 검색: TMAP 장소(POI) 통합 검색. 이름·주소와 시설 검색어로 후보를 찾는다.
- 길찾기: TMAP 자동차 경로 REST API. 검색 시점 교통을 반영한 시간과 한국어 안내를 사용한다.
- GPS 안내: 우리 차량 앱에서 Android GPS를 받아 경로를 따라 남은 거리/시간/회전 안내를 계산한다.
- 별도 상품인 TMAP Navigation SDK·EDC SDK는 사용하지 않는다.
- 카카오 키는 기존 로컬 파일에 남겨 두었지만 현재 서버는 사용하지 않는다.
- Pleos 기본 삼각형 내비의 빈 지도 문제는 별개이며 미해결이다.

설정
1. SK open API 로그인 → 대시보드 → 앱 → 앱 만들기 → Family Care.
2. 해당 앱에 TMAP 무료 상품을 추가한다. 유료 결제·자동 초과 과금은 신청하지 않는다.
3. 앱의 앱키(appKey) 탭에서 확인한 키를 프로젝트 루트 tmap.local.json의 app_key에 입력한다.
4. enabled=true. 키 파일은 요청마다 읽으므로 키만 바꿀 때는 서버 재시작이 필요 없다.
5. python scripts/check_tmap.py --live 로 공개 예제 장소 검색/경로를 검사한다. 키/응답 원문은 출력하지 않는다.
6. 키 파일은 Git·APK·휴대폰 ZIP에 포함하지 않는다. 친구 PC는 별도 키 또는 현재 PC 서버 연결이 필요하다.
앱키를 만들었다고 상품 사용 권한까지 생기는 것은 아니다. 상품 연결과 현재 무료 한도는 대시보드에서 확인한다.
공식 공개표: 장소 검색 20,000건/일, 경로안내 1,000건/일. 현재 계정의 상품 한도가 우선이다.
앱 자체 한도: 모든 검색/경로를 합쳐 분당 30회, 하루 최대 500회. 서버 프로세스 재시작 시 초기화되는 보조 제한이며 제공자의 계정 한도를 대체하지 않는다.
카드 없이 Free 상품을 활성화할 수 있는지는 해당 계정의 가입 화면에서 확인한다.

새 기능 확인 순서
1. 차량과 휴대폰 두 앱을 0.12.0으로 업데이트한다. 휴대폰에는 차량용 APK를 설치하지 않는다.
2. PC 시연 실행 → 차량 앱의 가족 연결 → 휴대폰 소유자/Family Care 각각 새 QR로 연결한다.
3. 차량 지도 → 목적지 선택 → TMAP → 장소 이름 입력 → 장소 찾기 → 결과 선택.
4. TMAP 길찾기 선택 → 우리 앱에서 경로 찾기 → 경로 확인 → 안내 시작.
5. 가족 탭에서 현재 경로 공유를 켠다. 공유하지 않으면 휴대폰은 기준 위치 주변 검색만 가능하다.
6. Family Care 홈 → 쉬어 갈 곳 찾기 → 휴게소 등 시설 선택 → 장소 찾기.
7. 이곳 경유 시 우회 시간 확인 → 후보 선택 → 경유지 → 차량에 장소 제안.
8. 차량 P단·정차 → 요청 확인 → 승인하고 경로 찾기. 운전자 승인 전에는 경로가 바뀌지 않는다.
9. 차량/휴대폰에서 경로 변경 예상 시간 확인 → 차량 안내 재개.
10. PC 시연 패널의 차량 연결·GPS·가족 연결 상태를 각각 확인한다. 오래된 연결은 QR을 숨긴다.
공개 검색(Photon/Overpass)과 OSRM은 사용자가 직접 선택하는 별도 기능이다. 실패 시 다른 제공자로 자동 전송하지 않는다.

개선 범위
- 남은 경로 현재/약 10/25 km 전방 최대 세 지점에서 시설을 찾고 지나친 후보·경로와 먼 후보를 줄인다.
- 실제 두 번의 경로 계산으로 후보 경유 전/후 시간을 비교한다. 기존 경유지는 제외한 예상 비교이며 승인 시 다시 계산한다.
- 수유실·반려견·무장애 등은 검색어 일치 후보다. 시설 보유/운영/고속도로 진입 방향이 검증되었다고 표시하지 않는다.
- 휴식 요청에서 시설 찾기까지 연결했고, 변경 경로와 예상 시간이 가족 앱에 전달된다.
- 도로 구간별 시간을 사용해 남은 시간을 계산한다. 실시간 교통을 계속 수신하는 서비스는 아니다.
- 오래된 앱이 다른 제공자에게 잘못 동의해 위치를 보내지 않도록 업데이트를 요구한다.
- Pleos FusedLocation 1.1.3은 지원/초기화/수신/해제 진단을 추가했다. confidence를 미터 정확도로 임의 변환하지 않으며 길안내 위치 기준은 Android GPS다.

데이터 흐름
휴대폰/차량 → 역할별 2시간 세션 토큰 → PC relay → TMAP HTTPS API.
외부 응답 대기 중에도 차량 heartbeat·권한 회수가 가능하며 회수/만료가 먼저면 응답을 버린다.
API 응답 DB/장기 캐시/오프라인 경로 묶음 없음. 검색 결과는 메모리에서 1시간 후 비우고 안내 경로는 최대 23시간 후 폐기한다.
API 키는 PC만 보관한다. 신뢰 LAN의 개발용 앱→PC 통신은 HTTP이며 상용 운영은 TLS·계정 서버가 필요하다.
개발 시연은 ADB 상태 파일에 현재 경로를 일시 기록하고 정상 종료 시 삭제한다. 강제 종료 후 잔여 파일을 오래된 시연에 재사용하지 않는다.
사용자가 동의한 실제 GPS 이동 기록은 외부 제공자 경로와 별도다.

검증 및 남은 일
- 서버 테스트 44개, 시연 상태 테스트 3개, Android 단위 테스트 55개 통과.
- 실제 TMAP 장소 검색·자동차 경로 요청 성공. 에뮬레이터 통합 결과는 검증결과-0.12.txt 참조.
- 카메라/짖음 감지는 사용자 요청으로 보류. 실차 원격 시동/잠금·OEM 소유권 인증·클라우드 푸시는 미구현.
- 공공 휴게소 구조화 데이터(수유실·도로 방향 등)와 검색 후보의 검증된 결합은 아직 없다.
- 실차 안전 검증·상용 서비스 승인·최종 서명·팀명·접수 서류는 완료되지 않았다.
- GPS 자동 주행은 에뮬레이터 위치 재생이며 실제 자율주행이 아니다.
