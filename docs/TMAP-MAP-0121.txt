TMAP 지도 연결 0.12.1 · 2026-10-28

무엇이 바뀌었나
- 우리 차량 앱과 휴대폰 앱의 지도 배경을 공식 TMAP Android Vector Map SDK 3.7로 전환.
- 현재 GPS 위치, TMAP 자동차 경로, 장소 선택, 사진 핀, 확대·축소 표시.
- 차량 지도 방향 버튼은 북쪽 고정 / 진행 방향. SDK가 지원하지 않는 카메라 기울기를 3D로 표시하지 않음.
- Pleos 기본 내비 앱 자체의 지도 공급자는 변경하지 않음. 하단 F. 아이콘의 우리 앱에서 확인.

비용
- 사용자가 SK open API 앱의 상품이 '무료체험 Free'임을 확인함.
- 공식 무료 제공량: 지도보기 100,000건/일, POI 검색 20,000건/일, 경로안내 1,000건/일.
- 이 수치는 API 요청량이며, 지도를 여는 횟수와 같다고 보장하지 않음.
- Free 한도 초과 시 이용이 차단됨. 유료 상품 가입·전환은 하지 않음.
- PC의 500회/일 제한은 REST 검색·경로용 보조 제한. SDK 지도 요청은 제공자의 Free 쿼터로 제한됨.
- 시연 전 SK 대시보드에서 Free 상품과 사용량 확인. 무료 한도를 늘리려고 동일 서비스의 앱을 추가 생성하지 않음.

연결·사용
1. 같은 Wi-Fi에서 기존 시연 실행 도구로 PC 서버와 차량 앱을 켠다.
2. 차량에서 동승자 연결을 시작한다. 시연 실행 도구에서는 자동으로 준비한다.
3. 연결이 되면 TMAP 지도가 표시된다. 인터넷 연결도 필요하다.
4. 실제 휴대폰은 새 0.12.1 APK로 업데이트하고 시연 페이지의 새 QR로 연결한다.
5. 차량 목적지 검색 또는 시연 페이지의 경로 준비 후 자동 주행을 시작한다.
6. Family Care 앱의 요청 탭에서 지도·장소를 선택하고 운전자에게 제안한다.
연결 전에는 '차량 연결을 시작하면 티맵 지도가 표시돼요'라고 안내한다.

인증 키·공유 범위
- 키 원본은 Git 제외 파일 tmap.local.json의 app_key. map_sdk_enabled=true가 있어야 SDK 전달이 활성화된다.
- 사용자가 2026-10-28 런타임 키 전달을 명시적으로 허용함.
- 차량 세션 생성은 PC 로컬 연결만 가능. 활성 세션의 차량·소유자·가족 토큰만 SDK 설정을 받을 수 있음.
- 손님·상태 확인 역할, 잘못된 토큰, 회수·만료된 연결에는 키를 반환하지 않음.
- 앱 코드는 키를 소스·APK·설정 파일에 저장하지 않고 해당 연결 동안 메모리에 보관.
- 현재 PC→기기는 HTTP 시연 연결. 같은 Wi-Fi에서 가로채질 위험이 있으므로 신뢰하는 시연 네트워크와 기기만 사용.
- 이미 전달된 키 자체는 QR 권한 회수로 폐기되지 않음. 키 유출이 의심되면 SK 콘솔에서 키 재발급 필요.
- 외부 배포 시 HTTPS, 기기 인증, 제공자에서 지원하는 앱/IP 제한 등을 별도로 설계해야 함.
- 지도 화면 범위·기기 네트워크 정보는 공식 SDK를 통해 TMAP으로 전송됨. 오프라인 지도 저장/수집 기능은 없음.

팀원 PC에서 빌드
- scripts/windows/Setup-TmapSdk.ps1 실행. 공식 ZIP의 SHA-256을 확인하고 android/local-sdk/tmap에 설치.
- FamilyCare.cmd 빌드 메뉴와 시연 시작 스크립트는 이 설치를 자동 확인함.
- Android Studio 또는 Gradle을 직접 실행하는 경우 SDK 설치 스크립트를 먼저 실행.
- SDK AAR은 Git에서 제외. 앱 키도 Git·채팅·공유 ZIP에 넣지 않음.
- 공식 SDK: https://tmapapi.tmapmobility.com/main.html

확인 범위
- 서버 권한·동의·설정 비활성·권한 회수·세션 종료 테스트 포함 45개 통과.
- Pleos 2.1 에뮬레이터에서 공식 티맵 지도 인증, 한국 지도 타일, 좌표, 확대축소, 지도 선택 확인.
- 사진 핀 표시·열기와 읽기 전용 지도에서 선택·사진 터치 차단 검증 통과.
- Android 단위 검사 55개 통과, 세 APK에 실제 API 키 미포함 확인.
- 실제 TMAP 경로에서 20km/h 모의 GPS 6초 주행(약 33.6m) 후 정차 복귀 확인.
- 실제 휴대폰 설치 후의 화면·성능 및 실차 주행은 별도 확인 대상.
