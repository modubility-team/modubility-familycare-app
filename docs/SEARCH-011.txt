

Family Care 0.11 manual place search (2026-10-28)
Place search: Photon public demonstration API by komoot, using OpenStreetMap data.
https://github.com/komoot/photon
Facility search: Overpass API. https://wiki.openstreetmap.org/wiki/Overpass_API
Data: © OpenStreetMap contributors, ODbL. https://www.openstreetmap.org/copyright
Query and search center are sent only after the user presses the search button.
Public APIs have no availability guarantee; no-result and network-failure states are distinct.
No API key, proprietary POI database, mass tile download, or copied manufacturer artwork was added.
