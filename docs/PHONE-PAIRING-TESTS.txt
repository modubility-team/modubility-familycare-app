Family Care 간편 연결 변경 및 검증 / 2026-10-27
차량 앱 0.4.0 유지 / 스마트폰 길안내·케어 0.4.1 (versionCode 2)

변경
- 연결 메뉴에서 다른 앱으로 같은 세션·역할의 연결을 넘깁니다.
- 받는 앱에서 확인해야 연결됩니다. 기존 연결은 확인 전까지 유지됩니다.
- 전달 대상 패키지를 고정하고 두 앱의 서명이 일치하는지 검사합니다.
- 코드의 영구 저장, 클립보드 자동 읽기, 새로운 Android 권한은 추가하지 않았습니다.
- PC에서 연결 가능한 사설 네트워크가 하나면 자동 선택, 여러 개면 번호로 선택합니다.
- 실제 물리 어댑터와 게이트웨이가 있는 주소를 우선하여 VPN·가상 어댑터의 오선택을 줄입니다.

검증 결과
1. 두 스마트폰 제품의 JVM 테스트 6개 통과.
2. 두 스마트폰 제품 lint: 오류 0, 경고 0.
3. 세 APK exportDebugApks 빌드 성공, 업데이트한 두 APK 에뮬레이터 설치 성공.
4. PhoneFlowTest 두 제품 모두 통과: QR 링크 수신은 자동 연결하지 않음,
   요청/응답, 손님 권한, 새 링크 수신 시 기존 역할 유지, 취소, 해제 시 전달 불가 확인.
5. ADB로 실제 두 앱 UI의 버튼을 눌러 길안내 → 케어 연결 확인.
   케어 → 길안내에서 기존 가족 연결을 유지하다가 확인 후 손님 연결로 전환 확인.
   차량 세션 종료 후 연결 권한과 전달 기능 해제 확인.
6. Windows 네트워크 선택 5개 시나리오 그룹 통과:
   물리 Wi-Fi 우선, 복수 어댑터 선택 유지, 공인/루프백/APIPA 제외,
   대체 후보 중복 제거, 사설 주소 범위 검증.
7. 현재 PC에서 Wi-Fi 주소 자동 선택 확인. 방화벽 변경 없음.

검증 범위
앱 간 실제 전환은 Pleos 에뮬레이터, 차량 상태는 로컬 테스트 세션의 합성 데이터 사용.
실제 휴대폰 카메라·브라우저의 앱 열기, Wi-Fi 접속은 아직 검증하지 않음.
차량 앱과 서버 본문은 이번에 변경하지 않았으며 기존 0.4.0 전체 시험 기록은
THREE-PRODUCT-TESTS.txt를 참조. 해당 기록의 전체 41개 시험을 이번에 재실행한 것은 아님.
