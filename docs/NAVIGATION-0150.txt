Family Care 차량 내비게이션 0.15.0
작성일: 2026-11-01

현대·기아 ccNC 공식 사용 설명서를 비교해 차량용 길안내 흐름과 화면을 보완했습니다.
현대차의 넓은 지도, 우측 회전 안내, 하단 목적지·현재 위치 구성을 참고했습니다.
현대·기아의 화면 이미지, 로고, 아이콘 파일은 앱에 복사하지 않았습니다.

1. 바로 사용하는 순서

① 시연 보조 페이지 http://127.0.0.1:8770/ 를 새로고침합니다.
② 현재 위치를 지도에서 선택하고 적용합니다.
③ 차량 앱에서 '어디로 갈까요?' → 주소/장소 입력 → '검색' → 결과 선택을 누릅니다.
   지도를 눌러 임의의 목적지를 직접 정할 수도 있습니다.
④ 추천 / 무료 우선 / 최소 시간 / 고속도로 우선 / 최단 거리 / 어린이보호구역 회피 중 선택합니다.
⑤ '경로 찾기'로 실제 자동차 경로·예상 시간·통행료를 확인합니다.
⑥ '안내 시작 / 재개'를 누릅니다. 시연 보조의 GPS 주행 시작으로 이동시킬 수 있습니다.
⑦ 정차 상태에서 '경로·설정'을 누르면 전체 경로, 재탐색, 경유지 삭제, 일시정지/재개를 사용할 수 있습니다.

2. 주행 화면

우측: 이번 회전의 방향·거리·도로명, 이어지는 회전, API가 제공하는 다음 휴게 시설.
하단: 목적지, 현재 주행 도로, 도착 예정 시각, 남은 시간·거리, 경로 진행률.
지도: 현재 위치 화살표, 진행 방향 추적, 회전 접근 시 자동 확대, 목적지 깃발.
교통: 티맵이 제공한 구간만 원활(초록) / 서행(노랑) / 정체(빨강)로 표시합니다.
      지체는 정체와 같은 색이며 정보가 없는 구간은 기본 파란 경로입니다.
      조회 후 10분이 지나면 교통 색을 지우고 재탐색으로 갱신하도록 안내합니다.
좌측: 현재 속도, GPS 상태. 정차 시 현재 위치 추적, 북쪽/진행 방향, 확대·축소 버튼.
우측 아래: 기존 Family Care 알림을 안내판보다 위에 표시합니다.

3. 추가된 내비 메뉴

'경로·설정 → 경로'
- 실제 경로의 예상 시간·거리·승용차 통행료 확인
- 현재 GPS에서 수동 재탐색 / 경로 옵션 변경 후 재탐색
- 전체 경로 보기 / 방향 전환 지점별 상세 안내
- 목적지 변경 / 경유지 추가·삭제 / 안내 일시정지·재개·종료
- 옵션별로 사용자가 선택한 한 경로를 조회합니다. 여러 경로를 동시에 비교하지는 않습니다.
- '무료 우선'은 유료 구간을 완전히 금지하는 옵션이 아닙니다. 실제 통행료를 확인하세요.

'경로·설정 → 장소'
- 집·회사·즐겨찾기 3곳: 목적지 선택 화면에서 '등록'을 누릅니다.
- 직접 등록한 슬롯 이름과 좌표만 차량 앱 내부에 저장합니다. 삭제 버튼으로 제거합니다.
- 최근 목적지: 이번 실행에서 성공적으로 검색한 최대 10곳. 23시간 이내 자동 만료.
  앱을 다시 실행하면 최근 목록은 비워집니다. API의 경로 응답을 영구 저장하지 않습니다.
- 장소를 선택하면 목적지 선택 화면으로 돌아가 새 GPS 기준으로 다시 경로를 검색합니다.

'경로·설정 → 지도·음성'
- 북쪽 고정 / 진행 방향, 자동 확대 켜기·끄기, 수동 확대·축소, 현재 위치 추적
- 길안내 음성 켜기·끄기, 이번 안내 다시 듣기
- Family Care 요청·주의 알림 소리와 길안내 음성 설정을 분리했습니다.

'목적지 검색'
- 기존 가족 편의시설에 주차장·주유소·전기차 충전소 검색을 추가했습니다.
- 경로가 있을 때 시설 결과에 경로 전방·옆 거리를 표시하는 기존 기능을 유지합니다.
- 검색 결과의 시설 운영 여부·충전기 가용 여부는 실시간으로 보장하지 않습니다.

4. 검증

- 차량 APK 및 두 휴대폰 앱 컴파일 통과.
- 차량 단위 검사 59개, TMAP 연동 규칙 검사 15개 통과.
- 실제 TMAP 무료 우선 경로: 통행료와 원활·서행·정체 구간 응답 확인.
- 에뮬레이터 GPS: 경로 옵션 변경, 화면 겹침, GPS 단절·복구, 이탈 재탐색, 안내 소유권, 도착 검사 통과. 로그: dist/demo/navigation-0150-e2e.log
- 네이티브 지도: 네 방향 추적·화면상 차량 위치·전체 보기·조작·읽기 전용 검사 2개 통과. 로그: dist/demo/navigation-0150-map-tests.log

5. 상용 순정 내비와의 차이 — 구현 완료로 표시하지 않은 항목

- 차로별 추천, 단속카메라, 제한속도, 신호등 잔여 시간, 3D 교차로/AR, 실내 주차장 지도는 미구현입니다.
  현재 앱에 연결한 지도·경로 응답과 SDK만으로 이 기능의 완전한 안내를 구성하지 못합니다.
  관련 데이터/내비 SDK 이용 권한과 지원 범위 확인이 필요합니다. 없는 값을 만들어 표시하지 않습니다.
- 지도는 진행 방향 기준 2D입니다. 입체 카메라 기울기를 흉내 낸 화면을 적용하지 않았습니다.
- 상시 교통 갱신, 서버 기반 사고·통제 정보, 오프라인 지도, 다중 대안 경로 동시 비교는 없습니다.
- 위치가 오래되거나 부정확하면 회전·음성 안내를 대기하고 도착 예정 시각을 숨깁니다.
- 경로 이탈 재탐색은 요청 간격을 제한합니다. 네트워크 불가 시 이전 경로와 실패 상태를 보여줍니다.
- 다른 앱으로 나가면 길안내를 일시정지합니다. 돌아와 안내 재개를 눌러야 합니다.
- 복잡한 검색·설정 조작은 차량 플랫폼에서 허용하는 정차 상태에서 사용합니다.
- 에뮬레이터 검증이며 실차 주행 검증이나 상용 내비 품질 인증을 완료한 것은 아닙니다.
- 현재 Free 상품 설정을 유지했습니다. 유료 SDK 가입, 결제, 요금제 변경은 하지 않았습니다.
