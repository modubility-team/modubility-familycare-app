## 조절과 승인

동승자 요청은 전부 운전자 승인 후 실행합니다. 실제 SDK 조절은 현재 운전석 목표 온도 18~28°C, 0.5°C 간격입니다. 공조 전원이 켜져 있고 설정값이 읽혀야 활성화됩니다. SDK 지원 범위와 겹치는 온도만 사용하며, P단·속도 0·주행 제한 해제 상태를 실행 직전 다시 확인합니다. 승인 대기 요청은 60초 만료됩니다. 소유자 앱은 소유자 QR로 인증한 경우에만 정차 차량에 직접 온도 요청을 보냅니다.

시원하게/따뜻하게/음악 줄이기 같은 홈의 한마디는 부탁을 전달합니다. 이 요청의 확인 완료는 운전자가 읽었다는 뜻입니다. 별도의 숫자 온도 요청은 SDK 설정값을 다시 읽어 일치한 경우에만 조절 완료로 표시합니다. 온도 설정 성공이 실내 냉각 완료나 반려동물 안전 보장을 뜻하지 않습니다.

## 사진과 개인정보

선택한 사진 한 장만 읽습니다. 사용자가 위치 정보 사용 안내를 확인한 뒤 파일 선택기를 열고, 사진의 EXIF 촬영 장소·시간을 자동 입력합니다. 위치가 없거나 권한 거절/기기 정책으로 삭제되어 있으면 지도에서 직접 장소를 고르고, 시간이 없으면 직접 입력합니다. 현재 위치 추적이나 갤러리 전체 읽기는 하지 않습니다.

사진·제목·좌표·촬영 시간은 공유 버튼을 누른 뒤 연결된 가족·소유자·차량에 전달됩니다. 이미지를 JPEG로 다시 인코딩해 다른 EXIF 정보를 제외합니다. 서버 RAM에 세션당 최대 12장, 최대 2시간만 저장하며 전체 연결 종료/만료/서버 종료 시 삭제합니다. 자동 영구 앨범 백업 기능은 없습니다. 장소/날짜 공유 삭제와 원본 사진 삭제는 별개입니다.

지도 제공자는 지도 타일 조회 범위와 IP를 볼 수 있습니다. 사진 파일과 가족 정보 자체를 지도 제공자에게 보내지는 않습니다. 세부 출처·라이선스: MAPS-070.txt 및 THIRD-PARTY-NOTICES.txt.

역할 QR은 해당 링크를 가진 사람에게 권한을 부여하는 로컬 시연 방식입니다. 본인 명의 차량 인증·제조사 계정 OAuth·개인별 가입 인증은 아닙니다. 가족 권한 회수는 가족 역할 전체를 끊고 토큰을 바꿉니다. 다시 허용하면 새 링크를 전달해야 하며, 소유자 링크를 Family Care로 전달하지 않습니다.
