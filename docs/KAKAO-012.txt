Family Care 0.12 · 카카오 연결과 개선 안내
작성일: 2026-10-28

1. 무엇이 달라졌나
- 지도 바탕은 MapLibre/OpenFreeMap이다. 카카오 지도를 복제한 화면은 아니다.
- 장소·주소 찾기: Kakao Local. 이름 검색 결과가 없으면 같은 카카오 주소 API로 조회한다.
- 자동차 길찾기: Kakao Mobility. 검색 시점의 교통을 반영한 예상 시간과 한국어 안내 문구를 사용한다.
- 남은 시간은 도로 구간별 소요 시간을 이용해 계산한다. 계속 갱신되는 실시간 교통 방송이나 차로·단속 안내는 아니다.
- 시설 검색은 남은 경로 현재/약 10/25 km 앞쪽의 최대 세 지점을 조사한다. 경로와 너무 먼 후보·이미 지난 후보를 줄인다.
- ‘이곳 경유 시 우회 시간 확인’은 현재 지점→목적지와 후보 경유 경로를 실제 API로 비교한다. 기존 경유지는 포함하지 않는 예상 비교다. 승인 시 다시 계산한다.
- 수유실·기저귀 교환대·반려견 허용은 검색어 일치 후보다. 시설 보유/영업 여부/고속도로 진입 방향을 확인된 사실로 표시하지 않는다.
- 휴식 요청 확인 뒤 차량의 ‘쉬어 갈 곳 찾기’로 이동할 수 있다. 동승자 앱에서도 경유지 제안→승인→결과를 확인한다.
- 시연 패널은 차량/GPS/가족 연결 상태를 분리하고 오래된 상태·QR을 숨긴다.
- Pleos FusedLocation 1.1.3 지원/초기화/수신/해제를 진단한다. SDK confidence의 정확도 단위가 확인되지 않아 Android GPS를 길안내 위치 기준으로 유지한다.

2. 카카오 설정
프로젝트 루트의 kakao.local.example.json을 kakao.local.json으로 복사한다.
rest_api_key: 이번 프로젝트의 카카오 REST API 키를 입력한다.
mobility_rest_api_key: 같은 앱이면 비워 둔다. 다른 승인된 앱 키를 사용할 때만 입력한다.
enabled: true. 서버는 요청마다 읽으므로 키 입력 후 서버 재시작은 필요 없다.
max_requests_per_day: 기본 500. 서버 프로세스의 한국 날짜 기준 방어 한도이며 서버 재시작 시 카운터가 초기화된다. 제공자의 계정 전체 쿼터를 대신하지 않는다.
카카오 디벨로퍼스 → 해당 앱 → 제품 설정 → 카카오맵 → 사용 설정 ON.
무료 쿼터는 계정의 첫 활성화 앱에 적용된다. 두 번째 앱/초과 사용의 결제 조건은 공식 콘솔에서 별도 확인한다. 이 프로젝트는 결제 수단을 등록하거나 유료 사용을 활성화하지 않는다.
진단: python scripts/check_kakao.py --live
키 값은 출력하지 않는다. 공개 예제 좌표로 실제 API를 호출한다.
키 파일은 Git·APK·휴대폰 ZIP에서 제외한다. 친구는 자기 PC에 별도로 설정하거나 키가 설정된 이 PC 서버에 연결한다.

3. 바로 누르는 순서
① 기존 시연을 종료한 뒤 시연 실행 파일을 다시 실행한다. 차량 앱은 0.12.0, 휴대폰 두 앱도 0.12.0으로 업데이트한다.
② 휴대폰 앱에서 새 소유자/가족 QR로 연결한다.
③ 차량 지도에서 목적지 선택 → 카카오 → 장소 이름 → 장소 찾기 → 결과 선택.
④ 카카오 길찾기를 선택하고 ‘우리 앱에서 경로 찾기’ → 경로 확인 → 안내 시작.
⑤ 가족 탭에서 현재 경로 공유를 선택하면 가족 앱에서 경로 앞쪽 시설을 검색할 수 있다. 공유를 안 하면 선택 위치 주변 검색만 한다.
⑥ Family Care 홈 → 쉬어 갈 곳 찾기 → 시설 선택 → 장소 찾기.
⑦ 후보의 ‘이곳 경유 시 우회 시간 확인’ → 후보 선택 → 경유지 → 차량에 장소 제안.
⑧ 가상 차량 P단 정차 → Family Care 요청 → 승인하고 경로 찾기.
⑨ 차량/휴대폰에서 경로 변경 예상 시간 확인 → 차량 안내 재개.
실패 시 오류 문구를 확인한다. 공개 검색/OSRM을 직접 선택할 수 있지만 자동으로 다른 업체에 위치를 보내지는 않는다.

4. 데이터 흐름과 남은 범위
휴대폰 → 역할별 연결 토큰 → PC relay → Kakao HTTPS API → 검색 화면.
차량 → 승인된 경로 요청 → PC relay → Kakao HTTPS API → 자체 GPS 길안내.
PC relay가 장시간 API를 기다려도 차량 heartbeat와 권한 회수를 막지 않는다. 만료/권한 회수가 먼저면 검색 결과를 버린다.
공급자 응답 DB/장기 캐시/오프라인 경로 묶음 없음. 검색·현재 안내에서만 사용하고 안내 종료 시 지운다.
개발용 시연의 ADB IPC 상태 파일은 현재 경로 재생에 일시 사용하며 시연 정상 종료 시 삭제한다. 강제 종료 잔여 파일은 다음 시연에서 덮어쓴다. 제출용 앱에는 이 테스트 코드가 들어가지 않는다.
사용자가 동의한 GPS 기록은 공급자 경로와 별도인 자신의 실제 이동 기록이다.
공공 휴게소 표준 데이터(수유실·화장실·도로 방향)의 구조화 결합은 이번 버전에 포함되지 않았다. 자료 갱신·매칭 검증 후 추가해야 한다.
실내 카메라와 짖음 감지는 사용자 요청으로 보류한다. 실제 원격 시동/잠금·OEM 소유권 인증·클라우드 푸시는 미구현이다.
Pleos 기본 내비 지도는 별도 공급자 환경 문제이며 이번 카카오 연결은 우리 앱에 적용된다.

5. 발표에서 설명할 내용
핵심은 새 지도 서비스가 아니라 ‘동승자의 요구를 안전한 운전자 승인과 경로/차량 설정으로 연결하는 가족 케어’다.
지도·경로는 외부 제공자, 차량 상태/공조는 Pleos Vehicle, 음성은 Pleos TTS, 기본 내비 연동은 NaviHelper가 맡는다.
모의 GPS 자동 주행은 테스트 위치 재생이다. 실제 자율주행, 안전 인증, 의료적 멀미 예측으로 설명하지 않는다.
서버/차량/GPS 중 어디서 끊겼는지를 보여주고 상태를 모르면 제어하지 않는다는 점을 시연한다.
팀명·앱명·서명 키·동의서·최종 접수는 팀이 확정해야 한다.
