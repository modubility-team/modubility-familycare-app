Family Care 0.11.0 — 55개 기능 수정 결과
작성: 2026-10-28

판정 범위: 로컬 소스·빌드·단위 테스트와 Pleos 에뮬레이터. 실제 자동차나 실제 휴대폰의 절전 동작까지 검증했다는 뜻은 아닙니다.
사용자 보류: P6 실내 카메라 / F17 짖음·이상행동 감지.
외부 확인 대기: N6 Overpass 편의시설 서버 과부하/시간 초과. 검색 코드는 구현했지만 실제 응답은 확인하지 못했습니다.
시연 지표: N9/F9/F11은 급조작에 따른 휴식·점수·참고지수이며 의학적/실차 안전 성능 검증이 아닙니다.

확인한 테스트
- Android 세 앱 단위 테스트 53개 통과. Debug/Release 세 앱 빌드 통과.
- 서버 권한·요청·알림 이력·수신 대상·위치 공유 테스트 23개 통과.
- 에뮬레이터 통합 4개 통과: 가족 구성/타이머/기록 공유, 휴대폰 백그라운드 도착·뒷좌석 알림, 승인된 SDK 공조·공조 보조·복원, GPS 목적지·경유지 승인.
- Photon 공개 검색: 서울역 결과 3개 응답. Overpass: 502 및 25초 시간 초과.

처음 확인할 순서
1. 앱설치파일의 02(내 차 관리), 03(Family Care)를 휴대폰에 업데이트 설치. 01은 Pleos 차량용입니다.
2. 기존 시연 실행 파일로 차량·릴레이를 켜고 새로운 QR로 연결. 서버 재시작 전의 QR은 만료됩니다.
3. 차량: 가족 → 구성·민감도, GPS 기록 및 가족 경로 공유 선택 → 이동 시작. 시연 조종석 준비는 모의 GPS 기록·공유를 켭니다.
4. Family Care: 홈 → 가족 구성, 반려동물 → 타이머/공조 보조 요청. 차량의 받은 요청에서 정차 후 승인.
5. 휴대폰: 연결 → 알림·보호자 설정 → 별명/연락처 저장 → 백그라운드 알림 켜기. 각 보호자 기기에서 수행.
6. 휴대폰 추억 탭에서 이동 리포트를 저장하고, 선택한 공유 사진을 열어 기기 앨범에 저장.
7. 주소 검색은 차량의 어디로 갈까요? 또는 Family Care의 요청 탭. 시설 검색 실패 시 잠시 뒤 다시 시도하거나 지도에서 직접 선택.

보관과 연결
- 차량: GPS 기록을 켠 이동 최근 20개. 휴대폰: 직접 저장한 이동 20개, 사진 30장. 앱 데이터 삭제 시 삭제.
- 릴레이: 상태·선택한 가족 정보·요청·공유 경로/사진·알림 이력은 RAM에 최대 2시간. 종료/재시작 시 삭제.
- 전화번호는 해당 휴대폰에만 저장. 보호자 별명은 알림을 켤 때 차량과 소유자에게 등록.
- 손님/상태 확인 역할에는 가족 구성·이동 경로·사진 비공개. 기기에 이미 따로 저장한 사본은 서버 연결 종료로 지워지지 않음.
- 백그라운드 알림은 사용자가 켠 LAN 연결 서비스입니다. 강제 종료·Wi-Fi 이탈·차량 전원/앱 종료에는 지속을 보장하지 않음.
- 차량 공조 SDK 시연에는 Virtual Console의 활성 시뮬레이션 연결이 필요. 시연 조종석을 열어 두세요.

항목별 결과
N1. [구현] 목적지 검색 및 경로 안내
주소·장소명 Photon 검색 → 좌표 선택 → 실제 GPS/OSRM 길안내. 검색은 버튼을 누를 때만 전송. 서울역 검색 응답 확인.

N2. [구현] 동승자 목적지·경유지 요청 수락/거절
가족 목적지·경유지 제안은 pending → 정차 승인 → 경로 검색 → 결과 공유. 실제 경로 API 통합 테스트 통과. 경유지 1개 지원.

N3. [구현] 동승자 요청 카드 수락/거절
한마디 요청 확인·보류·처리 결과 유지. 메모 확인이 차량 장치 실행을 의미하지 않음.

N4. [구현] 급가속·급제동·급조향 발생 시 짧은 경고 표시
지도 길안내 중에도 급가속·급감속·급조향의 짧은 경고를 표시. 중요한 케어 알림을 먼저 표시.

N5. [구현] 가족 맞춤 휴식 간격 제안
0~3세 아이 동승 60분, 그 외 90분 주행 기준 휴식 안내. 직접 휴식 확인 시 누적 주행 기준 초기화.

N6. [외부 서비스 확인 대기] 휴게소 편의시설 필터
휴게소·화장실·수유·기저귀 교환·반려견 공원·무장애 화장실 필터 구현. 기준 위치 5km 이내 OSM 등록 정보. Overpass 서버 과부하(502)와 재시도 시간 초과로 실제 시설 검색 검증은 미완료. 없는 시설을 임의 표시하지 않음.

N7. [구현] 경로·정차 지점 기록
차량 가족 탭에서 GPS 기록을 켠 뒤 이동 시작. 경로·1분 이상 정차·수동 휴식·이벤트 기록, 차량 최근 20회 저장.

N8. [구현] 출발 시 가족 맞춤 모드 추천 안내
이동 시작 전 탑승 유형, 추천 모드, 휴식 간격, GPS 기록·공유 여부를 확인하는 안내창 추가.

N9. [시연 지표] 멀미 위험에 따른 휴식 및 경유지 제안
최근 급조작이 누적되면 짧은 휴식 안내와 정차 후 장소 찾기 제공. 생리적 멀미 예측 모델은 아님.

N10. [구현] 목적지 도착 및 남은 거리·시간 안내
GPS 도착 판정, 남은 거리·시간과 진행률 공유. 실시간 교통 미반영.

N11. [구현] 경로 변경 시 추가 거리·시간 비교
목적지·경유지 변경 성공 시 이전 남은 경로 대비 추가 km/분 표시. 검색 실패 시 기존 경로 보존.

N12. [구현] 여행 진행 상황 및 경유지 방문 현황
전체 경로 기준 진행바, 단일 경유지의 예정·방문 표시. 경유지 주변 60m 이내의 GPS 수신으로 방문 확인.

N13. [구현] 목적지 도착 시 뒷좌석 확인 안내
GPS 도착 후 P단 정차 확인 시 아이·반려동물 뒷좌석 확인 안내. 확인 후 같은 도착에서 반복되지 않는 규칙 테스트 통과.

P1. [구현] QR 스캔 및 차량 연결
휴대폰 기본 카메라의 QR 읽기 → 웹 연결 페이지 → 설치 앱으로 연결. 앱 자체 카메라 스캐너는 추가하지 않음.

P2. [구현] 가족·손님별 접근 권한 적용
소유자·가족·손님·상태 확인 역할 유지. 승인·개인 기록·사진 권한은 서버에서도 검사.

P3. [구현] 실내 온도·배터리·도어·창문 상태 확인
온도·배터리와 문·창문 상태 표시. 미지원·오래된 신호는 미확인.

P4. [구현] 반려동물 케어 단계별 위험 경고 수신
차량 위험 단계·60초 미확인 재알림과 연결 끊김 표시. 설치 앱의 사용자 시작 백그라운드 연결 알림 추가.

P5. [구현] 반려동물 복귀 타이머 설정 및 확인
휴대폰에서 1~30분 타이머 시작·종료 요청 → 차량 정차 승인 → 남은 시간 동기화. 실제 릴레이 통합 테스트 통과.

P6. [사용자 보류] 실내 카메라 실시간 확인
사용자가 실내 카메라 기능을 보류하도록 요청함. 실제 영상 기능을 구현했다고 표시하지 않음.

P7. [구현] 목적지 변경·경유지 추가 요청
좌표 선택·주소 검색 결과를 목적지/경유지로 요청. 최종 길안내는 차량에서 시작.

P8. [구현] 운전자 요청 카드 전송
한마디·휴식·온도 요청 및 요청 처리 내역.

P9. [차량 조건부] 뒷좌석·조수석 공조 온도 조절
SDK의 좌석별 공조 영역·범위·읽기 상태를 조회해 지원하는 좌석만 선택 가능. 조수석·뒷좌석 독립 영역이 없는 차량에는 해당 항목이 나오지 않음. 운전자 승인 후 쓰기·읽기 재확인.

P10. [구현] 음악 변경 및 제어 요청
음악 줄이기와 자유문자 음악 변경 요청. 음악 앱을 직접 제어하는 기능은 요구 범위의 요청과 구분.

P11. [구현] 운전 피드백 상세 기록 확인
급조작 종류·시각·수신된 위치와 이동별 상세 리포트. 최신 위치가 없으면 이벤트 위치를 지어내지 않음.

P12. [구현] 아이용 도착 진행바
차량 경로 전체 길이를 기준으로 한 진행바와 도착 표시.

P13. [구현] 경로·정차 지점 확인
차량에서 공유를 켠 현재 이동의 경로·정차·이벤트 지도와 목록. 휴대폰에 명시적으로 저장 가능.

P14. [구현] 갤러리 사진의 시간·위치 자동 매칭 및 여행 앨범
선택한 사진의 EXIF 위치·시간을 사용. 사진 열기 → 기기 앨범 저장, 최근 30장. 저장된 이동과 촬영 시간(분 단위 오차 1분)·기록 위치 250m 이내를 매칭. 전체 갤러리를 자동 수집하지 않음.

P15. [구현] 여행 통계 카드
이동 거리·시간·급조작별 횟수·참고 점수 카드. GPS 모의 위치를 포함하면 시연 기록으로 표시.

P16. [구현] 가족 공유 링크 생성
소유자가 역할별 초대 링크 공유·권한 회수. 기존 링크 회수 시 대기 명령과 해당 역할 수신 기기도 정리.

P17. [구현] 목적지 도착 알림 수신
휴대폰 앱을 화면에서 내린 상태에서도 도착 Android 알림 생성 확인. 연결 → 알림·보호자 설정에서 직접 켜야 함.

P18. [차량 조건부] 아이·반려동물 두고 내림 위험 알림 수신
아이·반려동물 선택 상태의 도착·종료·문/지원되는 시동 신호를 바탕으로 직접 확인 알림. 실내 존재를 자동 검출하거나 실제 방치 방지를 보장하는 장치가 아님.

P19. [구현] 운전자 요청 처리 상태 확인
대기·처리 중·확인 완료·보류·결과 미확인 표시. 승인 없이 차량 설정 실행 금지.

P20. [구현] 반려동물 위험 알림 이력 및 처리 상태 확인
활성 알림의 확인 및 해제된 최근 100개 이력, 발생·확인·해제 시각. 서버 세션 종료/최대 2시간에 지워짐.

P21. [구현] 차량 연결 상태 및 데이터 갱신 시각 확인
연결/끊김, 마지막 차량 데이터 갱신 시각. 끊긴 뒤에도 마지막 수신 시각은 유지하고 현재 수치는 미확인 처리.

F1. [구현] 가족 프로필 등록·관리
차량과 휴대폰에서 가족 구성 2개 저장·관리. 탑승 유형·아이 나이대·민감도 설정.

F2. [구현] 가족 프로필 전환
저장된 구성 불러오기 → 차량 승인 후 적용. 이동·타이머 중 구성 변경 차단.

F3. [구현] 가족 탑승 여부 선택 및 확인
아이·어르신·임산부·반려동물·초보운전자 선택. 실제 탑승을 자동 인식하는 기능은 아님.

F4. [구현] 가족 구성에 따른 맞춤 모드 추천
유형별 맞춤 모드 및 출발 전 추천 안내. 가족에게 현재 적용 모드 동기화.

F5. [구현] 초보운전·아이·어르신·임산부 탑승 모드
아이 나이대 및 어르신·임산부·반려동물·초보 유형마다 가감속·조향 기본 기준을 다르게 적용.

F6. [구현] 복수 케어 모드 동시 적용
복수 유형을 선택하면 더 엄격한 기준을 적용.

F7. [구현] 탑승자 유형별 운전 피드백 기준 설정
유형별 기준과 낮음/기본/높음 민감도. 차량에서 실제 수치 확인. 휴대폰 변경은 운전자 승인 필요.

F8. [구현] 급가속·급제동·급조향 감지 및 기록
실제 차량 속도·조향 신호로 급조작 감지, 8초 중복 억제와 신호 공백 처리. 기록을 켜면 종류·시각·위치 기록.

F9. [시연 지표] 가족 맞춤 안전 운전 점수 산출
100점에서 급조작 1회당 3점 차감하는 공개된 시연용 참고 점수. 검증된 안전 운전 인증 점수가 아님.

F10. [구현] 운전 상세 리포트 생성
현재 이동과 차량 최근 20개 리포트. 휴대폰에서 명시적으로 보관한 최근 20개는 연결 종료 후에도 열람 가능.

F11. [시연 지표] 멀미 위험도 계산
최근 3분 급조작 1회당 20점, 최대 100인 멀미 케어 참고지수. 실제 멀미 발생 확률·의학적 위험도 모델 검증은 수행하지 않음.

F12. [구현] 반려동물 실내 온도·배터리·도어·창문 상태 감시
반려동물 확인 타이머 동안 온도·배터리·도어·창문 신호 감시. 전원·통신·센서 조건 미확인 시 경고.

F13. [구현] 반려동물 위험 단계별 판단
온도·배터리·문/창문·센서 누락·타이머에 따른 1~3단계 확인 알림과 미확인 재알림.

F14. [구현] 반려동물 보호자·보조 연락처 알림 관리
담당·보조 보호자 별명/전화번호를 휴대폰에 저장, 전화 앱 열기. 각 보호자가 연결 링크로 참여하고 알림을 켜면 케어/미확인 재알림 수신. 자동 문자·자동 전화는 없음.

F15. [구현] 반려동물 복귀 타이머 관리
휴대폰 타이머 요청·차량 승인·동기화·종료. 오래된 설정 요청은 60초 후 만료.

F16. [차량 조건부] 반려동물 공조 자동 유지
운전자 승인 후 5분/23°C 기준 공조 보조. 30초 간격으로 22~24°C 설정을 보조하며 P단·타이머·공조 전원·센서·배터리 조건 및 수동 변경 감시. 조건 이탈/수신 실패/시간 종료 시 중단. 자동 시동이나 공조 전원 켜기는 하지 않음. Pleos SDK 실행·중단·원래 설정 복원 테스트 통과.

F17. [사용자 보류] 반려동물 짖음·이상행동 감지
사용자 요청으로 짖음·이상행동 감지 보류. 녹음·분석을 실행하지 않음.

F18. [차량 조건부] 아이·반려동물 두고 내림 방지
아이/반려동물 선택 시 출구 문·이동 종료·GPS 도착에 따른 뒷좌석 직접 확인과 보호자 알림. 에뮬레이터의 시동 OFF 미지원 및 탑승 감지 센서 부재는 그대로 표시.

F19. [구현] 가족 도착 알림 대상 관리
알림을 켠 휴대폰을 수신 기기로 등록. 차량 또는 소유자가 기기별 도착/케어 수신을 관리하고 각 기기에도 개별 수신 설정 제공.

F20. [구현] QR별 접근 권한 및 가족 정보 관리
QR 역할별 권한, 역할 회수, 가족 구성 공유 범위 검사. 손님/상태 확인용 링크에는 가족 구성·이동 경로·사진을 보내지 않음.

F21. [구현] 출발·주행·도착 과정의 케어 이벤트 기록
기록 시작·정차·휴식·급조작·케어 알림 발생·GPS 도착·이동 종료 타임라인. 위치 기록/가족 공유는 별도 선택.
