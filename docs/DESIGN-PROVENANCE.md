# Family Care 0.9.0 디자인·자산 제작 기록

작성일: 2026-10-27. 공모전 참가 자체가 제조사의 사진·상표·디자인 사용 허가를 뜻하지 않습니다. 이 문서는 제작 방식에 관한 기록이며 법적 권리 확인이나 주최 측의 심사 승인을 대신하지 않습니다.

## 화면

- 차량 앱은 사용자가 제시한 Pleos 내비 화면의 지도 중심 구성, 목적지 입력, 하단 바로가기, 우측 지도·음량 버튼을 참고했습니다. 구현은 VehicleNavigationHome.kt의 자체 Compose 코드입니다.
- 세 앱과 보조 웹은 흰색·회색 바탕, 남색 강조, 간결한 테두리 버튼을 공유합니다. 스마트폰의 기능 구분과 동승자 운전자 승인 정책은 유지합니다.
- 현대·기아 로고, 공식 앱 스크린샷, 전용 글꼴, OEM 차량 이미지 파일은 복사하거나 추출해 포함하지 않았습니다. 시스템 글꼴과 기존 아이콘 코드를 사용합니다. WithME(구 Family Drive / Family Care)는 독립 개발 프로토타입입니다.
- Pleos 에뮬레이터의 왼쪽 차량 모형, 상태·공조·런처 바는 공급자 소프트웨어 화면입니다. 해당 영역을 우리 앱의 제작 자산으로 주장하지 않습니다.

## WithME 로고·앱 아이콘 (2026-11-11)

- 앱 이름을 패밀리케어앱에서 WithME(위드미)로 바꾸며 로고와 아이콘을 새로 만들었습니다. ME는 차를 뜻합니다.
- 아이콘 ‘말 거는 차’: 말풍선 모양의 차 몸체, 창문 셋(말줄임표이자 가족, 하나는 코랄색), 바퀴 둘. 기본 도형(둥근 사각형·원·삼각형)으로 직접 그린 Android 벡터입니다. 외부 아이콘 세트·제조사 로고·상표를 사용하지 않았습니다.
- 앱별 배경: 차량 #2F6BFF, 내 차 #D8EDFF, 가족 #FFF1E4, 태블릿 #FFFFFF. 가족 점 #FF8A5B.
- 파일: android/app/src/main/res/drawable/ic_withme_foreground.xml, mipmap-anydpi-v26/ic_launcher.xml(적응형), ic_stat_withme.xml(알림), 휴대폰 main·care, 태블릿 같은 이름.
- ‘위드미’는 다른 업종에서 쓰인 적 있는 이름이라 최종 사용 전 상표 검색(KIPRIS)을 권장합니다.

생성 이미지에 로고가 없다는 사실만으로 제3자 권리와의 충돌이 없다고 보증할 수는 없습니다. 특정 현대/기아 차종의 공식 사진이나 3D 모델로 교체하려면 해당 자산의 출처와 사용 허락 범위를 확인해야 합니다. AI 보조 제작의 공모전 취급은 주최 측 조건에 따릅니다.

## 지도와 테스트 자료

지도는 MapLibre/OpenFreeMap을 사용하며 OpenFreeMap·OpenMapTiles·OpenStreetMap 출처를 화면에 유지합니다. 지도 타일을 자체 자산으로 재배포하지 않습니다. 0.10부터 차량 앱은 Android GPS와 OSRM/FOSSGIS 경로로 자체 길안내를 제공합니다. 기존 Pleos 목적지 전달도 별도 버튼으로 유지합니다. 0.9 이전에는 자체 GPS·경로선이 없었습니다. [0.10 구현 범위](NAVIGATION-010.txt).

미리보기의 배터리 82%, 실내 23.4°C, 테스트 차량 명칭은 통합시험 데이터입니다. FAMILY TRIP / DEMO 사진은 시험 코드에서 생성한 합성 이미지입니다. 실제 사용자 차량·사진이라고 설명하지 않습니다. Android 미리보기는 Pleos 에뮬레이터에서 얻었으며 실제 휴대폰 화면 검증을 대신하지 않습니다.

0.8 이하 버전의 Canvas/SVG 차량과 파랑·민트·짙은 화면 설명은 과거 제작 기록입니다. 0.9의 차량 이미지는 위 PNG로 교체했습니다. 기존 SDK·오픈소스 출처, 라이선스 및 NOTICE는 유지합니다.
