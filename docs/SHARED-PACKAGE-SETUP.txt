이 파일부터 읽어 주세요
이 ZIP은 다른 Windows PC에서 실행하고 코드를 수정할 수 있는 전달본입니다.
코드, 설치용 APK 4개, 노트북 연결 서버, 시연 보조 화면, API 설정,
자연어 음성 경유 모델, Cloudflare 외부 연결 도구, 빌드 도구, 사용법을 포함합니다.
최신 상태는 이 안내와 사용안내 폴더를 기준으로 보세요. 일부 과거 개발 기록은 docs에 남아 있습니다.

1. 압축 풀기
ZIP을 마우스 오른쪽 클릭 → 모두 압축 풀기.
예: C:\FamilyCare\FamilyCare_공유패키지
ZIP 창 안에서 CMD를 실행하지 마세요. 원본 ZIP은 보관해 두세요.

2. 받는 PC에 처음 한 번 설치할 것
Intel/AMD x64 Windows PC 기준입니다. Windows ARM PC의 차량 이미지 실행은 확인하지 않았습니다.
개발 도구와 차량 시스템 이미지는 이 ZIP에 복사하지 않았습니다. 아래 공식 설치로 준비하세요.

Android Studio: https://developer.android.com/studio/install
Temurin JDK 17: https://adoptium.net/temurin/releases/?version=17&os=windows&arch=x64
Python 3.12 (Windows 64-bit): https://www.python.org/downloads/windows/
  → 목록의 Python 3.12.10 Windows installer (64-bit), 첫 화면에서 Add python.exe to PATH 체크 후 Install Now
Git (공동 작업을 할 때): https://git-scm.com/install/windows

Android Studio → SDK Manager에서 다음 항목을 설치하세요.
- SDK Platforms: Android 15 / API 35
- SDK Tools: Platform-Tools, Emulator, Command-line Tools, Build-Tools 35.0.0
설치 중 표시되는 약관은 받는 사람이 확인하고 동의 여부를 결정합니다.

Pleos 차량 이미지 설치
SDK Manager → SDK Update Sites → +
Name: Pleos Connect System Image
URL: https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml
SDK Platforms → Show Package Details → API 34의 Pleos Connect system image 설치.
Android Studio 재시작 → Device Manager → Create device → Automotive → Pleos Connect v2.1.0.
Cold boot, RAM 4 GB, API 34 Pleos Connect v2.1.0 APIs를 선택합니다.
이름을 FamilyCare_Pleos로 지정하면 실행 도구가 찾습니다.
공식 설치 화면과 요구사항:
https://document.pleos.ai/docs/connect/guide/getting-started/application-development/setup-connect-sdk-emulator
https://document.pleos.ai/docs/connect/guide/getting-started/application-development/configure-pleos-connect-emulator

3. 첫 실행 준비
프로그램 설치 후 01_FirstSetup.cmd를 더블클릭하세요.
Python 의존성, 음성 모델 실행환경, TMAP SDK, Android 라이브러리를 준비하고 네 앱을 빌드합니다.
음성 모델 파일 자체는 ZIP에 포함돼 있어 해시가 맞으면 다시 다운로드하지 않습니다.
처음 준비할 때는 인터넷이 필요합니다. Setup complete가 나와야 완료입니다.
이 단계는 차량이나 시연 서버를 켜지 않습니다.

설치 경로를 못 찾으면 team-project\familycare.local.example.json을
familycare.local.json으로 복사하여 AndroidSdk / JdkHome / PythonExe / StudioExe /
AvdName / DeviceSerial 중 필요한 항목만 지정하세요.
예: AndroidSdk에 C:/Users/본인이름/AppData/Local/Android/Sdk
경로를 임의로 만들지 말고 Android Studio에 표시된 실제 위치를 사용하세요.

4. 시연 켜기
노트북을 인터넷에 연결 → 00_한번에켜기.cmd 더블클릭 (또는 02_StartDemo.cmd).
00_한번에켜기는 처음 설치(필요할 때만) → 휴대폰 네트워크 선택 → 시연 켜기 → 에뮬레이터 마이크 연결까지 합니다.
처음 실행하면 바탕화면에 '패밀리케어앱 시연 켜기/끄기' 버튼이 생깁니다.
같은 Wi-Fi에서는 기존 QR을 사용합니다. 다른 Wi-Fi·LTE·5G에서는 시연 보조의
‘외부 연결 시작’ → 준비 완료 → 외부 소유자/동승자 QR을 사용합니다.
Cloudflare Quick Tunnel을 다시 시작하면 새 주소가 만들어지므로 새 QR로 연결합니다.
노트북은 계속 켜 둬야 하며, 태블릿 화면·GPS와 IP 카메라는 기존 같은 Wi-Fi 방식을 유지합니다.
상세: 사용안내\EXTERNAL-CONNECTIONS-0206.txt
차량 에뮬레이터, 차량 앱, 연결 서버, 시연 보조 화면을 실행합니다.
노트북 시연 보조 화면: http://127.0.0.1:8770/
차량 신호 보조 화면: http://127.0.0.1:8088/
휴대폰용 Wi-Fi 주소와 외부 연결 QR은 받는 PC에서 새로 만듭니다. 보내 준 사람의 옛 QR은 쓰지 마세요.
Windows 방화벽 질문이 뜨면 본인이 신뢰하는 사설 네트워크에서만 허용하세요.
방화벽 규칙이나 네트워크 설정은 이 도구가 임의로 바꾸지 않습니다.
네트워크가 여러 개라 자동 선택이 안 되면 05_DeveloperMenu.cmd → 2번으로 차량 시작,
6번으로 휴대폰과 같은 네트워크를 골라 서버를 켠 뒤, 그 창을 유지하고 02_StartDemo.cmd를 실행하세요.

5. APK 설치
04_OpenApks.cmd로 설치 파일 폴더를 여세요.
- 01-FamilyCare-vehicle-debug.apk: Pleos 차량용. 일반 휴대폰 설치용이 아닙니다.
- 02-FamilyCare-navigation-debug.apk: 차량 소유자의 ‘내 차 관리’ 휴대폰 앱.
- 03-FamilyCare-care-debug.apk: 동승자의 WithME 가족 휴대폰 앱.
- 04-FamilyCare-tablet-debug.apk: 안드로이드 태블릿의 차량 화면·GPS 연결용. 선택 사항.
휴대폰에는 02와 03을 설치합니다. 태블릿에는 04를 설치하세요.
소유자는 소유자 QR, 동승자는 가족 QR을 스캔 → 설치한 앱에서 연결 → 연결 확인.
태블릿은 시연 보조 화면의 ‘탭으로 차량 화면’ QR을 사용합니다. 노트북도 계속 켜 둡니다.
서버를 재시작하면 새 QR로 연결하세요.

서명 충돌이 나오면
전달받은 APK와 받는 PC에서 새로 빌드한 APK는 개발용 서명이 다를 수 있습니다.
이 경우 기존 앱 위에 덮어쓰기가 되지 않습니다. 보관할 내용을 확인한 후 기존 앱을 삭제하고
그 PC에서 빌드한 앱들을 설치하세요. 앱 삭제 시 해당 기기의 앱 데이터도 삭제됩니다.
서로 다른 PC의 개발용 APK를 번갈아 덮어쓰지 말고, 한 PC의 빌드로 맞춰 사용하세요.

6. 새 음성 경유 확인
가족 앱에서 길안내 권한 요청 → 차량 승인 → 차량 목적지 설정·안내 시작.
시연 보조 화면 ‘GPS 주행 시작’ → 가족 앱에서 장소 제안 → 차량 ‘음성 명령’ → ‘말하기’.
‘추천지를 경유해 줘’, ‘가족이 보내준 데 잠깐 찍고 가자’처럼 말하면
원래 목적지를 유지하며 경유 경로를 계산합니다. 후보가 여러 개면 번호나 이름으로 고릅니다.
애매한 말은 다시 묻습니다. 현재 경유지 1곳, 대기 중인 장소/픽업 요청을 대상으로 합니다.
노트북 마이크로 말하려면 에뮬레이터 옆 '⋯'(Extended controls) → Microphone →
'Virtual microphone uses host audio input'을 켜세요. 에뮬레이터를 켤 때마다 다시 꺼집니다.
상세 안내는 사용안내\53_자연어음성경유_0.20.5.txt를 보세요.

7. 코드 수정
05_DeveloperMenu.cmd → 7번 또는 Android Studio → Open → team-project\android.
Gradle JDK는 JDK 17로 설정합니다.
차량: android\app / 휴대폰 2종: android\phone / 태블릿: android\tablet
공통 화면: android\shared-ui / 연결 서버: companion / 시연 보조: scripts\live_demo.py
수정 후 01_FirstSetup.cmd를 다시 실행하면 라이브러리를 확인하고 APK를 다시 빌드합니다.
그다음 03_StopAll.cmd → 02_StartDemo.cmd 순서로 재실행하고 휴대폰 APK도 업데이트하세요.

Git 공동 작업
이 ZIP은 전달 당시의 최신 로컬 코드 사본입니다. Git 이력과 자동 동기화는 포함하지 않습니다.
GitHub에 같은 최신 코드가 올라가 있다고 가정하지 마세요.
기존 팀 저장소 초대를 받은 뒤, 별도로 clone한 작업 폴더에 이 코드의 변경분을 확인하며 반영하세요.
다른 사람이 수정한 파일을 무조건 덮어쓰거나 강제 push하지 마세요.
API 키, local.json, APK, dist, 서명키는 저장소에 올리지 않도록 .gitignore에 설정돼 있습니다.

8. 종료
03_StopAll.cmd(또는 바탕화면 '패밀리케어앱 시연 끄기')를 실행하면 해당 프로젝트의 시연 서버와 Pleos 차량을 종료합니다.
소스 코드와 설치 파일은 지우지 않습니다.

전달 설정과 범위
사용자의 요청대로 team-project\tmap.local.json 및 kakao.local.json에 현재 API 설정을 포함했습니다.
동일 API 계정의 키를 함께 사용하므로 이 ZIP은 지정된 개발팀에게 직접 전달하는 용도입니다.
API 키를 공개 저장소나 게시판에 업로드하지 마세요. 키 값은 안내문·파일 목록에는 적지 않았습니다.
PC 경로·만료된 QR·실시간 연결 토큰·개인 사진·브라우저 로그인·앱 서명 비밀키는 필요하지 않아 넣지 않았습니다.
받는 PC의 Python 실행환경과 SDK는 해당 PC에서 만들며, Wi-Fi 주소와 연결 QR도 매번 새로 만듭니다.
지도·경로는 기존 TMAP 인터넷 연결과 해당 계정의 사용 한도를 따릅니다.
IP 카메라와 휴대폰 음악 공유는 실제 기기의 연결·허용이 필요합니다.
이 묶음은 개발·시연용이며 공모전 최종 제출용 서명 패키지를 의미하지 않습니다.

확인 파일
PACKAGE-MANIFEST.json에는 묶음 파일별 SHA256이 기록돼 있습니다.
개발 도구 전체를 포함한 무설치 프로그램은 아닙니다. 새 PC에서는 2~3단계를 먼저 진행하세요.

9. 하나의 전달 파일 계속 갱신하기
코드 수정과 필요한 검사를 마친 뒤 06_UpdateSharePackage.cmd를 실행하세요.
네 앱과 시연용 APK를 빌드하고, 현재 코드·실행 도구·사용법·허용된 API 설정을 묶습니다.
기본적으로 바탕화면의 FamilyCare_전체프로젝트_0.20.5_API포함_20261102.zip을 같은 이름으로 교체합니다.
파일명은 기존 전달 파일을 유지하기 위한 것이며 실제 최신 날짜·버전은 00_최신업데이트정보.txt와 PACKAGE-MANIFEST.json에서 확인합니다.
ZIP 압축 및 파일별 SHA256 검증이 성공하기 전까지 기존 ZIP을 유지합니다.
이 도구는 비공개 팀 전달용 API 설정을 포함하므로 공개 저장소 업로드에 쓰지 마세요.

10. 제출용 APK 만들기 (팀 대표 한 명만)
팀명 모두빌리티, 앱명 WithME(위드미)로 정했습니다. (2026-11-11 패밀리케어앱에서 변경)
07_CreateReleaseKey.cmd로 팀 서명 키를 한 번 만들고 08_BuildReleaseApk.cmd를 실행하면
team-project\apk\모두빌리티_WithME_release.apk가 만들어집니다.
키 파일과 비밀번호는 따로 백업하세요. 팀 키가 이미 있으면 새로 만들지 말고 그 키를 받아 씁니다.
