Family Drive / Family Care — 세 앱 사용법과 기능 배분
2026-10-27 / 0.8.0 / 개발·시연용

1. 차량에서: Family Drive 내비게이션
첫 화면이 실제 지도입니다. 목적지를 지도에서 선택하고 이름을 확인한 뒤 길 안내를 요청합니다.
실제 경로 계산·회전 안내는 Pleos 차량 기본 내비가 담당합니다.
가족 구성/모드, 주행 피드백, 휴식, 반려동물 타이머, 뒷좌석 확인, 동승자 요청 승인, 추억 사진을 함께 담당합니다.
당일 공유 사진은 내비 지도에 표시되고, 추억 탭에서는 날짜별로 모아 봅니다.
주행 제한/상태 미확인 때 지도·사진·상세 조작은 숨기고 짧은 안내만 표시합니다.

2. 소유자 휴대폰에서: Family Drive 내 차
내 차 / 관리 / 가족 / 추억의 네 탭입니다.
차량 별명·모델·선택적 차량 번호를 등록하고 차량의 소유자 QR로 연결합니다.
등록 정보는 휴대폰에만 저장되며 제조사 소유권 인증이 아닙니다.
관리: 차량 온도·배터리·문/창문 상태, 목표 온도 설정 요청, 결과 확인.
가족: 가족·손님·상태 확인 역할의 초대 링크와 권한 회수.
시동·문 잠금: 제조사 API 연동 전이므로 연동 준비 안내만 표시합니다.
기존 길안내 앱이 이 앱으로 바뀝니다. 내부 navigation 패키지와 기존 APK 파일명은 업데이트 호환을 위해 유지했습니다.

3. 동승자 휴대폰에서: Family Care
홈 / 요청 / 반려동물 / 추억의 네 탭입니다.
홈의 시원하게·따뜻하게·음악 줄이기·휴식은 간단한 부탁을 운전자에게 보냅니다.
요청의 숫자 온도 조절은 운전자 승인 후 실제 SDK 설정을 시도합니다.
지도에서 목적지·경유지 선택·제안·투표, 장소 저장도 이 앱으로 옮겼습니다.
반려동물 탭에서 차량 상태·확인 타이머·알림을 보고 직접 확인 요청을 보냅니다.
소유자 QR을 Family Care에 넣어 소유자 제어를 우회할 수 없습니다.

4. 합의한 두 가지 규칙
동승자 조절은 모두 운전자 승인 후 실행.
현재 실제 제어: 운전석 목표 온도 18~28°C, 0.5°C 간격. P단·속도 0·UX 허용·SDK 지원 범위·공조 설정값 수신을 확인합니다.
공조 전원이 꺼져 값이 읽히지 않으면 먼저 차량 기본 공조를 켭니다. 앱의 공조 전원/풍량/열선 제어는 아직 없습니다.
승인 대기 60초 뒤 만료. 실제 차량 응답을 다시 읽어 일치해야 완료로 표시합니다.
소유자 앱은 소유자 연결인 경우에만 정차 차량에 설정 요청을 직접 보낼 수 있습니다.

추억 사진은 사용자가 선택한 사진의 촬영 위치·시간으로 자동 배치.
사진 선택 → 위치 사용 안내 → 파일 선택 → 자동 입력된 장소/시간 확인 → 가족 지도에 공유.
EXIF가 없거나 접근할 수 없으면 지도에서 장소 선택/시간 직접 입력. 임의 위치를 실제 촬영 위치로 만들지 않습니다.
전체 갤러리를 수집하지 않고, 현재 위치도 자동 추적하지 않습니다.
서버에는 JPEG 압축 사진·작은 미리보기·제목·촬영 좌표·시간을 세션당 최대 12장 보관합니다.
가족·소유자·차량에 보이며 서버 메모리에서 최대 2시간, 연결 종료/서버 종료 시 삭제됩니다.
영구 저장되는 여행 앨범은 아닙니다. 사진 원본은 사용자의 사진 앱에 그대로 있습니다.

5. 실행
PC: 01_자동차켜기.cmd → 08_우리앱실행.cmd → 서버.
PC 내부는 12번 서버, 휴대폰과 같은 Wi-Fi에서는 13번 서버 중 하나만 사용합니다.
차량: 요청 → 동승자 연결 → 소유자는 소유자 QR, 동승자는 가족 QR.
휴대폰: 앱설치파일의 최신 02/03 APK를 각각 업데이트 → QR에서 해당 앱 열기 → 정보 확인하고 연결.
소유자 앱에서 Family Care로 넘길 때는 가족 링크를 전달합니다. 소유자 링크를 공유하지 않습니다.
서버 재시작/만료/권한 회수 후에는 새 QR로 연결해야 합니다.
기존 웹페이지는 기본 요청·앱 열기용이며 설치 앱의 새 기능을 모두 제공하지 않습니다.

6. 기획상 남은 외부 연동
자체 GPS 추적·경로선·교통정보·주소/시설 검색·경로 주변 휴게소 추천.
제조사 계정/소유권 인증·실차 원격 시동·문 잠금·추가 제어 API.
반려동물 자동 공조 유지·카메라/수면 감지·차량 외부 표시.
인터넷 원격 연결·백그라운드 푸시·SMS/전화·장기 사진 백업.
차량 API 지원/계약과 동의가 필요한 항목이며 버튼만으로 실행 완료라고 표시하지 않습니다.
실물 휴대폰·실차·장시간·제조사 심사·최종 팀 서명/제출 검증은 별도입니다.

7. 개발자 참고
android/app = 차량, android/phone navigation = 소유자, care = 동승자.
companion/server.py = 로컬 역할/요청/사진 중계. 기본 loopback, 사진/링크 로그 및 디스크 저장 없음.
공유 UI: android/shared-ui/com/familycare/ui.
공식 SDK: Vehicle 2.3.2, NaviHelper 3.0.5, TTS 3.3.1. 지도: MapLibre 12.2.0/OpenFreeMap.
사진/지도/폰트 등 외부 고지와 SDK 조건은 docs의 THIRD-PARTY/COMPLIANCE 문서를 확인하세요.
현대/기아 로고·차량 사진·공식 UI를 복제하지 않고 코드로 직접 그린 화면과 아이콘을 사용했습니다.
