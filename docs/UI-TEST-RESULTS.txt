Family Care 0.3.0 UI 변경 안내

차량 앱: 고정 메뉴, 이동 브리핑, 가족 케어, 실제 신호 카드로 재구성했습니다.
이동 화면의 '지도 열기'는 설치된 Pleos 내비 앱을 엽니다. 앱 안의 선·차량 그림은 이동을 표현한 일러스트이며 실제 경로 지도가 아닙니다.
동승자 페이지: '우리 차 / 요청 / 확인 알림' 하단 메뉴를 추가했습니다.
요청은 '요청' 메뉴에서 보내세요. 직접 입력·장소 제안을 펼치면 기존 좌표 입력 기능을 사용할 수 있습니다.
서버와 앱 실행 방법은 동일합니다: 01 → 08 → 12 → 14. 휴대폰은 기존 13번 안내를 따르세요.

디자인: 청회색·하늘색의 독자적인 배치와 직접 작성한 차량 SVG, Canvas 도형, CSS 아이콘을 사용했습니다.
기아·현대 로고, 공식 앱 이미지/스크린샷, 특정 차종 렌더링, 전용 폰트, 지도 타일을 번들하지 않았습니다.
기존 SDK와 오픈소스 고지는 유지했습니다. 자세한 제작 기록은 UI-디자인출처.txt 또는 저장소 docs/DESIGN-PROVENANCE.md를 보세요.

검증: debug·unsigned release 빌드 성공. Android UI·차량 통합 4개, 실제 웹 요청 시연 1개, 서버 8개 통과.
최종 아이콘과 앱 영역 캡처 변경 후 화면 전환 시험 1개를 추가 재실행해 통과했습니다.
수동으로 '지도 열기'에서 설치된 내비 앱 전환도 확인했습니다.
실제 동승자 요청 → 차량 확인 → 웹 확인 완료 동작을 확인했습니다.
주행 제한 시 상세 메뉴·QR·조작을 숨기는 기존 동작을 유지합니다.
