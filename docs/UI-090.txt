Family Care 0.9.0 — 화면 변경 및 검증
2026-10-27

적용한 화면
1. 차량: 전체 지도, 하단 목적지 입력·가족/추억/차량/이동 바로가기, 우측 2D/3D·확대/축소·알림 버튼.
2. 내 차: 흰색/남색 화면, 사실적인 차량 예시, 상태 요약, 공조/가족/시동/잠금 버튼.
3. Family Care: 같은 색상과 차량 예시, 시원하게/따뜻하게/음악 줄이기/휴식 요청을 첫 화면에서 확인.
4. 웹: 같은 색상과 차량 이미지. 웹은 보조 연결/요청 화면이며 설치 앱 전체 기능과 동일하지 않습니다.

조작
차량 지도 → 아래 ‘어디로 갈까요?’ 또는 지도 터치 → 위치 선택 → 이곳으로 안내.
검색어로 장소를 찾으려면 ‘차량에서 검색’을 누릅니다. 이름 입력만으로 주소 검색이 되지는 않습니다.
2D/3D 버튼은 실제 지도 기울기를 바꿉니다. ‘42dot 기준 위치’는 기준점으로 복귀하며 실시간 GPS가 아닙니다.
Family Care/하단 가족·추억·차량 버튼으로 기존 기능에 바로 접근합니다.
동승자 온도 변경은 요청 → 운전자 승인 후 실행합니다. 시동/문 잠금은 API 연동 준비 단계입니다.

검증 결과
- 차량·내 차·Family Care debug APK 0.9.0 빌드와 에뮬레이터 설치 성공.
- 차량 DrivingUiTest 3개 통과: 홈 접근, 좁은 화면, 주행 제한.
- MapNavigationTest 1개 통과: 지도 목적지를 Pleos로 전달하고 실제 안내 모드/좌표 확인 및 테스트 경로 취소.
- MemorySharingTest 1개 통과: 합성 사진 공유 → 지도 마커 → 미리보기/추억 → 삭제 반영.
- 내 차·Family Care PhoneFlowTest 각 1개 통과: 연결·요청·결과·손님 제한.
- Python 서버 단위시험 8개 통과. 새 차량 이미지 HTTP 200, 브라우저 표시 확인.
- 작은 휴대폰 레이아웃에서 네 개 요청 버튼 표시, 차량 지도 우측 버튼 글자 표시 확인.
초기 테스트의 기존 스크롤 가정과 팝업 캡처 방식, 지도 비동기 렌더 대기를 수정한 후 통과했습니다.

실제 휴대폰/실차 검증, 자동 GPS, 자체 경로선, 시동·문 잠금은 이번 UI 변경의 완료 범위가 아닙니다.
기본 Pleos 내비 자체의 빈 지도 문제는 별개입니다. 새 화면은 우리 차량 앱에서 실행합니다.
서버 재시작 후 이전 연결 링크는 만료됩니다. 차량에서 새 QR/링크를 열어 다시 연결하세요.
