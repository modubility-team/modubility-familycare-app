시험 조건과 해석
- 에뮬레이터 콘솔에서 공개 시험 좌표를 주입했습니다. 실제 차량 GPS 안테나/도로 주행 시험이 아닙니다.
- 주행 위치는 경로의 좌표를 빠르게 재생했습니다. 화면에 모의 위치임을 표시합니다.
- 에뮬레이터는 마지막 위치를 반복 전송하므로 GPS 끊김 시험은 위치 수신을 잠시 중단해 수행했습니다.
- 초기 확대 시험은 화면의 1초 갱신 대기와 긴 경유지 경로 재생 시간을 반영하지 않아 실패했습니다.
  해당 시험 조건을 보완한 뒤 통과했습니다.
- 음성은 SDK 완료와 AudioTrack 재생 진행을 검증했습니다. 사용자의 실제 스피커 청취 확인은 별개입니다.
- 휴대폰 화면 시험도 에뮬레이터입니다. 물리 휴대폰/실차 확인은 남아 있습니다.
- 기본 Pleos 내비의 빈 지도는 GPU 비교/재부팅 뒤에도 미해결입니다. 해결된 것으로 표시하지 않습니다.
- 실시간 교통/차로/단속/오프라인/주소 검색은 포함하지 않습니다.
