Family Care 0.6.0 — 화면과 동선 개선 / 2026-10-27

디자인 기준
사용자가 제공한 상용 앱 사진은 큰 상태 숫자, 아이콘과 짧은 버튼 이름,
단순한 메뉴라는 원칙만 참고했습니다. 사진·제조사 로고·차량 이미지·아이콘 파일은
프로젝트에 복사하지 않았습니다. 공통 아이콘은 Compose Canvas로 직접 그렸습니다.
스마트폰: 흰 배경, 진한 글자, 선명한 파란 버튼. 차량: 검정·회색 바탕과 흰 글자.

빠르게 사용하는 법
① 차량
- 첫 화면: 내비게이션 / 이동 시작·종료 / 요청 확인 / 동승자 연결.
- 내비게이션을 누르면 실제 설치된 Pleos 내비로 이동합니다.
- 요청 확인은 받은 요청을 먼저 보여줍니다. QR은 QR 보기로 펼칩니다.
- 첫 화면의 동승자 연결은 공유 내용을 확인한 뒤 QR로 이동합니다.
- 차량 탭에서 한국어 알림 시험·상태 확인·확인 타이머를 사용합니다.
- 차량 상세 신호는 상세 상태 보기로 펼칩니다.
- 주행 제한 중에는 이 버튼들을 숨기고 짧은 문구와 음성 안내만 유지합니다.

② 스마트폰 길안내
- 하단 메뉴: 이동 / 장소 / 요청.
- 첫 화면의 목적지 찾기로 장소 입력을 엽니다.
- 휴식 요청은 첫 화면에서 한 번에 보냅니다.
- 저장 장소를 누르면 장소 이름과 좌표가 제안 화면에 채워집니다.
- 지도 검색은 설치된 지도 앱을 엽니다. 차량에 제안할 정확한 좌표는 별도로 입력합니다.

③ 스마트폰 케어
- 하단 메뉴: 홈 / 요청 / 알림.
- 홈에서 온도·배터리·문/창문 상태를 확인합니다.
- 홈의 시원하게 / 따뜻하게 / 음악 줄이기 / 휴식 요청으로 바로 요청합니다.
- 요청 화면에는 직접 쓰기와 처리 내역이 있습니다.
- 공조/음악 버튼은 운전자에게 보내는 요청이며 자동 차량 제어가 아닙니다.

연결
두 스마트폰 앱 모두 오른쪽 위 연결 또는 연결됨 버튼을 누릅니다.
연결 링크 입력 → 정보 확인하고 연결. 새 링크는 확인 전까지 기존 연결을 바꾸지 않습니다.
연결 관리에서 다른 앱으로 연결을 넘길 수 있습니다.
앱을 업데이트하면 메모리에 있던 연결이 끊길 수 있으므로 새 QR로 연결하세요.

웹 동승자 화면 보완 / 2026-10-27
설치형 UI만 먼저 변경되어 웹에 이전 디자인이 남아 있던 문제를 수정했습니다.
- 케어 앱과 같은 흰 바탕·검정 상태 카드·선명한 파란 아이콘.
- 큰 차량 그림과 상단 앱 실행 배너 대신 온도·배터리와 빠른 요청 4개를 먼저 표시.
- 홈 / 요청 / 알림 메뉴. 직접 입력·목적지 제안은 요청에서 바로 사용.
- 오른쪽 위 연결됨 → 연결 관리. 설치된 앱으로 열기는 이곳에서 펼칩니다.
- 상단 WEB과 하단 설명으로 웹 화면임을 구분합니다.
- 웹은 동승자용 통합 화면입니다. 차량/길안내/케어 설치형 앱 전체를 브라우저에서 실행하는 것은 아닙니다.
- 서버를 실행하고 기존 웹 페이지를 새로고침하면 적용됩니다. APK 재설치는 필요 없습니다.

웹 보완 검증
- 서버 단위/HTTP 보안 시험 8개 통과, JavaScript 문법 검사 통과.
- 별도 로컬 시험 연결에서 홈 요청, 목적지 제안, 운전자 확인 결과 수신 확인.
- 손님: 장소 제안 비활성. 상태 확인 전용: 요청 메뉴·빠른 요청 숨김.
- 확인 알림 수신/직접 확인, 연결 해제 후 링크 입력으로 재연결 확인.
- 차량 응답이 끊기면 온도·배터리·주행·도착 정보를 미확인으로 표시.
- 현재 웹 화면에서는 실제 에뮬레이터 연결과 네 개 요청 버튼의 표시를 확인했습니다.
- UI-web-care.png는 연결된 에뮬레이터의 웹 화면입니다. 실차 측정값이 아닙니다.
