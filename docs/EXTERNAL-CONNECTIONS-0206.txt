WithME — 다른 Wi-Fi / LTE·5G 연결 사용법
연결 도구 업데이트: 2026-11-06 / 0.20.6
차량 APK 0.20.5 · 소유자/가족 APK 0.20.4 · 태블릿 APK 0.20.0 유지

1. 처음 켜는 순서
기존 시연 실행 파일로 노트북의 차량 에뮬레이터와 시연 보조 프로그램을 켭니다.
노트북에서 http://127.0.0.1:8770/#externalConnection 을 엽니다.
차량 연결 및 공유가 준비되면 ‘다른 Wi-Fi · LTE·5G 연결’의 ‘외부 연결 시작’을 누릅니다.
‘외부 연결 준비 완료’가 나오고 QR 두 개가 나타날 때까지 기다립니다.
휴대폰 카메라로 ‘외부 연결’ 영역의 소유자 또는 동승자 QR을 찍습니다.
연결 페이지에서 ‘설치한 앱에서 연결’을 누른 뒤 앱에서 차량에 연결합니다.
이번 변경은 노트북 연결 도구 변경이므로 위 APK 버전을 설치했다면 앱 재설치는 필요 없습니다.

2. 픽업 시험
소유자 휴대폰은 외부 연결 소유자 QR로, 동승자 휴대폰은 외부 연결 동승자 QR로 연결합니다.
소유자 앱에서 기존 픽업 위치 공유를 켭니다.
동승자 앱의 ‘타기 전 픽업’에서 차량 위치를 확인하고, 본인 위치 권한을 허용합니다.
기다리는 가게/건물과 추가 설명을 입력하고 픽업 요청을 보냅니다.
차량에서 요청과 음성 안내를 확인하고 픽업을 경유지로 반영합니다.
두 휴대폰은 서로 다른 Wi-Fi나 LTE·5G여도 됩니다. 노트북은 인터넷이 연결되어 있어야 합니다.
자동 주행과 현재 위치 지정, 기존 지도·길안내, 좌석별 권한과 승인 흐름은 그대로입니다.

3. 연결 종류 선택
‘같은 Wi-Fi’ QR: 기존 방식. 노트북과 휴대폰이 같은 네트워크여야 합니다.
‘외부 연결’ QR: 새 방식. 서로 다른 네트워크에서 연결할 때 사용합니다.
태블릿의 차량 화면 전송 및 IP 카메라 주소 연결은 기존 같은 Wi-Fi 방식을 유지합니다.
이 기능은 휴대폰 연결 서버만 외부에 연결하며 시연 보조·차량 콘솔·태블릿 화면 서버는 공개하지 않습니다.

4. 종료와 재연결
‘외부 연결 종료’를 누르면 외부 접속만 끝납니다. 기존 같은 Wi-Fi 연결은 유지됩니다.
외부 연결을 다시 시작하면 주소가 바뀌므로 새 QR을 다시 찍어야 합니다.
노트북을 끄거나 절전 모드로 두면 외부에서도 사용할 수 없습니다.
시연 보조 프로그램 종료 시 외부 연결도 종료합니다. 비정상 종료 시에도 약 60초 내 자동 종료합니다.
연결 서버 프로세스가 강제 종료되면 연결 도구도 함께 종료하도록 구성했습니다.

5. 접속이 안 될 때
시연 보조에서 차량 연결·공유 준비가 되었는지 먼저 확인합니다.
외부 주소가 처음 만들어질 때 DNS 반영이 늦을 수 있습니다.
접속 확인 시간 초과가 나오면 인터넷 연결을 확인한 뒤 ‘외부 연결 시작’을 다시 누릅니다.
기존 QR 대신 현재 표시되는 외부 QR을 사용합니다.
회사/학교/공용 Wi-Fi에서 터널 통신을 차단하면 다른 인터넷 연결에서 시험합니다.
휴대폰 브라우저는 열리지만 앱 연결이 안 되면 앱을 최신 배포 APK로 업데이트합니다.

6. 비용과 접근 범위
Cloudflare Quick Tunnel은 무료 개발·시연용 임시 연결입니다. 계정·도메인을 만들 필요가 없습니다.
지도 API의 기존 무료 한도 및 휴대폰 데이터 요금은 별개입니다.
지속 운영을 보장하는 서비스가 아니며 동시 처리 중인 요청 200개 제한과 SSE 미지원 조건이 있습니다.
우리 앱의 HTTP 요청 방식과 시연 규모에 맞춰 연결했습니다.
휴대폰과 Cloudflare 사이는 HTTPS이며, Cloudflare가 노트북의 연결 서버로 중계합니다.
기존 역할 토큰·기기 연결·권한 승인은 유지됩니다. QR에는 연결 권한이 있으므로 참여자에게만 공유합니다.
외부 경로에서는 차량 전용 토큰, 세션 생성, 연결 시작/종료 관리 API를 차단합니다.
