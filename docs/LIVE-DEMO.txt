Family Care 0.13.0 · 바로 시연하는 법

1. 공모전 폴더의 26_시연조종석켜기.cmd 실행.
2. 현재 위치 고르기 → 지도 클릭/검색 → 선택한 현재 위치 적용.
3. 목적지 고르기 → 지도 클릭/검색 → 선택한 목적지로 길찾기.
4. 실제 경로 확인 → GPS 주행 시작. 정차가 필요하면 P단 정차.
5. 공조·타이머·사진·장소 제안은 설치 앱에서 직접 조작.
6. 이동 종료 후 뒷좌석 확인. 종료 도구는 28_GPS시연종료.cmd.

고정 서울 경로·합성 사진·타이머 바로가기는 제거했습니다.
휴대폰 앱은 0.13.0 ZIP 또는 최신 앱설치파일 폴더로 업데이트하세요.
