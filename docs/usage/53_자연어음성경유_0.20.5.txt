WithME · 자연어 음성 경유 사용법 (차량 0.20.6, 휴대폰 0.20.6)
2026-11-08

이번 변경
가족이 보낸 목적지·경유지·픽업 요청을 운전자가 자연스러운 말로 경유하도록 승인합니다.
단어를 정확히 외워 말할 필요 없이 노트북의 문장 이해 모델이 경유 의도를 분류합니다.
원래 최종 목적지를 유지하고 경유 경로를 다시 계산하며, 시작한 길안내도 이어집니다.

바로 시연하는 순서
1. 노트북의 시연 보조 화면 http://127.0.0.1:8770/ 을 여세요.
   휴대폰은 같은 Wi-Fi에 연결하고 새 WithME 가족 QR로 다시 연결하세요.
2. WithME 가족 → 권한 → 좌석 선택 → 길안내 권한을 요청하고 차량에서 승인하세요.
3. 차량 내비에서 최종 목적지를 검색하고 경로 선택 → 안내 시작을 누르세요.
   노트북 보조 화면에서 ‘GPS 주행 시작’을 눌러 주행 상태를 만드세요.
   주행 중 받은 장소 제안은 운전자의 처리를 기다리므로 음성 경유를 확인하기 좋습니다.
4. 휴대폰 WithME 가족 → 홈 ‘장소 제안’ 또는 ‘쉬어 갈 곳 찾기’.
   장소를 검색해 결과를 선택 → ‘차량에 장소 제안’을 누르세요.
   임의로 입력한 이름만으로는 위치를 만들지 않으며 검색에서 받은 좌표를 사용합니다.
5. 차량 화면 아래 ‘음성 명령’ → ‘말하기’를 누르고 아래처럼 말하세요.
   - 추천지를 경유해 줘.
   - 가족이 보내준 데 잠깐 찍고 가자.
   - 추천해 준 장소를 일정 중간에 추가해 줄래.
   - 아까 얘기한 장소를 들르는 걸로 경로 바꿔.
   - 픽업하러 들렀다가 최종 목적지로 가자. (픽업 요청이 있을 때)
6. 후보가 여러 개면 번호와 장소를 읽어 줍니다.
   다시 ‘말하기’를 누르고 ‘두 번째’ 또는 표시된 장소 이름을 말하세요.
   후보를 고르기 전 ‘승인’만 말해도 임의로 첫 장소를 선택하지 않습니다.
7. 경유 경로 계산 후 완료 음성과 결과를 확인하세요.
   경유지가 추가되었는지, 최종 목적지가 원래 장소인지 확인하면 됩니다.

동작 범위와 다시 묻는 경우
- 항상 듣는 기능이 아닙니다. ‘말하기’를 누른 뒤 말씀하세요.
- 현재 연결에서 도착한, 아직 처리하지 않은 장소 제안/픽업 요청을 대상으로 합니다.
- 현재 한 번에 검토하는 후보는 최대 5곳입니다. 특정 요청을 고르면 해당 요청을 우선합니다.
- 정차 중에 길안내 권한으로 이미 자동 반영된 제안은 음성 승인 대기 목록에 남지 않습니다.
- 최종 목적지가 없으면 해당 장소 자체로 안내 경로를 준비합니다.
- 현재 남겨 둘 수 있는 경유지는 1곳입니다. 다른 경유지가 남아 있으면 덮어쓰지 않고 안내합니다.
- ‘들르지 마’, 단순 질문, 여러 행동을 섞은 문장, 알 수 없는 장소는 실행하지 않거나 다시 묻습니다.
- 해석이 불확실하면 다시 묻습니다. 모든 자유 대화를 이해하는 범용 대화형 AI는 아닙니다.
- 말하는 사이 요청/경로가 바뀌거나 연결이 끊기면 이전 판단으로 경로를 바꾸지 않습니다.
- 장소를 다시 고르는 답변은 60초 안에 해 주세요. 시간이 지나면 처음부터 다시 요청하세요.

설치와 비용
- 이 노트북 차량 앱과 휴대폰 내 차 관리/WithME 가족 앱은 0.20.6입니다.
  기존 앱이 0.20.6보다 낮으면 새 APK로 업데이트하세요.
- `android\pleos-stt.local.properties`를 열고 Pleos Playground My Project의 Client ID와 Client Secret을 입력한 뒤 APK를 다시 빌드하면 HYBRID 음성 인식을 우선 사용합니다. 값이 비어 있으면 기존 기기 내 인식이 계속 동작합니다.
- HYBRID는 운전자가 ‘말하기’를 누른 동안의 음성을 Pleos Speech로 보낼 수 있습니다. 앱은 녹음을 저장하지 않습니다. 서버 등록/인식에 실패하면 기기 내 엔진으로 전환합니다. 인식 문장은 기존 차량-노트북 연결로 전달되어 메모리에서 요청 뜻을 처리합니다.
- 노트북의 E5 말뜻 해석에는 외부 AI API 키가 필요하지 않습니다. Pleos Speech 사용은 Pleos 계정과 서비스 약관을 따릅니다.
- Client Secret은 빌드된 Android 앱에서 숨겨 둘 수 없습니다. Client ID/Secret을 넣고 빌드한 APK는 신뢰하는 시연자에게만 전달하세요.
- 지도/경로 계산은 기존 TMAP 인터넷 연결과 계정 한도를 그대로 사용합니다.
- 모델은 APK나 휴대폰 ZIP에 포함하지 않습니다. 이 노트북에는 설치해 두었습니다.
- 친구의 다른 노트북에서는 Python 3.12 설치 후 다음 파일을 한 번 실행하세요.
  team-project\scripts\windows\Setup-VoiceUnderstanding.ps1
  모델 첫 설치에는 인터넷이 필요합니다. 모델과 전용 실행환경은 dist\voice-runtime에 저장됩니다.

검증한 내용
- Android 단위 테스트 75개, 서버 테스트 127개 통과.
- 기존 기기 내 음성 경로의 테스트는 통과했습니다. 이 PC에는 Pleos Client ID/Secret이 없어 HYBRID 서버 등록과 실제 HYBRID 품질은 아직 확인하지 못했습니다.
- 추천지 2곳에서 번호 선택, 부정 표현 차단, 애매한 승인 차단, 바뀐 경로에 늦은 해석 적용 차단 확인.
- 원래 최종 목적지와 주행 중 안내 유지, 차량 음성 화면 표시 확인.
- 음성 입력 시험에는 생성한 한국어 음성 파일을 SDK에 넣었습니다.
  실제 노트북/탭 마이크의 수음 상태는 ‘말하기’로 직접 확인해 주세요.
