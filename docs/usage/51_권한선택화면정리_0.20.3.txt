WithME 0.20.3 · 권한 선택 화면 정리 · 2026-11-01

업데이트
- 이번 변경은 WithME 가족의 권한 선택 화면입니다.
- 03_FamilyCare-케어-debug.apk를 열어 기존 앱 위에 업데이트로 설치하세요.
- 내 차 관리 앱도 같은 버전의 설치 파일을 함께 넣어 두었습니다.
- 0.20.2에서 연결을 저장했고 차량 연결이 아직 유효하면 다시 열 때 복원됩니다.
- 차량 연결이 이미 종료되었다면 새 가족 QR로 연결하세요.

권한 요청 순서
1. WithME 가족 아래 ‘권한’을 누릅니다.
2. 1 좌석: 탑승 좌석과 운전자에게 표시할 이름을 정합니다.
3. ‘다음 · 기능 선택’을 누릅니다.
4. 2 기능: 필요한 분류를 눌러 펼칩니다.
   - 온도·바람: 설정 온도, 공조 전원, 에어컨, 풍량 등
   - 시트·열선: 내 좌석과 열선 조절
   - 문·창문: 문 잠금과 창문 개방 정도
   - 길안내: 목적지·경유지 변경
   - 가족·반려동물 케어: 상황별 케어, 확인 타이머, 가족 설정, 공조 보조
   실제로 연결된 차량과 선택한 좌석에서 지원하는 항목만 표시됩니다.
   새 차량에서 추가 기능을 제공하면 ‘기타 차량 기능’에 표시됩니다.
5. 필요한 기능만 체크합니다. 한 번에 한 분류만 펼쳐집니다.
6. 온도·창문 등의 세부 범위를 정하려면 해당 항목 아래 ‘허용 범위 … 변경’을 누릅니다.
   범위를 바꾸지 않으면 표시된 전체 허용 범위로 요청합니다.
7. ‘다음 · 선택한 N개 확인’을 눌러 선택한 권한과 허용 범위만 확인합니다.
8. ‘운전자에게 N개 권한 요청’을 누릅니다.
9. 차량에서 운전자가 승인하면 승인된 좌석·기능·범위만 사용할 수 있습니다.

수정·해제
- ‘좌석 변경’으로 좌석을 바꾸면 이전 좌석에서 고른 항목을 비웁니다.
- ‘선택 모두 해제’는 작성 중인 선택만 비웁니다. 이미 승인된 권한은 운전자가 회수합니다.
- 마지막 확인 화면의 ‘선택 수정’으로 돌아가도 고른 항목은 유지됩니다.
- 권한을 다시 승인받으면 기존 승인 목록을 새 목록으로 바꿉니다.
- 차량 공용 기능과 P단 정차가 필요한 기능은 각 항목에 표시합니다.
- 실제 사용 권한과 운전자 승인 절차는 기존과 같습니다.

검증
- 에뮬레이터에서 분류별 표시, 범위 펼치기, 좌석 변경 시 선택 초기화, 선택 모두 해제를 확인했습니다.
- 확인 화면에서 돌아가도 선택이 유지되고, 실제 요청에는 고른 좌석·권한·범위만 전달됩니다.
- 승인 전에는 제어할 수 없고, 운전자 승인 후 고른 기능만 허용되는 것을 확인했습니다.
- 0.20.2의 백그라운드 연결 유지 기능도 포함되어 있습니다.
