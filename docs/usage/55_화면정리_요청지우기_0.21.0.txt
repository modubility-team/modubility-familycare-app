WithME 0.21.0 · 차량 화면 정리와 요청 지우기 · 2026-11-11

무엇이 바뀌었나
- 요청 탭이 ‘확인 대기’와 ‘처리됨’ 두 묶음으로 나뉩니다. 각 묶음 옆에 개수가 보입니다.
- 요청마다 종류 아이콘(픽업·경로·온도·차량·한마디·권한 등)과 상태 칩(확인 대기/처리 중/완료/보류)을 붙였습니다.
- 처리된 요청은 한 줄로 줄어들고, 오른쪽 휴지통 버튼으로 하나씩 지울 수 있습니다.
  ‘처리됨’ 제목 옆 ‘모두 지우기’로 한꺼번에 지웁니다. 확인 대기·처리 중인 요청은 지울 수 없습니다.
- 지우기는 차량 화면 정리용입니다. 휴대폰과 연결 서버의 기록은 그대로이며, 차량 연결을 새로 시작하면 목록이 처음부터 다시 받아집니다.
- 위도·경도 숫자와 긴 안내 문장을 없애고, 아이콘이 붙은 한 줄 안내로 바꿨습니다.
- 승인 버튼은 아이콘+짧은 이름(예: 픽업 경유지 추가, 온도 적용, 경로 찾기)으로, 보류는 옆 버튼으로 둡니다.
- 동승자 연결 카드: 상태 한 줄 + ‘QR 보기’ ‘모두 연결 종료’ 버튼.
- 동승자 권한 관리: 스위치 목록 대신 칩(가족/손님/상태 확인, 도착 알림/케어 알림)과 ‘회수’ 버튼.
- 목적지 선택: 경로 옵션은 한 줄로 접어 두고 ‘변경’을 눌러 펼칩니다. 장소 저장은 집·회사·★ 칩,
  보조 기능(저장·최근 / 기준 위치 / 차량 검색 / 기본 내비로)은 아이콘 타일 4개로 모았습니다.
- 지도 위 상황별 케어 표시를 아이콘 + 두 줄로 줄였고, 측면 메뉴의 FD 표시는 WithME로 바꿨습니다.

확인 방법
1. 02_StartDemo.cmd → 가족 앱에서 요청 2~3개 보내기 → 차량 ‘WithME 가족’ 버튼.
2. 하나는 승인, 하나는 보류 → ‘처리됨’ 묶음으로 이동하는지 확인.
3. 휴지통 버튼으로 하나 지우기, ‘모두 지우기’로 나머지 지우기.
4. 새 요청이 오면 ‘확인 대기’에 다시 나타나는지 확인.
