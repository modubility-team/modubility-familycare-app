WithME 0.20.4 · 새 기능 확인 방법
2026-11-02

휴대폰 업데이트
- 03_FamilyCare-케어-debug.apk: 동승자 WithME 가족 앱
- 02_FamilyCare-내차관리-debug.apk: 차량 소유자 앱
- 기존 앱을 삭제하지 말고 같은 파일을 열어 업데이트하세요.
- 차량 연결이 종료되었으면 시연 보조 화면의 새 QR로 다시 연결하세요.
- 차량 앱은 노트북 에뮬레이터에 업데이트합니다. 휴대폰에 차량 APK를 설치하지 마세요.

1. 추억 장소를 검색으로 선택
WithME 가족 → 추억 → 추억 더하기 → 사진 선택 → 추억 장소 검색.
가게·관광지 이름 또는 주소를 입력하고 ‘검색’을 누른 뒤 결과를 선택하세요.
사진의 촬영 위치가 있으면 초기 위치로 유지하며, 검색 결과를 골라 바꿀 수 있습니다.
사진에 위치가 없으면 검색으로 장소를 지정한 뒤 공유하세요.
차량 앱의 추억 추가 화면도 같은 검색 방식을 사용합니다.

2. 픽업 장소를 경유하고 원래 목적지까지 안내
소유자가 픽업 위치 공유를 켜고, 동승자가 WithME 가족의 ‘타기 전 픽업’에서
현재 위치를 확인한 뒤 기다리는 가게·상가와 메모를 보내세요.
차량에 최종 목적지가 있으면 승인한 픽업 위치를 경유지로 추가합니다.
주행 중 안내는 새 경로가 준비되면 계속 이어집니다. 최종 목적지를 바꾸지 않습니다.
차량 → 음성 명령 → 표시된 픽업 요청 확인 → 말하기 → ‘픽업 경유해 줘’.
새 픽업 요청을 우선 표시합니다. 다른 요청이 선택되어 있으면 ‘다음 요청’으로 고르세요.
‘승인’도 선택된 요청에 적용됩니다. 다른 요청이 표시된 상태에서 픽업 명령을 말해도
그 요청을 임의로 승인하지 않습니다. 마이크 버튼을 누른 동안만 인식합니다.
최종 목적지가 없으면 픽업 장소 자체를 목적지로 설정합니다.
제한: 현재 경유지는 한 곳입니다. 다른 경유지가 남아 있으면 덮어쓰지 않고 안내합니다.
기존 경유지를 마치거나 경로 설정에서 제외한 후 픽업을 다시 승인하세요.

3. 권한 모두 추가
WithME 가족 → 권한 → 좌석 선택 → 다음 · 기능 선택 → 모두 추가.
해당 좌석과 연결 차량이 지원하는 항목만 선택됩니다.
각 분류 안의 ‘이 분류 모두 추가’로 그 분류만 더할 수도 있습니다.
선택한 항목 확인 → 운전자에게 권한 요청 → 차량에서 승인 순서입니다.
‘모두 추가’는 선택을 돕는 버튼이며 운전자 승인이나 정차 조건을 생략하지 않습니다.

4. 홈에서 기능으로 바로 이동
‘쉬어 갈 곳 찾기’ → 요청 화면의 장소 검색으로 이동하며 경유지·휴게소가 선택됩니다.
‘장소 제안’ → 요청 화면의 목적지 검색으로 이동합니다.
‘가족 투표’ → 제안된 장소와 투표·처리 결과가 있는 위치로 이동합니다.

5. 조작 결과를 화면 위에서 확인
예: ‘조수석 22°C · 적용 대기’ → 차량 확인 후 ‘조수석 22°C · 반영 완료’.
창문은 ‘50% 열기’, 잠금은 ‘잠금 / 잠금 해제’처럼 선택한 값을 표시합니다.
거절되면 ‘적용 안 됨’, 결과가 불확실하면 ‘결과 미확인’으로 표시합니다.
아래쪽으로 스크롤해도 위쪽 안내는 보이며 ‘닫기’로 지울 수 있습니다.

실제 도로 모양·차선·교차로 SDK 조사

사진 속 왼쪽 차량 주행 화면은 Pleos 시스템 영역입니다. 우리 앱의 지도 화면과
별개의 프로그램이며, 현재 확인한 공개 API에서 그 화면의 도로 모형을 교체하거나
차선 형상을 입력하는 방법은 확인하지 못했습니다. 이번 버전에서 이 영역을 바꾸지는 않았습니다.

A. TMAP Vector Map SDK
현재 앱이 사용하는 지도 계열로 실제 도로·교차로 지도와 경로 좌표를 표시하는 데 적합합니다.
지도 표시만으로 차량 주변 차선을 정확한 3D 도로 모형으로 재현할 수 있다고 보장되지는 않습니다.
https://tmapapi.tmapmobility.com/main.html#androidVSM/guide/androidGuide.sample1

B. TMAP Navi SDK
TMAP 내비 엔진과 UI를 앱에 포함하는 별도 SDK입니다.
공식 안내에 제휴 협의로 사용 한도가 반영되어야 이용할 수 있다고 명시되어 있습니다.
현재 무료체험 지도 키가 이 SDK 이용 권한까지 포함한다는 근거는 확인하지 못했습니다.
계정 요금제 변경이나 유료 서비스 신청은 하지 않았습니다.
https://tmapapi.tmapmobility.com/main.html#androidUISDK/guide/androidGuide.sample1

C. TMAP EDC SDK
TMAP의 주행 정보를 다른 앱에 제공하고 TMAP을 제어하는 SDK입니다.
차선 수, 차선 안내 지점까지 거리, 차선별 회전 방향·권장 여부, 복잡 교차로 이미지를
전달하는 항목이 공식 문서에 있습니다. SDK 인증과 호스트 연동이 필요합니다.
이 자료는 차선 안내에 유용하지만, 모든 도로의 차선 경계 좌표·폭·곡률을 제공하는
정밀 3D 도로 지도라고 해석해서는 안 됩니다. 현재 앱에 EDC를 연결한 상태는 아닙니다.
https://tmapapi.tmapmobility.com/main.html#androidEDCSDK/guide/androidGuide.sample1
https://tmapapi.tmapmobility.com/main.html#androidEDCSDK/docs/androidDoc.RGData_laneInfo

D. Pleos ADAS 관련 문서
기존 ADAS/LocalMap 문서 경로는 현재 페이지 없음으로 응답했습니다.
설치된 프로젝트에도 ADAS 라이브러리는 포함되어 있지 않습니다.
해당 SDK의 현행 제공 여부·에뮬레이터 데이터·시스템 화면 수정 가능 여부는 추가 확인이 필요합니다.
https://document.pleos.ai/api-reference/connect-sdk-pleos/Adas/adas/ai.pleos.playground.adas.model.localmap/entry

권장 방향
지금은 우리 앱의 실제 TMAP 지도와 경로 안내를 사용하세요.
상용 수준의 차선 안내까지 확장하려면 TMAP Navi 또는 EDC 이용 권한을 먼저 확인하는 것이 좋습니다.
사진 속 Pleos 왼쪽 화면의 실제 도로 재현은 이들과도 별도로 시스템 확장 가능 여부 확인이 필요합니다.


이번 변경 검증 결과
- 차량 로직 자동 테스트 75개, 서버 자동 테스트 110개 통과.
- 에뮬레이터의 실제 WithME 가족 화면에서 전체·분류 선택, 좌석 변경, 승인 전 차단,
  승인 후 허용, 세 가지 홈 바로가기, 상단 결과 표시, 거절 결과 표시 확인.
- 실제 TMAP 장소 검색 결과를 눌러 추억 위치 좌표 선택 확인.
- 실제 TMAP 경유 경로 계산과 최종 목적지 유지, D단 안내 지속 확인.
- 생성한 한국어 시험 음성을 Pleos 음성 인식기에 넣어 ‘승인해 줘’ 인식과 픽업 처리 확인.
- ‘픽업 경유해 줘’ 명령은 인식 결과 처리 경로를 통해 경유 추가 확인.
- 기존 경유지 보호와 목적지가 없는 경우의 픽업 안내 확인.
- 실제 휴대폰에 이번 APK를 설치한 뒤의 조작 및 사용자의 실제 마이크 발화는 별도 확인이 필요합니다.
