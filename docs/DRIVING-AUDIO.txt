Family Care 차량 0.5.1 — 주행 중 한국어 음성 알림 / 2026-10-27

바뀐 점
기존 버전에는 화면 알림만 있었고 차량 알림 소리 기능이 없었습니다.
이제 주행 제한이 활성화되어도 짧은 한국어 음성과 간단한 문구로 알립니다.
음성 초기화/재생 실패 또는 응답 지연 시에는 직접 만든 알림음으로 전환합니다.
상세 요청 목록·QR·설정·확인/내비 전달 버튼은 정차 후에만 사용할 수 있습니다.
알림 소리가 난 것과 요청을 승인한 것은 다릅니다. 요청은 확인 대기로 유지됩니다.

대상
- 동승자 휴식/공조/음악 요청, 목적지·경유지 제안 도착
- 확인 타이머, 설정한 온도·배터리 기준, 신호 미확인, 뒷좌석 확인
- 휴식 제안, 급가속·급감속·급조향 피드백
임의로 입력한 요청 내용이나 장소명은 읽지 않고 일반적인 안내 문장으로 바꿉니다.

소리 시험
1. 가상 차량을 P단으로 둡니다.
2. 차량 앱의 차량 → 주행 알림 → 알림 소리 시험을 누릅니다.
3. 휴대폰을 새 가족 QR로 다시 연결합니다.
4. Virtual Console에서 D단으로 전환합니다. 차량 상세 화면이 제한됩니다.
5. 휴대폰 케어 → 홈 → 휴식 요청을 누릅니다.
6. 차량의 “동승자가 휴식을 요청했어요” 한국어 음성과 짧은 문구를 확인합니다.
7. P단으로 돌아와 차량 요청 메뉴에서 확인합니다.
연속 안내는 최소 15초, 운전 피드백은 최소 30초 간격입니다.
같은 상태가 계속되면 반복하지 않고, 상태가 해소 후 다시 발생해도 2분 이내 재알림을 억제합니다.
포커스가 거부된 동승자 요청은 수신 후 1분까지만 재시도합니다.

음성 지원 범위
Pleos TextToSpeech SDK 3.3.1, Mode.ON_DEVICE, Locale.KOREA를 사용합니다.
Pleos 2.1 에뮬레이터에서 초기화 성공 → onStart → onDone, 오류 없음으로 확인했습니다.
이 모드는 서버 합성용 앱 등록/인증키와 네트워크가 필요하지 않습니다.
차량과 휴대폰 연결 서버는 동승자 요청을 전달하는 별도 기능이므로 계속 필요합니다.
앞선 “에뮬레이터 한국어 미지원” 설명은 Android 기본 TTS 경로 시험 결과를
기기 전체로 넓혀 표현한 것이었습니다. Pleos 전용 SDK의 한국어 재생은 성공했습니다.
음성 실패·응답 지연 시에는 해당 실행 동안 알림음으로 대체합니다. 앱을 완전히 다시 실행하면 음성 초기화를 다시 시도합니다.
차량 → 주행 알림에서 소리를 끄거나 켤 수 있습니다.
기기 음량·음소거·통화·오디오 정책에 따라 실제로 들리지 않을 수 있으며,
앱이 음량을 강제로 올리거나 통화/차량 경고를 가로채지 않습니다.

오디오 정책 반영
일반 NOTIFICATION 사용, AudioFocusRequest와 AudioAttributes 적용.
재생 전 포커스 획득 확인, 포커스 거부 시 보류, 상실/일시 상실/duck 요청 시 짧은 안내 중단.
완료·오류·화면/서비스 종료 시 재생 자원과 포커스 정리.
음성 요청 앞 200ms 무음 PCM을 실제 재생합니다. Pleos 서비스는 별도 오디오 트랙을 사용하므로
실차에서 트랙 사이 연결과 음성 첫머리 잘림 여부를 추가 확인해야 합니다.
알림음 PCM 앞에도 200ms 무음과 짧은 fade를 적용합니다.
TTS_SERVICE 권한을 추가했습니다. 마이크 권한·음성 서버 인증키·외부 음성 파일은 없습니다.
앱 등록/출시 시에는 TTS_SERVICE를 포함한 사용 권한 신청·승인을 별도로 확인해야 합니다.

검증
- 차량 JVM 32개 통과(기존 24 + 새 알림 정책 8).
- lint 오류 0, 기존 경고 27.
- PleosTtsProbeTest 1개 통과: 공식 SDK의 ON_DEVICE 한국어 초기화/시작/완료, 오류 없음.
- DriverAudioTest 3개 통과: 실제 한국어 음성 완료, AudioTrack 알림음 진행/완료,
  한국어 재생 중 포커스 상실 → 중단, 늦게 도착한 중단 콜백 무시,
  시험용 음성 실패 주입 → 알림음 전환/완료.
- DrivingUiTest 2개 통과: 주행 중 상세 UI 차단 및 작은 화면 유지.
- DrivingAudioIntegrationTest 1개 통과:
  실제 Virtual Console P→D 전환으로 CarUxRestrictions가 활성화된 상태에서
  서버로 휴식 요청 수신 → 한국어 음성 완료 → 요청은 pending 유지 → P단 복귀/시험 연결 종료.
  당시 속도는 0km/h였으며 실제 주행/실차 시험이 아닙니다.
- 기존 두 음의 알림음은 사용자가 노트북에서 실제로 들었다고 확인했습니다.
- 한국어 음성은 SDK 재생 완료까지 검증했습니다. 사용자가 당시 자리를 비워 청취 여부는 미확인입니다.
- 실제 통화/긴급 경고와의 오디오 정책 조합, 실차 출력, 전원 Suspend/Resume는 추가 검증 대상입니다.
