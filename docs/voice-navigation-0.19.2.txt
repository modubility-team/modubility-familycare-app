지도 확장 · 마이크 요청 승인 사용법 — 차량 앱 0.19.2
작성: 2026-11-01

바뀐 화면
- 오른쪽을 비워 두던 지도 폭 제한을 제거했습니다.
- 회전 거리·방향·다음 회전·휴게 시설은 오른쪽 작은 카드에 표시합니다.
- 카드 아래에도 지도가 이어지며, 하단에 목적지·도로명·도착 예정·남은 시간·거리를 표시합니다.
- 차로와 신호등 등 현재 API가 주지 않는 정보는 임의로 만들어 표시하지 않습니다.

음성으로 요청 처리하기
1. 시연 보조 화면의 새 QR로 휴대폰을 다시 연결합니다.
2. Family Care에서 필요한 좌석 권한을 요청하거나 ‘휴식 요청’ 등을 보냅니다.
3. 차량 화면 아래 ‘음성 명령’을 누릅니다.
4. 표시된 요청 내용을 확인합니다. 여러 요청이 있으면 정차 중 목록에서 선택할 수 있습니다.
5. ‘말하기’를 누르고 ‘듣고 있어요’가 뜨면 말합니다.
   - ‘승인해 줘’ / ‘승인’ / ‘허용해 줘’
   - ‘거절해 줘’ / ‘보류’ / ‘승인하지 마’
   - ‘요청 읽어 줘’ / ‘다음 요청’
   - ‘다시 안내해 줘’ / ‘취소’
6. 차량 응답과 최종 처리 결과를 확인합니다. ‘승인을 전달했어요’는 아직 완료가 아닙니다.

승인 범위
- 화면에서 선택한 한 요청만 승인합니다. ‘모두 승인’과 모호한 복합 문장은 실행하지 않습니다.
- 말을 시작한 뒤 요청이 바뀌거나 다른 곳에서 처리됐다면 실행하지 않습니다.
- 좌석 권한은 표시된 좌석·기능·조절 범위 안에서 승인합니다. 범위를 바꾸려면 기존 요청 화면을 이용하세요.
- 주행 중에는 일반 요청 확인 및 허용되는 공조·온열·통풍 요청을 음성으로 처리할 수 있습니다.
- 문·창문·새 권한 부여 등은 기존 정차 조건을 유지합니다.
- 이미 좌석 권한을 승인받은 동승자의 조절은 기존처럼 승인 범위에서 자동 적용됩니다.
- 소유자 휴대폰에서 공조를 보내는 것은 기존대로 P단 정차 중에 가능합니다. 정차 때 보냈지만 출발 후 도착한 요청은 음성으로 승인할 수 있습니다.

마이크
- 노트북 마이크를 에뮬레이터의 차량 마이크로 연결했습니다.
- Pleos SpeechToText 3.3.1의 ON_DEVICE 모드로 한국어를 인식합니다.
- 별도 서버 음성 전송·녹음 파일 저장·상시 대기어 수집은 하지 않습니다.
- 버튼을 눌러 시작하며, 완료·취소·앱 이탈·15초 제한에 따라 입력을 종료합니다.
- 말하기 전에 ‘준비 중…’이 끝날 때까지 기다리세요.
- 입력이 없으면 노트북의 마이크 음소거와 Android Emulator > Extended Controls > Microphone의 입력 설정을 확인하세요.

업데이트 범위
- 차량 앱 0.19.2를 에뮬레이터에 설치했습니다.
- 휴대폰 앱 0.19.1은 그대로 사용할 수 있습니다. 이번 변경으로 휴대폰 재설치는 필요하지 않습니다.
- 차량 앱 재실행으로 연결 QR은 갱신됩니다. 공유 사진은 보관 후 복원합니다.

검증
- 차량 앱 단위 테스트 74개.
- 실제 Pleos 오프라인 음성 엔진에 합성한 한국어 음성을 전달해 ‘승인해 줘’ 인식 및 요청 승인 확인.
- 부정 표현 거절, 좌석 권한 범위 승인, 대기 공조 요청 승인 및 실제 SDK 온도 응답 확인.
- 이동 중 창문 요청 차단, 마이크 시작·종료 화면, 지도 전체 폭과 카드 아래 공간 확인.
- 사람의 목소리·주변 소음에 따른 인식률은 직접 말해 최종 확인하세요.
