반영 사항
1. PC 시연 화면에서 지도를 클릭하거나 TMAP 장소·주소 검색으로 현재 위치·목적지를 선택.
2. 현재 위치 변경 시 P단 정차, 이전 경로 해제, 실제 Android GPS 좌표 수신을 확인.
3. 위치 변경 후 ‘다시 준비’해도 방금 선택한 출발 위치 유지.
4. 고정 서울 목적지와 합성 사진·타이머 바로가기 제거. 기능은 설치 앱의 실제 흐름으로 사용.
5. TMAP의 새 목적지 경로 요청이 실패하면 이전 목적지 경로를 해제하여 잘못된 재생 방지.
6. 소유자/가족/정차 차량의 선택형 IP Webcam 화면과 직접 확인 시각 기록.
7. 차량 주행·앱 백그라운드·연결 오류·권한 회수 시 영상 표시/전달 중단.

  NavigationRequestTest: 가족 목적지·경유지 제안 → 운전자 승인 → 실제 TMAP 경로, 지원 범위 밖 새 목적지 실패 시 이전 경로 해제.
  ClimateApprovalTest: 동승자 승인 전 설정 유지, 승인 후 공조 전원/온도 반영, 제한 시간 공조 보조, 원래 값 복구.

검증하지 않은 항목 / 남은 사항
- 실제 여분의 안드로이드폰 카메라 영상은 아직 받지 않았습니다. IP Webcam 설치·서버 시작 후 표시 주소가 필요합니다.
- CameraPanelTest는 자동화 시험용 영상이며 실제 반려동물/실물 카메라 검증을 대신하지 않습니다.
- 카메라는 약 1초 간격 JPEG 화면입니다. 녹화·음성 스트리밍·짖음/이상행동 AI는 없습니다.
- 설명회는 외부 API/네트워크를 허용했으나 외부 장치 현장 반입은 명시적으로 확인하지 못했습니다.
  LOCATIONS-CAMERA-0130.txt에 근거와 주최 측 문의 초안을 포함했습니다. 문의는 전송하지 않았습니다.
- 국내 TMAP 자동차 도로 지원 범위의 길찾기입니다. 모든 세계 좌표·바다·사유지 진입을 보장하지 않습니다.
- 실제 주행 GPS·차량/휴대폰 기종별 장시간 실행·전원 OFF 후 동작은 별도 실물 검증 대상입니다.
- Pleos 융합 위치 SDK 초기화 실패 시 Android GPS를 사용하며 이번 GPS 시험도 Android 위치 수신을 확인했습니다.
- Pleos 기본 내비 지도 문제는 이 변경과 별개입니다. 우리 차량 앱은 TMAP 지도를 사용합니다.
- 원격 시동·문 잠금·제조사 소유권 인증·클라우드 푸시/SMS는 기존과 같이 미연결입니다.
