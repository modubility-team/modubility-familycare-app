Family Drive 0.10.0 — GPS와 차량 길안내
2026-10-27

사용 방법
1. Pleos에서 파란 F 아이콘의 Family Drive 내비게이션을 엽니다.
2. 정차 중 ‘위치 허용’을 누르고 정확한 위치를 허용합니다.
3. GPS 상태가 수신 중인지 확인합니다. 에뮬레이터는 반드시 ‘모의 위치’로 표시합니다.
4. 지도를 터치해 목적지를 선택하거나 ‘어디로 갈까요?’를 눌러 위치를 고릅니다.
5. ‘우리 앱에서 경로 찾기’ → 경로 확인 → ‘안내 시작 / 재개’를 누릅니다.
6. 내 위치는 현재 GPS로 복귀, 경로 전체는 전체 경로 확인, 안내 종료는 경로 삭제입니다.

휴대폰은 소유자용 ‘내 차’와 동승자용 ‘Family Care’를 설치합니다.
01 차량 APK는 Pleos용입니다. 일반 휴대폰용 길안내 앱이 아닙니다.
가족이 보낸 목적지/경유지는 차량의 받은 요청에서 승인합니다.
‘확인’은 경로 검색 성공을 뜻하며 자동 출발·자동 차량 조작을 뜻하지 않습니다.

추가된 기능
- Android LocationManager GPS: 현재 위치·정확도·방향, 지도 따라가기.
- OSRM 도로 경로선, 회전 방향/거리, 남은 거리, 교통 상황을 반영하지 않은 예상 시간.
- Pleos 한국어 음성 길안내. 음성 엔진 실패 시 알림음으로 대체하고 상태에 표시.
- 목적지와 경유지, 경로 이탈·같은 길 역방향 이동 시 재탐색, 도착 처리.
- GPS 정확도 60m 초과 또는 10초 이상 새 위치가 없으면 안내 대기.
- 다른 앱으로 나가면 위치 수신/안내 중단. 돌아온 뒤 ‘안내 시작 / 재개’ 필요.
- Android Automotive 길안내 소유권을 획득한 뒤 시작, 다른 앱으로 소유권이 넘어가면 중단.
- 주행 중 상세 메뉴/사진/검색/승인은 숨기고 지도·회전·가족 안전 알림·종료만 표시.

구현 범위
이 버전은 공모전 시연용 내비게이션 프로토타입입니다.
실시간 교통, 차로별 안내, 단속 카메라, 오프라인 지도, 음성 목적지 검색, 주소 자동 검색은 없습니다.
이름 칸은 선택 지점에 붙일 이름입니다. 글자만 입력한다고 좌표가 검색되지 않습니다.
실제 차량 GPS/터널/복잡한 교차로/실도로 주행은 아직 검증하지 않았습니다.
스마트폰 위치를 차량에 전달하는 GPS 브리지는 이번 버전에 포함하지 않았습니다.
에뮬레이터에는 실제 GPS 안테나가 없습니다. 노트북을 움직여도 실제 위치가 되지 않습니다.

지도·경로·개인정보
지도: MapLibre Native / OpenFreeMap / OpenMapTiles / OpenStreetMap.
경로: https://router.project-osrm.org (OSRM/FOSSGIS 공개 시연 서비스).
검색 시 현재 위치·목적지·경유지 좌표를 HTTPS로 경로 제공자에게 전송합니다.
제공자 서버 로그에 좌표가 남을 수 있습니다. 앱은 GPS 위치 이력과 경로를 영구 저장하지 않습니다.
차량 현재 GPS 좌표를 동승자 서버에 추가 전송하지 않습니다. 기존 가족 장소 요청/사진 공유 정책은 유지합니다.
사용자 경로 검색은 최소 2초, 자동 재탐색은 최소 15초 간격이며 한 번에 한 요청만 처리합니다.
공개 서버에는 가용성/최신성 보장이 없습니다. 대규모 배포 전 계약된 경로 서비스 또는 자체 서버가 필요합니다.
정책: https://routing.openstreetmap.de/about.html
정책: https://github.com/Project-OSRM/osrm-backend/wiki/Demo-server
차량 가이드: https://document.pleos.ai/en/docs/pleos-only/vehicle-app-developer-guide/navigation-app-development-guide
