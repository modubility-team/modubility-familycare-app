Family Care — Pleos API 활용 현황 / 2026-10-27 / 차량 0.8.0

1. Vehicle SDK 2.3.2 — 이미 연결
온도·배터리·문/창문 등 차량 신호를 지원 여부 확인 후 읽습니다.
차속·기어 등은 Android Automotive 신호도 사용합니다.
공식 SDK에 제어 API가 있더라도 실제 차량의 capabilities와 승인 권한을 확인해야 합니다.
0.8.0은 공조 목표 온도를 CONTROL_CAR_CLIMATE 권한으로 설정합니다. 가족 요청은 운전자가 정차 후 승인하고, 소유자 역할은 P단 정차 차량에 설정을 요청합니다. 실제 설정값을 다시 읽어 일치해야 완료입니다. 공조 전원 ON/OFF·풍량·자동 온도 유지는 앱에 미구현입니다. 공조 전원이 켜지고 설정값을 읽을 수 있어야 조절할 수 있습니다.

2. NaviHelper SDK 3.0.5 — 이미 연결
차량의 기본 내비게이션으로 목적지/경유지를 전달합니다.
전달 후 목적지와 경로를 확인한 경우에만 성공으로 표시합니다.
현재 에뮬레이터의 일부 경유지 응답 제한은 별도 검증 기록을 따릅니다.
스마트폰 앱에 지도를 그려 주는 범용 지도 SDK는 아닙니다.

3. TextToSpeech SDK 3.3.1 — 이번에 연결/검증
Mode.ON_DEVICE와 ko-KR로 고정된 짧은 안내 문장을 차량에서 합성합니다.
동승자 휴식 요청, 목적지 제안 도착, 확인 타이머 등 기존 알림에 적용했습니다.
서버 합성용 인증키/앱 등록은 필요하지 않으며 TTS_SERVICE 권한을 선언했습니다.
Pleos 2.1 에뮬레이터의 한국어 합성 시작/완료 및 주행 UI 제한 중 요청 안내를 검증했습니다.
실제 사용자의 한국어 청취와 실차 오디오 품질은 별도 확인 대상입니다.
실패 시 기존 자체 알림음으로 전환합니다. 상세 시험 결과: DRIVING-AUDIO.txt

4. SpeechToText SDK — 문서 제공, 현재 앱에는 미연결
음성을 글자로 바꾸는 기능입니다. 음성 명령으로 앱 기능을 실행하는 것은 별도 연결이 필요합니다.
공식 가이드는 앱 기능 호출에는 Gleo Interface 사용을 안내합니다.
마이크 접근/권한·사용 흐름을 함께 설계해야 합니다.

5. FusedLocation SDK — 문서 제공, 현재 앱에는 미연결
차량 위치를 활용할 수 있으며 isSupported(), 위치 권한 및 마지막 위치의 null을 처리해야 합니다.
위치 정보 사용 목적과 동의 흐름을 정한 뒤 연결해야 합니다.

앱 3개와의 관계
이 API들은 주로 1번 Pleos 차량 앱이 사용하는 차량 플랫폼 SDK입니다.
2번 스마트폰 소유자 관리와 3번 Family Care 앱에 설치한다고 차량에 직접 연결되는 것은 아닙니다.
현재 스마트폰 요청은 같은 네트워크의 로컬 서버를 거쳐 차량 앱에 전달합니다.
실제 현대/기아 공식 앱이나 Bluelink 계정의 원격제어 API를 확보한 것은 아닙니다.
