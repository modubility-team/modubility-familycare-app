Family Care 0.13.0 — 원하는 위치에서 주행 / 스마트폰 카메라
작성일: 2026-10-29

1. 켜는 순서
기존 ‘시연’ 실행 도구 또는 team-project\scripts\windows\LiveDemo.cmd를 실행합니다.
차량 에뮬레이터와 연결 서버가 준비되면 http://127.0.0.1:8770/ 을 엽니다.
차량에는 01 차량 APK, 휴대폰에는 역할에 따라 02 내 차 / 03 Family Care APK를 업데이트합니다.
이전 버전 위에 설치할 수 있습니다. 서버 재시작 후에는 새 QR로 연결합니다.

2. 현재 위치를 지도에서 정하기
① ‘현재 위치 고르기’를 누릅니다.
② 지도를 이동·확대해서 원하는 도로/진입로를 클릭합니다.
   또는 장소명·주소를 입력 → ‘검색’ → 검색 결과를 선택합니다.
③ ‘선택한 현재 위치 적용’을 누릅니다.
④ 차량 P단 정차, 기존 경로 해제, 새 GPS 수신까지 기다립니다.
   완료 메시지가 나오면 차량 지도도 그 위치로 바뀝니다.
   새 이동 기록이 필요하면 ‘이동·가족 연결 다시 준비’를 누릅니다.
   이 버튼은 방금 적용한 출발 위치를 유지합니다.

3. 임의 목적지로 길찾기
① ‘목적지 고르기’ → 지도 클릭 또는 장소 검색으로 목적지를 고릅니다.
② ‘선택한 목적지로 길찾기’를 누릅니다.
③ 차량 화면의 경로와 목적지를 확인합니다.
④ 재생 속도를 고르고 ‘GPS 주행 시작 / 재개’를 누릅니다.
⑤ 정차가 필요하면 ‘P단 정차 / 안내 일시정지’를 누릅니다.
⑥ 도착 후 ‘이동 종료 / 뒷좌석 확인’으로 마칩니다.

차량 앱의 검색창이나 Family Care의 장소 제안 → 운전자 승인으로 만든 경로도 재생 가능합니다.
고정된 서울 목적지는 없습니다. 부산·제주 등 국내 위치를 직접 선택할 수 있습니다.
TMAP 자동차 도로 지원 범위가 기준입니다. 바다·해외·출입 불가 지점까지 안내된다고 보장하지 않습니다.
경로 검색에 실패하면 실패 사유를 표시하며 임의 직선/예제 경로로 대체하지 않습니다.
새 목적지 검색에 실패했을 때는 이전 목적지 경로도 해제합니다.
PC 선택 지도는 OpenStreetMap입니다. 차량/휴대폰 지도와 장소 검색·길찾기는 TMAP을 유지합니다.
지도 타일은 화면에 필요한 것만 요청합니다. 유료 상품을 새로 활성화하지 않았습니다.
기존 TMAP Free 할당량을 사용하며 무료 호출 한도·서비스 장애 시 검색이 제한될 수 있습니다.

4. 기능은 실제 앱에서 조작
시연 패널의 합성 사진 생성과 1분 타이머 바로가기를 제거했습니다.
사진: 휴대폰 ‘추억’에서 실제 사진을 직접 선택하고 공유합니다.
타이머: Family Care ‘반려동물’에서 요청 → 차량에서 정차 후 승인합니다.
공조·장소·프로필: 실제 휴대폰 요청과 차량 승인 흐름으로 확인합니다.
PC 도구는 에뮬레이터의 GPS·주행 재생·연결 준비에 사용합니다.
GPS 재생은 실제 차 자동운전이 아닙니다. 제품 앱의 기능과 구분해 발표합니다.

5. 여분의 안드로이드폰을 카메라로 쓰기
① Google Play ‘IP Webcam’을 설치합니다.
   https://play.google.com/store/apps/details?id=com.pas.webcam
② 카메라폰·노트북·앱을 볼 휴대폰을 같은 Wi-Fi에 연결합니다.
③ IP Webcam의 영상 해상도를 우선 640×480 또는 720p로 설정합니다.
④ 필요한 카메라 권한을 허용하고 ‘Start server / 서버 시작’을 누릅니다.
   화면 보기만 사용하므로 마이크·클라우드 방송·자동 녹화는 켜지 않아도 됩니다.
⑤ 화면 아래 http://192.168...:8080 형식 주소를 확인합니다.
⑥ PC 시연 화면 맨 위 ‘카메라 IP 변경’ → IP 주소 입력 → ‘이 주소로 연결 / 변경’.
   192.168.x.x:8080처럼 http:// 없이 입력해도 됩니다. IP가 바뀌면 이 칸만 수정하세요.
   페이지 새로고침 시 설정된 주소를 다시 불러옵니다. 서버 재시작 후에는 다시 입력하세요.
   또는 내 차 앱 ‘관리 → 실내 확인 → 카메라 연결’에서 입력합니다.
   카메라 앱에 로그인 이름·비밀번호를 설정했다면 해당 입력란에 넣습니다.
   비밀번호를 주소에 넣거나 채팅에 보내지 마세요.
⑦ Family Care ‘반려동물 → 실내 확인 → 화면 보기’에서 확인합니다.
   (2026-11-08부터 차량 앱에서는 카메라 화면을 뺐습니다. Pleos 내비게이션 앱 가이드의 영상 요소 금지 대응이며, 휴대폰 앱에서만 봅니다.)
⑧ 실제로 직접 확인했다면 ‘직접 확인했어요’를 눌러 확인 시각을 남깁니다.

6. 카메라 범위와 한계
- HTTP JPEG 스냅샷을 약 1초 간격으로 받아 보여 줍니다. 음성 통화·녹화·짖음 AI가 아닙니다.
- IP Webcam의 /shot.jpg 경로를 사용합니다. RTSP 전용 카메라는 이 연결에 지원하지 않습니다.
- 별도 소유자 연결로 등록하고, 허용된 가족만 볼 수 있습니다. 손님/관찰자 권한으로는 볼 수 없습니다.
- 영상과 카메라 비밀번호는 디스크에 저장하지 않습니다. 설정은 현재 연결의 서버 메모리에만 남습니다.
- 같은 Wi-Fi의 HTTP 통신이므로 신뢰할 수 있는 개인 네트워크에서 사용합니다.
- 소유자의 연결 해제, 권한 회수, 세션 만료 시 화면 전달이 중단됩니다.
- 앱이 백그라운드로 가거나 차량이 주행하면 차량 화면 수신을 멈춥니다.
- 연결 오류 시 마지막 영상을 계속 현재 화면인 것처럼 표시하지 않습니다.
- 건강·안전·짖음·이상행동을 자동 판정하지 않습니다. 직접 확인 타이머와 함께 사용합니다.
- PC/차량 연결이 유지되어야 합니다. 제조사의 원격 차량 카메라 서비스가 아닙니다.

Pleos Connect 차량용 앱에서 반려동물 상태를 보호자가 직접 확인하는 기능을 개발 중입니다.

영상은 녹화·클라우드 업로드하지 않으며 차량 화면은 P단 정차 중에만 표시합니다.
2차 PT와 최종 행사에서 이 외부 스마트폰을 반입·설치해 시연할 수 있는지,
현장 네트워크·전원 사용과 사전 승인·장비 목록 제출 요건이 있는지 확인 부탁드립니다.

실물 검증: 사용자 카메라폰의 주소와 실제 화면 입력이 필요합니다.
앱 코드와 자동화된 시험용 영상 검증을 실제 카메라폰 검증으로 표시하지 않습니다.
