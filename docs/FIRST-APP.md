# Family Care 첫 앱

## 현재 동작

- 운전석 문이 닫힘: 기본 안내와 휴대폰·지갑·가방 목록
- 운전석 문이 열림: '잠깐, 챙기셨나요?'와 소지품 확인 문구
- 미지원·연결 오류·알 수 없는 값: 문이 닫혔다고 가정하지 않고 확인 필요 상태 표시
- 화면을 떠날 때 구독 해제, 진행 중인 비동기 조회가 끝난 뒤 SDK release
- 화면으로 돌아오면 SDK를 새로 연결하고 현재 값을 다시 조회
- 0.1.1: CarUxRestrictions의 제한·알 수 없음 상태에서는 목록과 하차 문구·화면 전환 버튼 숨김
- 0.1.1: 화면 크기/종횡비에 따라 가로·세로 배치, 정차 중 전환 가능

문 열림은 하차 의도의 단서일 뿐입니다. 시동 종료나 실제 물건의 남아 있음을 판단하지 않습니다.
앱을 종료하거나 화면을 떠난 상태에서 알림을 보내는 백그라운드 기능은 아직 없습니다.

## 코드

- `android/app/src/main/java/com/familycare/navigation/MainActivity.kt`: 화면과 Activity 생명주기
- `DoorSession.kt`: 연결·지원 확인·조회·변경 알림·정리 순서
- `PleosDoorGateway.kt`: Vehicle SDK의 실제 도어 API 호출
- `android/app/src/test/java/com/familycare/navigation/DoorSessionTest.kt`: 상태 변경, 지연 응답, 구독 정리 등 단위 테스트

Vehicle SDK 2.3.2, Gradle 8.10.2, AGP 8.8.2, Kotlin 2.0.0, JDK 17 기준입니다.
개발 패키지는 `com.familycare.navigation`으로 두었습니다. 팀/최종 패키지 이름은 제출 전 확정합니다.

## 1분 시연 순서

1. Family Care 앱과 Virtual Console을 나란히 띄웁니다.
2. 운전석 문을 닫은 상태의 기본 화면을 보여줍니다.
3. 조종판에서 운전석 문을 엽니다.
4. 앱의 문구가 바뀌는 모습을 보여줍니다.
5. 문을 닫아 기본 화면으로 돌아오는 것을 보여줍니다.
