검증일: 2026-10-29

이번에 수정한 사항
================================================================
1. 공조 조작
   - '시원하게 / 따뜻하게'를 단순 메시지에서 설정 온도 0.5도 변경 요청으로 연결.
   - 공조 전원 켜기/끄기, 지원 좌석 선택, 설정 온도 요청을 연결.
   - 가족 요청은 승인 전에는 차량 값을 바꾸지 않음. 정차 후 운전자 승인 시 실행.
   - 소유자 앱의 공조 조작은 P단 정차 상태에서 적용.
   - Pleos SDK로 전원과 온도를 바꾸고 다시 읽어 성공 여부를 확인.
   - 휴대폰의 상태 새로고침과 버튼 입력이 겹치면 입력이 무시되던 문제 수정.
   - 연속 요청이 서버 제한에 걸리면 같은 요청 ID로 한 번 기다렸다 재시도.

2. 앱 화면 표현
   - 앱/내비의 '모의', '시연', '예제', '합성' 등 불필요한 전시용 표현 제거.
   - 실제 지원하지 않는 기능, GPS 연결 상태, 승인 필요 안내는 유지.
   - PC 조종석과 개발 검증 기록에는 시험 환경을 정확히 구분해 표시함.

3. 지도 검색
   - 검색 입력란 바로 오른쪽에 파란 '검색' 버튼 배치.
   - 키보드 검색 키도 같은 동작으로 연결. 검색 시 입력 포커스 해제.
   - 검색 중 지도 안내 카드와 하단 버튼이 입력창을 가리지 않도록 정리.
   - 검색어 입력 시 이전 편의시설 필터를 해제해 입력한 장소로 검색.
   - TMAP의 검색 결과 없음(HTTP 204)을 서버 오류로 표시하던 문제 수정.

4. 주행 중 알림
   - 지도 우측 하단에 작은 알림 카드와 미처리 요청 수 표시.
   - 음성이 끝나도 미처리 요청 카드는 유지.
   - 주행 중에는 짧은 안내만 표시하고 승인·상세 조작은 정차 후 제공.
   - 안전 확인 알림을 우선 표시하며 자유 입력한 긴 문장을 주행 화면에 노출하지 않음.

5. 추가로 발견한 문제
   - 빠른 속도 센서 콜백 때문에 급가속·급제동 변화량이 누락되던 계산 수정.
     신호를 누적해 계산하되 연결 끊김·잘못된 값은 급조작으로 세지 않음.
   - 도착 표시와 길안내 종료 상태의 갱신 순서 수정.
   - 알림 권한이 없을 때 백그라운드 알림을 시작한 것처럼 보이지 않도록 안내.

이번 검증은 Pleos 에뮬레이터와 같은 기기에 설치한 휴대폰 APK를 사용했다.
차량 SDK 제어는 실제 에뮬레이터 값의 변경을 확인했다.
휴대폰 화면 시험은 시험용 서버 상태도 사용하므로, 사용자 실제 휴대폰에서
Wi-Fi 연결·OS 알림·스피커까지 모두 확인했다고 해석하면 안 된다.
실제 휴대폰은 이번 작업 중 ADB에 연결되어 있지 않아 원격 업데이트하지 않았다.

TMAP 편의시설 검색 — 42dot 부근, 실행 당시 응답
  휴게소 12 / 화장실 5 / 수유 12 / 기저귀 교환 0 / 반려견 공원 6 / 무장애 화장실 0.
  6개 필터 모두 정상 응답. 0건은 검색 결과 없음이며 실제 시설 부재를 뜻하지 않음.
  검색어 일치 후보이므로 시설 보유 여부·운영 여부를 확인한 인증 목록은 아님.

N2  [실행] 가족의 목적지·경유지 요청을 승인한 뒤 경로 반영, 보류 처리.

N4  [실행] 급가속·급제동·급조향 집계. 이번에 고빈도 속도 입력 누락 수정.
N5  [규칙] 아이 0~3세 60분, 그 외 90분의 누적 주행 휴식 제안과 휴식 후 초기화.
             시간 진행 검사로 확인했으며 실제 60/90분 운전 시험은 하지 않음.
N6  [실행/조건] 6종 시설 필터 실제 TMAP 조회. 결과 없는 경우 안내 확인.
N7  [실행] GPS 경로와 이동 이벤트, 1분 정차 기록, 이동 종료 기록.
N8  [규칙] 가족 구성에 따른 출발 추천. 구성·추천 기준과 적용 흐름 대조.
N9  [실행/규칙] 급조작 3회 이상에 따른 휴식 권고, 경유지 요청·승인 흐름.

N10 [실행] GPS 경로 끝 도착, 남은 거리·예상 시간, 도착 시 안내 종료.

N13 [실행/규칙] 아이·반려동물 구성에서 이동 종료/도착 후 뒷좌석 확인.

남아 있는 환경상 제한
================================================================
- 실제 차량 시동·문 잠금 원격 제어는 연결된 OEM API가 없어 지원 완료로 표시하지 않음.
- 조수석·뒷좌석 독립 공조는 해당 차량 SDK가 지원하는 좌석만 가능.
- P6 카메라, F17 짖음 감지는 보류 상태 유지.
- 실제 휴대폰 설치·QR 카메라·OS 절전 상태의 알림·실제 스피커는 사용자 기기 확인 필요.
- TMAP 지도·검색은 연결·인터넷·계정의 사용 가능량에 영향을 받음. 요금제 변경 없음.
