패밀리케어앱 0.20.15 · 처음부터 켜는 방법 (자세한 실행 안내)
팀 모두빌리티 · 작성 2026-11-09
버전: 차량 앱 0.20.15 / 휴대폰 앱 0.20.12 / 태블릿 앱 0.20.1
(파일 이름의 0.20.5는 예전 링크가 깨지지 않도록 그대로 두었습니다.)

이 문서 하나로 "새 Windows 노트북에 설치 → 시연 켜기 → 휴대폰 연결 → 끄기 → 제출용 APK 만들기"까지
따라 할 수 있게 정리했습니다. 단계마다 '무슨 일이 일어나는지 / 성공 확인 / 막혔을 때 해결법'을 적었습니다.
API 키 값은 이 문서에 적지 않았습니다.

[경로 읽는 법]
- 이 문서의 경로는 '프로젝트 폴더' 기준입니다.
  GitHub 저장소: 저장소 맨 위 폴더 / 팀 전달 ZIP: FamilyCare_공유패키지\team-project 폴더
- 실행 파일(00~08 .cmd)은 GitHub 저장소에서는 맨 위, 팀 전달 ZIP에서는 FamilyCare_공유패키지 맨 위에 있습니다.
- '사용안내' 문서(51~54)는 GitHub 저장소의 docs\usage, 팀 전달 ZIP의 사용안내 폴더에 있습니다.

0. 한눈에 보기
================================================================
[처음 한 번]
  1장 노트북 조건 → 2장 프로그램 설치 → 3장 SDK 항목 → 4장 Pleos 차량 이미지·가상 차량
  → 5장 코드 받기·TMAP 키 → 6장 01_FirstSetup.cmd
[시연할 때마다]
  7장 02_StartDemo.cmd → 8장 휴대폰 연결 → 9·10장 시연 → 11장 03_StopAll.cmd
  가장 쉬운 방법: 00_한번에켜기.cmd(7-0) → 8장 휴대폰 연결 → 9·10장 → 바탕화면 'WithME 시연 끄기'
[코드를 고친 뒤]  12장
[제출용 APK]      13장 07_CreateReleaseKey.cmd → 08_BuildReleaseApk.cmd
[막혔을 때]       14장 문제 해결표 (화면의 빨간 오류 문장으로 찾기)
[발표 당일]       15장 체크리스트

노트북 1대가 '자동차 + 연결 서버' 역할을 합니다.
  노트북
   ├ Pleos 차량 에뮬레이터 ......... 차량 앱 'WithME'이 여기서 실행
   ├ 연결 서버 (포트 8765) ......... 휴대폰이 같은 Wi-Fi로 접속하는 곳
   ├ 시연 보조 화면 http://127.0.0.1:8770/ ... 노트북 브라우저에서만 열림
   ├ 차량 신호 화면(Virtual Console) http://127.0.0.1:8088/
   ├ 태블릿 화면 연결 (포트 8771, 선택)
   └ 외부 연결 (Cloudflare 임시 https 주소, 선택)
  휴대폰: 02 'WithME 내 차'(차주) / 03 'WithME 가족'(동승자)
  태블릿(선택): 04 'WithME 차량 화면'

노트북은 시연 내내 켜 두어야 합니다. 절전·덮개 닫기·Wi-Fi 변경 시 연결이 끊깁니다.

1. 노트북 조건
================================================================
- Windows 10/11 64비트, Intel 또는 AMD CPU
  (Windows ARM 노트북에서는 차량 이미지 실행을 확인하지 않았습니다.)
- 메모리 16GB 이상 권장 (차량 에뮬레이터 혼자 4GB 사용)
- 저장공간 30GB 이상 여유 권장 (Android Studio, SDK, 차량 이미지, 빌드 캐시)
- BIOS에서 가상화(Intel VT-x / AMD SVM) 켜짐
- 인터넷: 처음 설치 때 필수(라이브러리·TMAP SDK·음성 실행환경 다운로드),
  시연 중에도 필요(TMAP 지도·검색·경로 계산)
- Windows 날짜·시간 '자동으로 시간 설정' 켜짐 (차량 시계를 PC 시간에 맞춥니다)

2. 프로그램 설치 (처음 한 번)
================================================================
① Android Studio
   https://developer.android.com/studio/install
   설치 후 첫 실행 마법사는 Standard로 진행합니다.

② Temurin JDK 17
   https://adoptium.net/temurin/releases/?version=17&os=windows&arch=x64
   Windows x64용 .msi를 받아 기본값으로 설치합니다.
   기본 위치(C:\Program Files\Eclipse Adoptium\jdk-17...)에 있으면 실행 도구가 자동으로 찾습니다.
   ※ Android Studio 안에 들어 있는 JDK는 17이 아니라서 실행 도구가 쓰지 않습니다. 꼭 따로 설치하세요.

③ Python 3.12
   https://www.python.org/downloads/windows/
   - 페이지 맨 위의 'Python install manager'나 최신 3.14가 아니라,
     목록에서 'Python 3.12.10 - April 8, 2025' → 'Download Windows installer (64-bit)'를 받습니다.
     (3.12 중 Windows 설치 파일이 있는 마지막 버전입니다. 음성 모델 실행환경은 3.11~3.13만 지원합니다.)
   - 설치 첫 화면 맨 아래 'Add python.exe to PATH'를 체크하고 'Install Now'를 누릅니다.
   - 확인: 명령 프롬프트(cmd)에서  py -3.12 --version  → Python 3.12.10

④ Git (팀 저장소 작업을 할 때)
   https://git-scm.com/install/windows

3. Android SDK 항목 설치
================================================================
Android Studio 첫 화면 → More Actions → SDK Manager
(프로젝트가 열려 있으면 File → Settings → Languages & Frameworks → Android SDK)

[SDK Platforms 탭]
  - Android 15 (API 35) 체크
[SDK Tools 탭] 오른쪽 아래 'Show Package Details' 체크 후
  - Android SDK Build-Tools → 35.0.0
  - Android Emulator
  - Android SDK Platform-Tools
  - Android SDK Command-line Tools (latest)
→ Apply → 약관은 본인이 읽고 동의 여부를 결정 → 설치 완료까지 대기

화면 위쪽 'Android SDK Location'을 메모해 두세요.
보통 C:\Users\<본인이름>\AppData\Local\Android\Sdk 입니다.

4. Pleos 차량 이미지와 가상 차량(AVD) 만들기
================================================================
4-1. 차량 이미지 받기
  SDK Manager → SDK Update Sites 탭 → + 버튼
    Name: Pleos Connect System Image
    URL : https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml
  → OK → Apply
  SDK Platforms 탭 → 'Show Package Details' 체크 → Android 14 (API 34) 펼치기
  → Pleos Connect system image 체크 → Apply → 설치 후 Android Studio 재시작

4-2. 가상 차량 만들기
  Device Manager → + (Create Virtual Device)
  → 왼쪽 분류 Automotive → Pleos Connect v2.1.0 → Next
  → 시스템 이미지: API 34 'Pleos Connect v2.1.0 APIs' → Next
  → 이름(AVD Name): FamilyCare_Pleos
  → 고급 설정(Advanced / Additional settings)에서 Boot: Cold boot, RAM: 4 GB
  → Finish
  공식 안내(화면 포함):
  https://document.pleos.ai/docs/connect/guide/getting-started/application-development/setup-connect-sdk-emulator
  https://document.pleos.ai/docs/connect/guide/getting-started/application-development/configure-pleos-connect-emulator

4-3. 꼭 지킬 것
  - 이름에 'pleos'가 들어간 AVD는 하나만 둡니다.
    예전에 만든 Pleos AVD가 있으면 지우거나, 6-4의 familycare.local.json에 AvdName을 적으세요.
    (2개 이상이면 'Create one Pleos 2.1 AVD named FamilyCare_Pleos...' 오류)
  - AVD를 Android Studio에서 미리 켜 둘 필요는 없습니다. 02가 콜드 부팅으로 직접 켭니다.

4-4. RTX 4060 같은 NVIDIA 노트북 (에뮬레이터가 느리거나 끊길 때만)
  NVIDIA 제어판 → 3D 설정 관리 → 프로그램 설정 → 추가
  → <SDK 위치>\emulator\qemu\windows-x86_64\qemu-system-x86_64.exe → '고성능 NVIDIA 프로세서'
  (또는 Windows 설정 → 시스템 → 디스플레이 → 그래픽에서 같은 파일을 '고성능'으로)
  시연은 충전기를 꽂은 상태로 하세요.

5. 코드 받기와 TMAP 키
================================================================
A. 팀 전달 ZIP을 받은 경우
  1) ZIP 파일 오른쪽 클릭 → 속성 → 아래쪽에 '차단 해제'가 보이면 체크 → 확인
     (인터넷에서 받은 ZIP이면 이걸 해야 cmd 실행 때 'Windows의 PC 보호' 경고가 덜 뜹니다.
      경고가 떠도 '추가 정보' → '실행'을 누르면 됩니다.)
  2) 오른쪽 클릭 → 모두 압축 풀기 → 예: C:\FamilyCare
     → C:\FamilyCare\FamilyCare_공유패키지\ 가 생깁니다. (폴더 이름의 한글은 빌드 도구가 처리합니다.)
  3) TMAP 키 파일(tmap.local.json)이 이미 들어 있습니다. 공개 저장소·게시판에 올리지 마세요.

B. GitHub에서 받은 경우
  1) git clone <저장소 주소>  또는  GitHub의 Code → Download ZIP → 압축 풀기
  2) TMAP 키 파일 만들기 (지도·검색·경로에 필요)
     tmap.local.example.json 을 같은 폴더에 복사해서 이름을 tmap.local.json 으로 바꾸고
       "app_key": 본인 TMAP 앱 키 (SK open API에서 TMAP 무료 상품을 연결한 앱의 appKey)
       "enabled": true
       "map_sdk_enabled": true
     로 저장합니다. 팀원은 팀 전달 ZIP의 tmap.local.json을 복사해도 됩니다.
     키 확인: 프로젝트 폴더에서  py -3.12 scripts\check_tmap.py --live  (키 값은 출력하지 않습니다)
     이 파일은 .gitignore로 GitHub에 올라가지 않습니다.

공통
  - OneDrive와 동기화되는 바탕화면·문서 폴더는 피하세요. 빌드 중 파일 잠김이 생길 수 있습니다.
  - ZIP 창 안에서 바로 cmd를 실행하지 마세요. 반드시 풀고 나서 실행합니다.
  - 실행 파일
    01_FirstSetup.cmd ........... 처음 설치·빌드 (PC마다 한 번, 코드 수정 후 다시)
    02_StartDemo.cmd ............ 시연 켜기
    03_StopAll.cmd .............. 전부 끄기
    04_OpenApks.cmd ............. 설치 파일(APK) 폴더 열기
    05_DeveloperMenu.cmd ........ 개발자 메뉴 (점검·수동 실행, 한 번에 메뉴 하나 실행 후 끝남)
    06_UpdateSharePackage.cmd ... 팀 전달 ZIP 다시 만들기 (팀 전달본에만 있음, API 키 포함)
    07_CreateReleaseKey.cmd ..... 제출용 서명 키 만들기 (팀에서 한 번)
    08_BuildReleaseApk.cmd ...... 제출용 APK 만들기

6. 01_FirstSetup.cmd (PC마다 처음 한 번)
================================================================
6-1. 실행
  인터넷 연결 → 01_FirstSetup.cmd 더블클릭 → 창을 닫지 말고 끝까지 기다립니다.
  처음에는 라이브러리 다운로드 때문에 10~30분 걸릴 수 있습니다.

6-2. 이 파일이 하는 일 (순서대로)
  ① Android SDK, Python(3.11 이상), JDK 17 위치 찾기
  ② SDK 항목 확인: API 35, Build-Tools 35.0.0, Platform-Tools, Emulator
  ③ Pleos AVD 확인 → 'SDK and Pleos AVD found: FamilyCare_Pleos'
  ④ android\local.properties에 SDK 위치 기록
  ⑤ QR 생성용 Python 패키지(qrcode) 설치
  ⑥ 음성 이해 모델 실행환경 준비 → 'Voice runtime Python: (사용할 Python 경로)'
     Python 3.11~3.13으로 dist\voice-runtime\venv를 만들고 onnxruntime 등을 설치합니다.
     모델 파일은 팀 전달 ZIP에 들어 있고, GitHub에서 받았다면 이때 공식 배포처에서 받아 해시를 확인합니다.
  ⑦ TMAP 지도 SDK 3.7을 공식 주소에서 받아 해시 확인 → android\local-sdk\tmap
  ⑧ Gradle로 앱 4개 + 시연용 APK 빌드
  차량이나 서버는 켜지 않습니다.

6-3. 결과 확인
  성공: 'Setup complete. Close this window and run 02_StartDemo.cmd.'
        → dist\apk 의 01~04 APK가 이 PC의 개발용 서명으로 새로 만들어집니다.
  실패: 빨간 글씨 'SETUP INCOMPLETE: (이유)' → 14장 표에서 같은 문장을 찾으세요.

6-4. 설치 위치를 못 찾을 때 (familycare.local.json)
  familycare.local.example.json 을 복사해서 이름을 familycare.local.json 으로 바꾸고
  필요한 칸만 채웁니다. 경로는 \ 대신 / 로 씁니다. 실제 위치는 탐색기에서 확인한 그대로 적습니다.
  {
    "AndroidSdk": "C:/Users/본인이름/AppData/Local/Android/Sdk",
    "JdkHome": "C:/Program Files/Eclipse Adoptium/jdk-17로 시작하는 실제 폴더 이름",
    "PythonExe": "C:/Users/본인이름/AppData/Local/Programs/Python/Python312/python.exe",
    "StudioExe": "",
    "AvdName": "FamilyCare_Pleos",
    "DeviceSerial": ""
  }
  이 파일은 PC 개인용이라 공유·업로드하지 않습니다.

7. 02_StartDemo.cmd (시연할 때마다)
================================================================
7-0. 한 번에 켜기: 00_한번에켜기.cmd (권장)
  더블클릭 하나로 아래를 차례로 진행합니다.
  ① 처음 켜는 PC면 01_FirstSetup 과정(설치·전체 빌드, 10~30분)을 먼저 실행
  ② 휴대폰용 네트워크 확인: 하나면 자동, 여러 개면 번호 선택(0 = 외부 연결),
     휴대폰과 같이 쓸 Wi-Fi가 없으면 외부 연결로 자동 전환
  ③ 02_StartDemo와 같은 과정(에뮬레이터·연결 서버·차량 앱·시연 보조 화면)
  ④ 에뮬레이터 마이크를 노트북 마이크에 연결 (노란 안내가 나오면 10-B대로 직접)
  ⑤ 외부 연결만 쓰는 경우 외부 연결 시작
  처음 실행하면 바탕화면에 'WithME 시연 켜기' / 'WithME 시연 끄기' 버튼이 생깁니다.
  다음부터는 바탕화면 버튼만 누르면 됩니다. 성공하면 '준비 완료!'와 휴대폰 앱 설치 주소가 나옵니다.
  실패하면 빨간 '오류:' 문장과 그 위의 ERROR 문장을 14장에서 찾으세요.
  에뮬레이터 첫 부팅이 길어 멈췄다면, 차량 홈 화면이 뜬 뒤 다시 누르면 이어서 켭니다.
  7-1~7-5는 같은 과정을 나눠서 설명한 것입니다. 02_StartDemo.cmd를 따로 써도 됩니다.

7-1. 켜기 전에
  - 노트북을 인터넷이 되는 Wi-Fi에 연결하고, 휴대폰도 같은 Wi-Fi에 연결합니다.
  - 그 Wi-Fi의 네트워크 프로필을 '개인 네트워크'로 바꿉니다.
    Windows 설정 → 네트워크 및 인터넷 → Wi-Fi → (연결된 Wi-Fi) 속성 → 네트워크 프로필 유형: 개인 네트워크
    집·팀 핫스팟처럼 믿을 수 있는 네트워크에서만 하세요.
    카페·학교 공용 Wi-Fi에서는 8-3 외부 연결을 쓰는 편이 안전합니다.
  - GitHub에서 받았다면 5장 B의 tmap.local.json이 있어야 지도가 나옵니다.
  - 유선 랜과 Wi-Fi가 동시에 연결돼 있으면 하나를 끊거나 7-4 방법을 씁니다.

7-2. 실행
  02_StartDemo.cmd 더블클릭 → 몇 분 기다림 → 브라우저에 시연 보조 화면이 자동으로 열립니다.
  성공 마지막 줄: 'Ready: http://127.0.0.1:8770/'
  실패: 빨간 'ERROR: (이유)' → 14장

  ★ 처음 실행할 때 Windows 방화벽 창('Windows 보안 경고' - Python)이 뜨면
     '개인 네트워크'만 체크 → '액세스 허용'.
     이 창을 '취소'하거나 놓치면 휴대폰이 노트북에 접속하지 못합니다. (14장 '휴대폰 연결' 참고)

7-3. 이 파일이 하는 일 (순서대로)
  ① 이미 켜져 있으면 다시 연결만 하고 보조 화면을 엽니다. (두 번 눌러도 안전)
  ② 차량 에뮬레이터가 없으면 FamilyCare_Pleos를 콜드 부팅으로 켭니다. (최대 약 3분 대기)
     → 차량 시계를 한국 시간으로 맞춤 → Virtual Console(8088) 연결
  ③ 에뮬레이터 ↔ 노트북 연결 (8088 forward, 8765 reverse)
  ④ Cloudflare 외부 연결 도구 확인 (실패해도 같은 Wi-Fi 연결은 그대로 사용 가능)
  ⑤ 연결 서버를 보이지 않는 창으로 시작
     휴대폰용 네트워크가 1개면 자동 선택:
     'Starting phone relay on your local network: http://192.168.x.x:8765'
     ← 이 주소(노트북 Wi-Fi 주소)는 8-1, 14장에서 씁니다.
  ⑥ 시연용 차량 앱을 오프라인 빌드(01에서 받아 둔 라이브러리 사용) → 에뮬레이터에 설치
  ⑦ 차량을 속도 0, P단으로 세팅
  ⑧ 시연 세션과 시연 보조 화면 실행 → 에뮬레이터에 차량 앱이 뜨고 보조 화면이 열림

  - 'Ready'가 나온 뒤 이 창은 닫아도 됩니다. 서버들은 뒤에서 계속 돌아갑니다.
    끌 때는 반드시 03_StopAll.cmd를 씁니다.
  - 에뮬레이터 창은 닫지 마세요. 그게 시연 차량입니다.

7-4. 네트워크가 여러 개라 자동 선택이 안 될 때
     (ERROR: Could not choose the phone network automatically (N found). ...)
  ① 05_DeveloperMenu.cmd → 2 입력(Start Pleos) → 'Ready. Open http://127.0.0.1:8088/...'까지 대기 → 창 닫기
  ② 05_DeveloperMenu.cmd를 다시 열고 → 6 입력(Phone Wi-Fi server)
     → 목록에서 휴대폰과 같은 Wi-Fi의 번호 입력
  ③ 'Server: http://192.168.x.x:8765 (keep this window open; Ctrl+C stops it).'가 나오면 이 창은 그대로 둡니다.
  ④ 02_StartDemo.cmd 실행 (이미 켜진 차량과 서버를 그대로 사용)

7-5. 같은 Wi-Fi를 아예 쓸 수 없을 때 (외부 연결만 쓰기)
  노트북에 사설 Wi-Fi 주소가 없으면 02가 연결 서버를 자동으로 켜지 못합니다. 이때는
  ① 05 → 2 (차량 시작) ② 05를 다시 열고 → 5 (Local server, 창 유지) ③ 02 실행
  ④ 보조 화면에서 8-3 외부 연결 시작 → 외부 QR 사용
  이 경우 '같은 Wi-Fi' QR은 PC 전용 주소(127.0.0.1)라 휴대폰에서 쓰지 않습니다.
  발표 전에 한 번 미리 해 보세요.

8. 휴대폰·태블릿 앱 설치와 연결
================================================================
8-1. 어떤 APK를 어디에 (04_OpenApks.cmd → dist\apk)
  01-FamilyCare-vehicle-debug.apk ..... Pleos 차량용. 휴대폰에 설치하지 않습니다. (02가 에뮬레이터에 자동 설치)
  02-FamilyCare-navigation-debug.apk .. 차주 휴대폰 → 앱 이름 'WithME 내 차'
  03-FamilyCare-care-debug.apk ........ 동승자 휴대폰 → 앱 이름 'WithME 가족'
  04-FamilyCare-tablet-debug.apk ...... 안드로이드 태블릿(선택) → 'WithME 차량 화면'
  - 휴대폰은 Android 9 이상. 시연할 때는 한 휴대폰에 02와 03을 둘 다 설치해도 됩니다.
  - 옮기는 방법 A (같은 Wi-Fi, 02 실행 중일 때 가장 쉬움)
      휴대폰 크롬 주소창에 직접 입력:
      http://(7-3 ⑤의 노트북 주소):8765/install/owner.apk   → 02 내 차
      http://(7-3 ⑤의 노트북 주소):8765/install/family.apk  → 03 WithME 가족
      다운로드 → 파일 열기 → '출처를 알 수 없는 앱 설치' 허용 → 설치
  - 옮기는 방법 B: USB 케이블로 휴대폰 '다운로드' 폴더에 복사 → 휴대폰 '내 파일'에서 열어 설치
  - Play 프로텍트 경고가 뜨면 '세부정보' → '무시하고 설치' (개발용 APK라 뜰 수 있습니다)
  - '앱이 설치되지 않았습니다' / '기존 패키지와 충돌'
    → 다른 PC에서 만든 APK가 이미 깔려 있는 것(개발용 서명이 PC마다 다름).
      기존 앱을 삭제(그 앱의 데이터도 지워짐)하고 이 PC에서 만든 APK로 설치합니다.
      팀원 휴대폰은 한 PC의 빌드로 맞춰 두면 편합니다.

8-2. 같은 Wi-Fi로 연결 (기본)
  ① 휴대폰을 노트북과 같은 Wi-Fi에 연결 (확실히 하려면 모바일 데이터를 잠시 끄기)
  ② 시연 보조 화면의 '같은 Wi-Fi · 휴대폰 앱 연결' 카드에서
     차주 휴대폰은 '소유자 · 내 차' QR, 동승자 휴대폰은 '동승자 · WithME 가족' QR을 카메라로 스캔
  ③ 열린 웹페이지 아래쪽 '설치된 휴대폰 앱으로 열기'를 눌러 펼치면 그 QR에 맞는 앱 버튼 하나만 나옵니다.
     소유자 QR → '소유자 · 내 차 앱 열기' / 동승자 QR → '동승자 · WithME 가족 열기'
  ④ 앱이 열리면 '정보 확인하고 연결' → 연결 완료
  - QR 주소는 http://192.168.x.x:8765/... 처럼 노트북 Wi-Fi 주소여야 합니다.
    127.0.0.1로 시작하면 PC 전용 주소라 휴대폰에서는 안 됩니다. (14장)
  - 소유자 QR은 차주에게만 보여 주세요. 차량 관리 권한이 들어 있습니다.
  - 앱 역할(0.20.7): 내 차 앱 = 소유자 QR만 (차량 관리, 권한 승인, 픽업용 차량 위치 공유)
                     WithME 가족 = 가족·손님 QR만 (권한 요청, 장소 제안, 픽업 대기 위치 보내기)
    다른 앱의 QR로 열면 연결하지 않고 '연결' 화면에 'WithME 가족 앱에서 열기'(또는 '내 차 앱에서 열기')를 보여 줍니다.
  - 서버를 다시 켜면(03 → 02) QR이 바뀝니다. 예전 QR이나 다른 PC의 QR은 쓰지 않습니다.
  - 시연 연결은 최대 2시간입니다. 지나면 보조 화면의 '차량 연결 복구' → 새 QR로 다시 연결.

8-3. 다른 Wi-Fi·LTE·5G에서 연결 (외부 연결)
  같은 Wi-Fi를 쓸 수 없거나, 멀리 있는 가족이 접속하는 장면을 보여 줄 때 씁니다.
  ① 노트북 인터넷 연결 확인
  ② 시연 보조 화면 위쪽 '다른 Wi-Fi 연결' → '외부 연결 시작' → 준비 완료까지 대기
  ③ 외부 '소유자 · 내 차' / '동승자' QR 스캔 → 8-2의 ③ ④와 같음
  - 주소는 https://(임의 이름).trycloudflare.com 으로 만들어지고, 다시 시작하면 바뀝니다. 새 QR로 연결.
  - 무료 임시 연결이라 인터넷 상태에 따라 끊길 수 있습니다.
  - 학교·회사 Wi-Fi는 이 연결을 막기도 합니다 → 노트북을 휴대폰 핫스팟에 연결해서 시도.
  - 태블릿 화면·GPS와 IP 카메라는 외부 연결로 되지 않습니다(같은 Wi-Fi 필요).
  - 다 쓰면 '외부 연결 종료'.
  - 상세: 사용안내 54번(외부 연결 Cloudflare 사용법)

8-4. 태블릿 (선택)
  ① 태블릿을 노트북과 같은 Wi-Fi에 연결
  ② 시연 보조 화면 '탭 화면·GPS 연결' → '탭으로 차량 화면' QR 스캔
  ③ '태블릿용 앱 다운로드' → 설치 (04 APK를 이미 설치했다면 건너뜀)
  ④ QR 페이지로 돌아와 '설치한 앱에서 연결' → 앱에서 '차량 연결'
  ⑤ 태블릿을 가로로 두고 차량 화면을 터치. 탭의 실제 위치를 쓰려면 '탭 GPS 시작' → 정확한 위치 허용
     → 탭 위쪽 '탭 위치 연결됨(GPS / GPS·Wi-Fi / Wi-Fi·기지국)' 확인
     실외는 GPS, 실내는 Wi-Fi 위치를 씁니다(오차 50m 이내만). 탭 설정의 'Google 위치 정확도'를 켜 두세요.
     탭 앱 0.20.0은 실내에서 위치가 안 들어옵니다 → 보조 화면 QR의 '태블릿용 앱 다운로드'로 0.20.1을 다시 설치
  - 소리와 음성 명령은 노트북 스피커·마이크로 동작합니다. 한 번에 태블릿 1대, 링크는 8시간 후 만료.
  - 실내 자동 주행으로 돌아올 때는 태블릿 'GPS 중지' 또는 보조 화면 '탭 GPS 중지 / P단 정차'
  - 상세: docs\tablet-screen-gps-0.20.0.txt

8-5. IP 카메라 (선택, 반려동물 실내 확인)
  여분 안드로이드폰에 'IP Webcam' 앱 설치 → 같은 Wi-Fi → 서버 시작
  → 화면에 나온 주소(예: 192.168.0.10:8080)를 보조 화면 '카메라 IP 변경' 칸에 입력
  → '이 주소로 연결 / 변경' → '화면 보기'로 확인
  화면은 내 차·WithME 가족 앱의 '실내 확인'에서 봅니다. 차량 앱에는 카메라 화면이 없습니다.
  (Pleos 내비게이션 앱 가이드가 영상 요소를 즉시 반려 항목으로 정하고 있어 2026-11-08에 뺐습니다.)
  카메라 앱의 클라우드 기능은 끄세요. 심사 현장에서 외부 장치를 써도 되는지는 주최 측 확인이 필요합니다.

9. 시연 보조 화면 사용법 (http://127.0.0.1:8770/)
================================================================
노트북 브라우저 전용 화면입니다. 실제 도로 대신 '위치와 주행 상태'를 만들어 주는 도구입니다.

[위쪽 상태칸] 차량 앱 상태 · 재생 속도 · 차량 GPS · 공조 설정 · 가족 연결

[1. 지도에서 현재 위치와 목적지 선택]
  - '현재 위치 고르기' → 지도 클릭 또는 검색 → '선택한 현재 위치 적용'
    (자동으로 P단 정차 → 기존 경로 해제 → 차량 GPS 수신 확인)
  - '목적지 고르기' → 지도 클릭 또는 검색 → '선택한 목적지로 길찾기' (TMAP 자동차 경로)
  - '차량 위치 보기' / 지도 색: 파랑 = 차량 GPS, 초록 = 선택한 현재 위치, 주황 = 목적지
  - 검색 버튼이 회색이면 연결 시간이 끝난 것 → '차량 연결 복구' → 휴대폰은 새 QR로
  - 바다·해외·출입 불가 지점처럼 자동차 경로가 없는 곳은 오류가 나는 게 정상입니다.

[2. 차량 앱의 경로로 GPS 재생]
  - 속도 선택: 20 / 40 / 80 / 120 km/h
  - 'GPS 주행 시작 / 재개' → 차량이 주행 상태 (주행 중 화면 제한·운전자 알림 확인용)
  - 'P단 정차 / 안내 일시정지' → 정차 상태 (정차 중에만 되는 기능 확인용)
  - '이동 종료 / 뒷좌석 확인' → 도착 후 뒷좌석 확인 흐름
  - '이동·가족 연결 다시 준비' → 처음 상태로
  운전자나 휴대폰이 제안한 목적지를 승인해도 같은 경로로 재생됩니다. 실제 자율주행 기능은 아닙니다.

[그 밖의 카드] 다른 Wi-Fi 연결(외부 연결) · 같은 Wi-Fi QR · 탭 화면·GPS · 카메라 IP

차량 신호 화면(Virtual Console) http://127.0.0.1:8088/ 은 Pleos 공식 도구로,
기어·속도·공조 같은 차량 신호를 직접 바꿔 볼 수 있습니다. 시연 중에는 보조 화면 버튼 위주로 쓰세요.

10. 대표 시연 흐름 (리허설용 예시)
================================================================
A. 동승자 요청 → 운전자 승인 → 차량 제어 (핵심 흐름)
  ① WithME 가족 → 권한 → 좌석 선택 → 다음 · 기능 선택 (한꺼번에 고르려면 '모두 추가')
  ② 선택한 항목 확인 → '운전자에게 권한 요청'
  ③ 차량 화면에서 승인 (정차 상태에서)
  ④ WithME 가족에서 예: 조수석 온도 22°C 요청
     → 휴대폰 위쪽 '조수석 22°C · 적용 대기' → 차량 반영 후 '조수석 22°C · 반영 완료'
     (거절되면 '적용 안 됨', 결과가 불확실하면 '결과 미확인')
  '모두 추가'는 고르기를 돕는 버튼일 뿐, 운전자 승인과 정차 조건을 건너뛰지 않습니다.

B. 장소 제안 + 자연어 음성 경유 (0.20.5 새 기능)
  ① A처럼 길안내 권한 요청 → 차량에서 승인
  ② 차량 내비에서 최종 목적지 검색 → 경로 선택 → 안내 시작
  ③ 보조 화면 'GPS 주행 시작 / 재개' (주행 중이어야 제안이 운전자 처리 대기로 남습니다)
  ④ WithME 가족 홈 '장소 제안' 또는 '쉬어 갈 곳 찾기' → 장소 검색 → 결과 선택 → '차량에 장소 제안'
  ⑤ 차량 화면 아래 '음성 명령' → '말하기' → "추천지를 경유해 줘" 또는 "가족이 보내준 데 잠깐 찍고 가자"
  ⑥ 후보가 여러 개면 번호를 읽어 줍니다 → 다시 '말하기' → "두 번째" 또는 장소 이름 (60초 안에)
  ⑦ 경유지가 추가되고 최종 목적지는 그대로인지 확인
  ★ 노트북 마이크로 말하려면 에뮬레이터를 켤 때마다 설정해야 합니다.
     에뮬레이터 옆 도구막대 '⋯'(Extended controls) → Microphone
     → 'Virtual microphone uses host audio input' 켜기
     (에뮬레이터 기본값이 꺼짐이고, 에뮬레이터를 다시 켜면 다시 꺼집니다. 02는 매번 새로 켭니다.)
     00_한번에켜기.cmd로 켜면 이 설정을 자동으로 켭니다. 노란 '마이크:' 안내가 나왔을 때만 직접 켜세요.
     Windows 설정 → 개인정보 및 보안 → 마이크 → 데스크톱 앱의 마이크 사용도 켜져 있어야 합니다.
  - 음성은 Pleos Speech HYBRID Client ID/Secret 설정 시 서버 우선, 실패 시 기기 내 인식으로 대체합니다. 설정 전에는 기기 내 인식만 사용합니다. 말뜻은 노트북 E5 모델이 해석합니다.
  - 상세: 사용안내 53번(자연어 음성 경유)

C. 음성으로 목적지 검색·안내 (0.20.7 새 기능)
  ① 차량 화면 아래 '음성 명령' → '말하기'
     음성 창에는 들은 말, 차량의 답, 번호 목록만 나옵니다(0.20.8). 말할 문장은 아래 예시를 보세요.
  ② 이렇게 말합니다
     - "강남역으로 안내해 줘" / "서울역 가자" / "롯데월드 가는 길 알려 줘"
     - "목적지를 부산역으로 바꿔 줘"
     - "집으로 가자" / "회사로 가자" (목적지 선택 화면에서 '집 등록'·'회사 등록'을 해 둔 경우)
     - "가까운 주유소 찾아 줘" / "스타벅스 검색해 줘" (결과를 먼저 보여 주고 고르게 합니다)
  ③ 이름이 정확히 하나로 맞으면 바로 경로를 찾고 안내를 시작합니다.
     후보가 여러 곳이면 3곳까지 번호와 이름을 읽어 줍니다 → 다시 '말하기' → "두 번째" 또는 장소 이름 (60초 안에)
     P단 정차 중에는 화면의 후보를 눌러도 됩니다.
  ④ 길안내 중에 "OO 찾아 줘"로 고른 곳은 최종 목적지를 유지한 채 경유지로 추가합니다.
     "OO으로 가자/안내해 줘"는 목적지를 바꿉니다.
  - 검색은 노트북 연결 서버를 거쳐 TMAP으로 합니다. 차량 연결(QR 공유)이 켜져 있어야 합니다.
  - 가족이 보낸 장소·픽업 요청을 말하는 문장("추천한 곳 들렀다 가자")은 B의 경유 기능이 그대로 처리합니다.
  - '가지 마', 질문("강남역까지 얼마나 걸려?"), 여러 행동을 섞은 문장은 실행하지 않습니다.

D. 픽업 요청
  차주 앱에서 픽업 위치 공유 켜기 → WithME 가족 '타기 전 픽업'에서 현재 위치·가게·메모 전송
  → 차량 '음성 명령' → 표시된 픽업 요청 확인 → '말하기' → "픽업 경유해 줘"
  상세: 사용안내 52번(검색·픽업·권한 개선)

E. 가족 이동 기준으로 경로 바로 바꾸기 (0.20.9 새 기능)
  ① A처럼 WithME 가족에서 '목적지·경유지 변경' 권한을 요청 → 차량에서 승인 (정차 상태에서)
  ② 차량 내비에서 목적지 검색 → 경로 선택 → 안내 시작 (TMAP 경로)
  ③ 보조 화면 'GPS 주행 시작 / 재개'
  ④ WithME 가족 → 이동 기준 → 예: '방향 전환 적게' 체크 → '차량의 경로 비교에 전달'
     → 휴대폰: "가족 기준을 보냈어요 · 차량 경로에 바로 반영돼요"
  ⑤ 몇 초 뒤 차량이 TMAP 후보(추천·최소 시간·고속도로 우선)를 비교해 안내 중인 경로를 바꾸고
     "가족 기준에 맞춰 방향 전환이 적은 길로 바꿨어요"라고 말합니다. 안내는 멈추지 않습니다.
     안내 패널 아랫줄: '가족 기준(방향 전환 적게) · +0.4 km / +3분 (예상)' 같은 변화량
     지금 경로가 이미 기준에 맞으면 "지금 경로가 가족 기준에 맞아요"라고 알려 줍니다.
  ⑥ 화장실·반려견 산책·쉬어 갈 장소
     - P단 정차 중: 경로 앞쪽(500 m 이후)의 화장실·반려견 공원·휴게소를 찾아 경유지로 넣습니다.
       경유로 20분 넘게 늦어지면 넣지 않고, 경유지가 이미 있으면 그대로 둡니다(경유지는 한 곳).
     - 주행 중: 자동으로 넣지 않고 "가족이 원하는 화장실 경유는 음성 명령으로 추가할 수 있어요"라고 알려 줍니다.
       운전자가 '음성 명령' → '말하기' → "화장실 찾아 줘" → 번호로 골라 경유지를 추가합니다.
  - '목적지·경유지 변경' 권한이 없는 가족이 보내면 경로는 그대로이고, 운전자가 P단에서
    '가족 기준으로 경로 비교'를 눌러 후보를 보고 고릅니다(예전 방식).
  - 목적지를 정하기 전에 보내면 '가족 기준을 받았어요 · 목적지를 정하면 반영해요' → 10분 안에 목적지를 정하면 반영합니다.
  - 운전자가 직접 비교·선택하거나 안내를 끝내면 기다리던 가족 기준은 지웁니다.
  - 방향 전환 수는 조회한 후보끼리의 비교이며 멀미 예방 효과를 뜻하지 않습니다.

F. 상황별 케어 + 지정 휴게소 (0.20.10 새 기능)
  ① WithME 가족 두 대에 '상황별 케어와 보호자 알림' 권한 (보호자 폰은 앱을 켜 둠)
  ② 차량: 목적지 안내 중 (이동 시작 → 안내 시작 → 보조 화면 GPS 재생)
  ③ WithME 가족 → 상황별 케어 → '아이가 잠들었어요' → 보호자 선택
     → '쉬어 갈 휴게소 지정'에 남은 경로의 휴게소가 가까운 순서로 자동으로 뜸(0.20.15, 'N km 앞')
       목적지 안내 전이면 "차량에서 목적지 안내를 시작하면…" 안내가 나옴. 이름을 입력해 다시 검색할 수도 있음
     → 결과 선택 → '이 설정으로 케어 시작'
  ④ 차량에 '지정 휴게소 · 이름' 경유지 요청이 도착
     - P단 정차 중: 요청 → '승인하고 경유지로 추가' → 최종 목적지는 그대로, 휴게소가 경유지로 들어감(안내 중이면 계속)
     - 주행 중: 운전자 '음성 명령' → "가족이 보내준 데 잠깐 찍고 가자"(또는 휴게소 이름 + "경유해 줘")
     - 보낸 가족에게 '목적지·경유지 변경' 권한이 있고 P단 정차 중이면 바로 경유지로 반영
  ⑤ 차량 안내 카드: '아이가 잠들었어요 · 지정 휴게소 도착까지 N분' / '일반 요청 → 보호자'
     경유지 반영 전: '지정 휴게소 · 경로 반영 대기'
  ⑥ 휴게소를 지나면(60 m 안) 가족 폰에 '지정 휴게소(이름)에 도착했어요' 알림 → 쉬고 나서 '휴식 완료'
  - 남은 시간은 내비 예상치입니다. 휴게소의 실제 시설·영업 여부는 직접 확인하세요.

G. 차량 지도의 추억 사진 카드 (0.20.11 새 기능, 0.20.12에서 더 크게)
  ① 차량: P단 정차 (0.20.12부터 길안내를 켜 둔 채여도 됩니다. 예: 이동 중 휴게소)
  ② WithME 가족 홈 '사진 한 장, 오늘의 추억' → '추억 사진 선택' → '사진 선택'
     - 촬영 위치가 있는 사진이면(0.20.13) 몇 초 안에 자동으로 채워짐:
       '주소·장소 이름 검색' 칸과 근처 장소 목록, '선택한 장소: (장소 이름)', '주소: (도로명 주소)', 사진 제목
       다른 곳이면 목록에서 고르거나 다시 검색. 제목을 직접 고치면 그 뒤로는 바꾸지 않음
     - 위치가 없는 사진이나 차량 연결 전이면 예전처럼 장소를 검색해서 고름
     - 촬영 시간은 입력하지 않아요(사진 정보, 없으면 공유하는 시각). 버튼이 꺼져 있으면 그 아래에 이유가 나옴
     → 제목 확인 → '이 사진을 가족 지도에 공유'
  ②-1 보관·다시 공유(휴대폰 0.20.11): 내 차·WithME 가족 모두 공유된 사진을 휴대폰에 보관(추억 탭 스위치)
     노트북을 다시 켜면 두 휴대폰을 차량의 새 QR로 다시 연결 → 몇 초 안에 보관한 사진이 차량 지도와 다른 앱에 다시 나타남
  ③ 차량 지도의 촬영 위치에 제목이 붙은 큰 사진 카드가 생김
     - 처음 몇 초는 작은 미리보기로 그렸다가, 차량이 원본 사진을 받으면 선명한 사진으로 바뀜
     - 같은 장소(50 m 안) 사진은 한 카드에 'N장'으로 묶임
  ④ 카드를 누르면 원본 사진을 크게 보여 줌 → '다음 ›' / '‹ 이전', '지도에서 위치 보기', '추억 전체 보기'
  ⑤ P단이 아니거나(주행·GPS 재생, D단 정지) 목적지를 고르는 중에는 목적지 표시와 같은 크기(48dp)의
     동그란 사진으로만 표시하고 눌러도 열리지 않음. P단에서 벗어나면 큰 사진 창도 닫힘
  - 카드 크기는 지도 폭의 약 22%(사진 세로는 지도 높이의 30% 이내)이며 화면을 좁히면 함께 작아집니다.
  - 지도를 축소해 카드끼리 겹치면 한 카드로 묶어 가장 최근 사진과 'N장'을 보여 주고, 확대하면 다시 나뉩니다.

그 밖의 기능: 사용안내 51~54, docs 폴더

13. 제출용 APK 만들기 (팀 대표 한 명만)
================================================================
제출 파일: apk\모두빌리티_WithME_release.apk  (규칙: apk/팀명_앱이름_release.apk)
내용: 차량 앱(패밀리케어앱 차량용, com.familycare.navigation 0.20.15)을 팀 release 키로 서명
준비: 01_FirstSetup.cmd가 성공한 PC

13-1. 07_CreateReleaseKey.cmd (팀 전체에서 한 번)
  - 영문·숫자 8~32자 비밀번호를 두 번 입력합니다.
  - 키 파일: %USERPROFILE%\FamilyCareReleaseKey\modubility-familycare-release.jks (프로젝트 밖)
  - 서명 설정: android\keystore.properties (Git이 무시함)
  - ★ 키 파일과 비밀번호를 USB 등에 바로 백업하세요. 잃어버리면 같은 앱으로 업데이트할 수 없습니다.
  - 팀원이 이미 키를 만들었다면 새로 만들지 말고 그 .jks와 keystore.properties를 받아서
    storeFile 경로만 내 PC 위치로 고쳐 씁니다.

13-2. 08_BuildReleaseApk.cmd
  - 단위 테스트 → release 빌드 → 서명 확인을 차례로 합니다.
  - 성공하면 'Submission APK: ...\apk\모두빌리티_WithME_release.apk'와
    서명 인증서(Signer #1 certificate DN), 크기, SHA-256이 표시됩니다.
  - 이미 같은 파일이 있으면 apk\old로 옮길지 묻습니다(YES 입력). apk\old는 GitHub에 올라가지 않습니다.

13-3. 제출 전에 설치해서 확인
  ① 05 → 2 (차량 시작)
  ② cmd에서: "%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" uninstall com.familycare.navigation
     (02가 깐 개발용 앱이 있으면 서명이 달라 설치가 거절되므로 먼저 지웁니다)
  ③ "%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" install apk\모두빌리티_WithME_release.apk
  ④ 05를 다시 열고 → 6 (서버, 창 유지) → 차량에서 앱 실행 → 지도, 동승자 연결 QR, 요청 승인 확인
  ⑤ 확인이 끝나면 ②의 uninstall 명령으로 release 앱을 지운 뒤 03 → 02로 평소 시연으로 돌아갑니다.

13-4. GitHub에 올리기
  - 차량 APK가 약 90MB라 GitHub 웹 화면 업로드(25MB 제한)로는 올라가지 않습니다.
    git push 또는 GitHub Desktop을 쓰세요(100MB 미만이면 경고만 나오고 올라감).
    올라가지 않으면 GitHub Releases에 APK를 올리고 README에 그 링크를 적습니다.
  - 비공개 저장소라면 공지된 심사용 계정을 초대하고 접근을 확인합니다.
    개인 계정 저장소의 Collaborator는 쓰기 권한도 생기니, 읽기만 주려면 Organization 저장소를 쓰세요.
  - 자세히: docs\RELEASE.md
