Family Care 차량 내비게이션 0.14.0
2026-11-01

시작하는 순서
1. 시연 보조 페이지 http://127.0.0.1:8770/ 를 연다.
   서버를 다시 켠 뒤 기존 페이지에 '요청 권한을 확인하세요'가 나오면 새로고침한다.
2. 현재 위치를 지도에서 선택하고 '선택한 현재 위치 적용'을 누른다.
3. 목적지를 검색하거나 지도에서 선택한 뒤 경로를 준비한다.
4. 'GPS 주행 시작'을 누른다. 지도에서 선택한 실제 TMAP 도로 경로를 따라 차량 GPS가 이동한다.
   차량 앱에서 직접 사용할 때는 목적지 선택 → 우리 앱에서 경로 찾기 → 안내 시작 / 재개 순서다.
5. 정차하려면 시연 보조 페이지의 'P단 정차'를 누른다.
   차량에서 '경로 전체'로 둘러본 뒤 '안내 화면'을 누르면 진행 방향 추적으로 돌아간다.

주행 화면
- 진행 방향이 위로 오도록 자동으로 회전하는 TMAP 지도
- 실제 GPS를 바탕으로 경로를 따라 움직이는 차량 화살표
- 앞쪽 도로가 더 보이도록 차량을 화면 아래쪽에 배치
- 선명하고 굵은 파란 경로, 교차로 접근 시 확대
- 다음 회전 방향 / 회전까지 거리 / 도로명
- 이어지는 회전과 두 교차로 사이 거리
- 현재 속도(km/h), 남은 거리, 예상 소요 시간, 도착 예정 시각
- 기존 한국어 음성 안내, 이탈 재탐색, 목적지 도착 처리
- 기존 Family Care의 주행 중 요청 알림 유지

확인 범위
- 도착 시간은 검색 시점 교통 정보와 경로 진행률에 따른 예상이다.
- GPS 신호가 오래되거나 정확도가 낮으면 안내를 대기한다.
- 경로에서 벗어나면 실제 GPS 위치를 표시하고 재탐색한다.
- 차로, 신호등 잔여 시간, 제한 속도, 단속 카메라는 데이터가 없는 상태에서 만들지 않는다.
- 공식 지도 SDK의 공개 기능으로 구현한 진행 방향 기준 2D 안내다.
- 차량용 APK만 0.14.0으로 갱신했다. 이번 차량 화면 변경 때문에 휴대폰 앱을 다시 설치할 필요는 없다.

개발 검증 기록
- Android 단위 테스트 57개 통과
- 실제 TMAP 지도 통합 테스트 2개 통과: 지도·사진·조작 잠금 및 네 방향 카메라 추적
- 실제 GPS·TMAP 주행 통합 테스트 통과: 안내 화면, GPS 단절/회복, 이탈 재탐색, 화면 복귀 후 안내 재개, 목적지 도착
  상세 결과는 dist/demo/navigation-e2e-test.log 참조
