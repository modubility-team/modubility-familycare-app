Family Drive 차량 화면 · 태블릿 연결 0.20.0 (탭 앱 0.20.1 반영)
작성일: 2026-11-01 · 수정: 2026-11-08
2026-11-08 탭 앱 0.20.1: 실내에서도 위치가 들어오도록 GPS와 함께 Wi-Fi·기지국 위치를 씁니다. (4장, 8장)

1. 어떤 방식인가요?
노트북에서 Pleos 차량 에뮬레이터와 시연 보조 프로그램을 계속 실행합니다.
탭용 앱은 노트북의 실제 차량 화면 전체를 받아 보여 주고, 터치를 차량으로 전달합니다.
지도·길안내·가족 요청·사진·차량 기능은 기존 차량 앱 그대로 사용합니다.
탭에서 GPS를 시작하면 탭의 실제 위치를 노트북 차량 에뮬레이터로 전달합니다.
노트북만으로도 기존처럼 차량 화면 조작과 실내 GPS 자동 주행이 가능합니다.
탭만 켜서 단독으로 사용하는 독립 내비게이션 앱은 아닙니다.

2. 설치 파일 구분
이 폴더의 '04-FamilyCare-tablet-debug.apk'만 탭에 설치합니다.
앱 이름: Family Drive 차량 화면
소유자용 내 차 앱과 동승자 Family Care 앱은 기존 휴대폰에서 계속 사용합니다.
Pleos 차량용 01 APK를 일반 탭에 설치하지 마세요.

3. 연결하는 순서
① 노트북에서 평소 시연 실행 파일로 Pleos 차량과 시연 보조 화면을 켭니다.
② 탭과 노트북을 같은 Wi-Fi 또는 같은 휴대폰 핫스팟에 연결합니다.
③ 노트북 시연 보조 화면(http://127.0.0.1:8770/)의 '탭 화면·GPS 연결'을 누릅니다.
④ 탭 카메라/QR 스캐너로 '탭으로 차량 화면' QR을 스캔합니다.
⑤ '태블릿용 앱 다운로드' → 파일을 열어 설치합니다.
   이미 이 폴더의 APK를 설치했다면 다운로드 단계는 건너뜁니다.
⑥ QR로 열린 페이지로 돌아와 '설치한 앱에서 연결'을 누릅니다.
⑦ Family Drive 차량 화면 앱에서 '차량 연결'을 누릅니다.
   앱이 자동으로 열리지 않으면 QR 페이지의 연결 링크 전체를 복사해서 앱에 붙여 넣습니다.
⑧ 탭을 가로로 놓고 차량 화면을 터치합니다. 화면은 비율을 유지하므로 검은 여백이 생길 수 있습니다.
   상단 '연결 설정'으로 링크 입력 칸을 보이거나 숨길 수 있습니다.

4. 탭의 실제 위치로 시연하기
① 탭 설정에서 위치 사용을 켜 둡니다.
   실내에서 쓰려면 설정 → 위치 → 위치 서비스 → 'Google 위치 정확도'도 켭니다(Wi-Fi 위치).
② 차량 화면 연결 후 '탭 GPS 시작'을 누릅니다.
③ 안드로이드 권한 창에서 '앱 사용 중 허용'과 '정확한 위치'를 허용합니다.
④ 탭 위쪽에 '탭 위치 연결됨(GPS)', '(GPS·Wi-Fi)' 또는 '(Wi-Fi·기지국)'이 뜨는지 확인합니다.
   실외에서는 GPS를, 실내처럼 위성 신호가 없으면 Wi-Fi·기지국 위치를 전달합니다(구글 지도와 같은 방식).
   오차가 50m 이내인 위치만 전달합니다. '위치 오차 80m …'가 보이면 창가로 옮겨 잠시 기다립니다.
⑤ 탭에 보이는 차량 내비에서 목적지 검색 → 경로 선택 → 안내 시작을 누릅니다.
⑥ 탭의 실제 이동에 맞춰 차량 내비 위치와 길안내가 갱신됩니다.
   탭의 위치가 오기 전까지 차량 화면에는 'GPS 위치를 받을 수 없어요'가 보입니다.
   보조 프로그램이 오래된 위치로 차를 움직이지 않으려고 에뮬레이터 위치를 잠시 꺼 두기 때문입니다.
   (예전 차량 앱은 같은 상황에서 'GPS가 꺼졌어요. 위치 설정을 확인해 주세요'로 표시했습니다.)
   Wi-Fi 위치는 오차가 커서 실제 주행 시연은 실외(GPS)에서 하는 것이 좋습니다.

5. 실내 시연으로 돌아오기
탭 상단 'GPS 중지' → 노트북에서 현재 위치/목적지 설정 → 'GPS 주행 시작 / 재개'.
GPS가 끊겨 탭에서 중지할 수 없으면 노트북의 '탭 GPS 중지 / P단 정차'를 누릅니다.
실제 GPS 모드와 실내 자동 주행은 동시에 실행되지 않습니다.
탭 앱을 벗어나거나 화면 연결을 종료하면 GPS 전달과 터치도 중단합니다.
GPS가 오래되거나 부정확하면 차량 내비가 안내 대기로 전환합니다. 가상 이동을 이어 가지 않습니다.
(움직이는 중에는 5초, 멈춰 있을 때는 Wi-Fi 위치 간격을 고려해 15초 동안 새 위치가 없으면 전환)
실내로 전환하면 마지막 위치를 기준으로 GPS 재생이 다시 켜집니다.

6. 알아 둘 점
차량 음성과 음악은 노트북 스피커, 음성 명령은 노트북 마이크를 사용합니다.
이번 연결 앱은 탭의 소리·마이크를 차량으로 보내지 않습니다.
한 번에 탭 1대만 차량 화면에 연결합니다.
노트북이 절전 상태가 되거나 Wi-Fi가 바뀌면 연결이 끊깁니다.
보조 프로그램을 재시작하면 QR이 바뀝니다. 링크는 8시간 후 만료됩니다.
링크를 가진 같은 네트워크 기기는 차량 화면을 조작할 수 있으니 시연자에게만 보여 주세요.
연결 링크와 GPS는 외부 서버에 저장하지 않습니다. 화면/GPS 연결은 같은 Wi-Fi의 HTTP를 사용합니다.
탭 앱은 링크를 별도 파일에 저장하지 않으며 다시 켰을 때 새 QR로 연결합니다.
지도·경로 검색은 기존 TMAP 연결과 사용량을 그대로 사용합니다.
이 도구의 차량 조작 대상은 노트북 에뮬레이터입니다. 실제 차량 원격제어 연결은 아닙니다.
