# 세 앱 설치·연결 — 0.8.0

차량은 Pleos 에뮬레이터에, ② Family Drive 내 차와 ③ Family Care는 안드로이드 9 이상 휴대폰에 설치합니다. 현재 파일은 개발용 debug APK입니다.

1. 공모전 폴더의 `앱설치파일`에서 02/03 APK를 휴대폰으로 옮겨 업데이트 설치합니다. 02의 파일명에 길안내/navigation이 남아 있어도 새 앱 이름은 Family Drive 내 차입니다. 기존 앱과 서명이 같으면 데이터가 유지됩니다.
2. PC에서 `01_자동차켜기.cmd` → `08_우리앱실행.cmd`를 실행합니다.
3. PC 내부 시험은 `12_동승자서버켜기.cmd`, 실제 휴대폰 연결은 같은 신뢰 Wi-Fi에서 `13_휴대폰연결서버켜기.cmd`를 사용합니다. 둘 중 하나만 실행하세요. 노트북이 휴대폰 핫스팟에 연결되어 있어도 기기별 접근 차단 여부는 확인이 필요합니다.
4. 차량이 P단 정차 상태일 때 `요청 → 동승자 연결`을 시작합니다. 서버를 다시 켰다면 이전 연결을 종료하고 새 QR을 만듭니다.
5. 소유자는 **소유자 QR → 내 차 앱 열기 → 정보 확인하고 연결**을 누릅니다. 내 차 탭에서 별명·모델·선택적 차량 번호를 등록합니다. 등록은 휴대폰 로컬 정보이며 제조사의 소유권 인증이 아닙니다.
6. 동승자는 **가족 QR → Family Care 열기 → 정보 확인하고 연결**을 누릅니다. 링크 전체를 복사해 오른쪽 위 연결 메뉴에 붙여넣어도 됩니다.
7. 소유자 앱의 가족 탭에서 가족 초대 링크를 전달하거나 Family Care로 넘깁니다. 넘기는 링크는 가족 역할입니다. 소유자 권한은 전달되지 않습니다. 동승자 연결을 소유자로 승격하려면 차량에서 별도의 소유자 QR을 사용하세요.

휴대폰 앱 0.20.2부터 검증된 연결 정보는 Android Keystore로 암호화해 기기에 보관합니다. 홈 이동·화면 전환·앱 재실행 시 같은 기기 연결을 복원하며, 백그라운드 연결 서비스가 서버의 유효기간을 확인합니다. 승인 권한과 차량 상태는 저장해 재사용하지 않고 서버에서 다시 확인합니다. 직접 연결 해제, 서버 재시작·만료, 차량의 전체 연결 종료 시 저장 연결을 지웁니다. 운전자의 권한 회수는 즉시 반영하며 자동으로 다시 승인하지 않습니다. 백업·다른 기기 이전에서 연결 정보는 제외됩니다. 링크를 외부에 공개하지 마세요.

## 바로 확인하기

- 차량: 첫 내비 지도에서 장소를 누르고 이름을 확인한 뒤 길 안내 요청. 실제 경로선/회전 안내는 차량 기본 내비에서 확인합니다.
- 소유자: 내 차 등록 → 소유자 연결 → 관리 → 목표 온도 선택 → 차량에 적용. P단 정차·공조 전원 ON·지원 설정값 수신이 필요합니다. 시동/잠금 버튼은 연동 준비 안내입니다.
- Family Care: 요청 → 원하는 온도 → 운전자에게 요청. 차량의 요청 탭에서 승인하고 온도 적용을 누른 뒤 결과를 확인합니다. 승인 전에는 값이 바뀌지 않습니다.
- Family Care: 요청 탭의 지도에서 장소 선택·제안. 차량에서 정차 후 승인합니다. 홈의 휴식/음악 등 버튼은 한마디 요청입니다.
- 반려동물: 차량의 가족 구성에서 반려동물을 선택하고 확인 타이머 시작 → Family Care 반려동물 탭에서 상태·남은 시간·직접 확인 알림 확인.
- 추억: 사진 선택 → 촬영 위치/시간 확인 → 가족 지도에 공유. 당일 사진은 차량 내비 지도에도 표시됩니다. 위치/시간이 없는 사진은 직접 입력합니다. 공유는 세션 종료 시 삭제됩니다.

## 연결 문제와 종료

휴대폰 링크가 127.0.0.1이면 PC용 QR입니다. 13번 서버로 전환하고 새 연결을 만드세요. 방화벽은 자동 변경하지 않습니다. 회사/공용 Wi-Fi가 기기 간 접근을 막을 수 있습니다. 실물 휴대폰 연결·EXIF 권한 동작은 기기에서 확인해야 합니다.

QR 웹페이지는 기본 요청과 설치 앱 연결용입니다. 새 온도 조절·차량 등록·사진 지도를 사용하려면 최신 APK를 설치하세요. 스마트폰 앱의 상태 갱신은 화면을 열어 둔 동안만 동작하며 SMS/전화/백그라운드 푸시가 아닙니다.

종료: 차량에서 이동·타이머·모든 연결 종료 → 서버 창 Ctrl+C → 04_자동차끄기.cmd.
