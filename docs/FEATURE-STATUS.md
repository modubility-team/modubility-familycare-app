# WithME(위드미) 기능별 구현 상태

팀 모두빌리티 · 2026-11-09 기준 (차량 앱 0.20.15, 휴대폰 앱 0.20.12, 태블릿 앱 0.20.1)
기획서의 기능 표기는 이 표와 같아야 합니다. 공모전 유의사항에 따르면 서류 내용이 사실과 다를 경우 선정이 취소될 수 있습니다.

- 구현: 코드에 있고 Pleos 에뮬레이터에서 동작을 확인한 기능
- 일부: 동작하지만 조건이 붙거나 실기기 시험을 하지 않은 기능
- 계획: 아직 구현하지 않은 기능

| 기획 기능 | 상태 | 기획서에 쓸 때 |
| --- | --- | --- |
| 가족 프로필·탑승 구성 저장, 모드 추천 | 구현 | 그대로 |
| 반려동물 케어: 온도·배터리·문/창문 확인, 확인 타이머, 단계별 알림 | 구현 | 시동이 꺼진 상태의 동작은 에뮬레이터에 신호가 없어 실차 확인 전이라고 적기 |
| 반려동물 공조 보조 | 구현 | 정차·확인 타이머·공조 전원·배터리 25% 초과 조건에서만 동작한다고 적기 |
| 실내 카메라 확인 | 일부 | 차량 카메라가 아니라 여분 휴대폰을 IP 카메라로 연결하는 선택 기능이며, 휴대폰 앱에서만 본다고 적기 |
| QR 동승자 연결, 좌석별 권한 요청, 운전자 승인 | 구현 | 그대로 |
| 내 차 앱과 WithME 가족 앱 역할 분리 (0.20.7) | 일부 | 내 차 앱은 소유자 QR만(차량 관리·권한 승인·픽업 공유), WithME 가족는 가족·손님 QR만(권한 요청·픽업 대기 위치) 연결한다고 적기. 휴대폰 실기기 확인 전 |
| 공조·시트·문·창문 조절 요청 | 구현 | 연결된 차량과 좌석이 지원하는 항목만 가능하다고 적기 |
| 목적지·경유지 제안, 가족 투표, 픽업 요청 | 구현 | 경유지는 한 번에 한 곳 |
| 가족 이동 기준 경로 비교·실시간 반영 (0.20.9) | 일부 | 가족이 고른 기준(빠른 도착·방향 전환 적게·화장실·반려견 산책·쉬어 갈 장소)으로 TMAP 후보를 비교. ‘목적지·경유지 변경’ 권한이 있는 가족이 보내면 안내 중인 경로를 바로 바꾸고 음성으로 알림, 권한이 없으면 운전자가 정차 중에 비교해 선택. 경유지는 P단 정차 중에만 자동 추가(주행 중에는 운전자가 음성으로 추가). 방향 전환 수는 후보끼리의 비교이며 멀미 예방 효과가 아니라고 적기. 에뮬레이터 화면 확인 전 |
| 자연어 음성 경유 | 구현 | 버튼을 누른 뒤에만 듣고, 가족이 보낸 장소의 경유 요청을 해석한다고 적기 |
| 음성 목적지 검색·안내 (0.20.7) | 일부 | ‘강남역으로 안내해 줘’처럼 말하면 TMAP 검색 → 애매하면 번호로 선택 → 경로 안내. 문장 규칙으로 해석하며 에뮬레이터 실제 음성 시험 전이라고 적기 |
| 음악 소리 줄이기 요청, 휴대폰 음악 공유 | 일부 | 실제 휴대폰에서의 음악 공유는 시험 전 |
| 운전 피드백: 급가속·급감속·급조향 집계, 주행 알림 | 구현 | 그대로 |
| 휴식 제안 | 구현 | 그대로 |
| 상황별 케어의 지정 휴게소 (0.20.10, 0.20.15) | 일부 | 남은 경로 전체에서 앞쪽 휴게소만 검색(TMAP 경로 반경 검색, 안 되면 경로를 따라 최대 8곳 검색, 경로 옆 1 km 안, 가까운 순). 운전자가 화면에서 승인하면 목적지·안내를 유지한 채 경유지로 추가. 가족이 고른 휴게소를 차량 경유지 요청으로 전달하고, 내비 예상 시간으로 '지정 휴게소 도착까지 N분' 표시, 도착 시 가족 알림. 주행 중 경유 추가는 운전자 음성 승인. 휴게소의 실제 시설·영업 여부는 직접 확인하라고 적기. 에뮬레이터 화면 확인 전 |
| 멀미 케어 참고지수 | 구현 | 최근 급조작 빈도로 계산한 참고 지표이며 의학적 판단이 아니라고 적기 |
| 동승자 휴대폰의 진행률·남은 시간·도착 알림 | 구현 | 그대로 |
| 하차 후 뒷좌석 확인 | 구현 | 운전석 문 열림 등으로 직접 확인을 안내하는 기능이며, 탑승자를 감지하지 않는다고 적기 |
| 추억 사진 지도, 이동 기록 | 구현 | 기기에 저장하고 연결 중에만 공유한다고 적기 |
| 차량 지도의 추억 사진 카드 (0.20.12) | 일부 | P단 정차 중에만(길안내 중 포함) 제목이 붙은 큰 사진 카드(지도 폭 약 22%, 원본 사진), 주행 중·P단이 아닐 때는 48dp 동그란 사진(누를 수 없음), 지도를 축소해 겹치는 사진은 한 카드로 묶음, 누르면 원본 크게 보기·이전/다음. 에뮬레이터 화면에서 확인한 뒤 '구현'으로 바꾸기 |
| 추억 사진 휴대폰 보관·다시 공유 (휴대폰 0.20.11) | 일부 | 두 휴대폰 앱이 세션의 사진을 앱 전용 저장소에 최근 30장 보관, 노트북 재시작·재연결 후 새 세션에 최신순으로 다시 공유(세션당 12장), 같은 세션에서 삭제된 사진은 잊음, 끄기 스위치. 촬영 시간 입력 칸 없앰(사진 정보 또는 공유 시각). 휴대폰 2대와 에뮬레이터로 확인한 뒤 '구현'으로 바꾸기 |
| 추억 사진 장소 자동 채우기 (0.20.13) | 일부 | 사진의 촬영 위치(EXIF GPS)로 TMAP 주소 변환·근처 1 km 이름 검색 → 300 m 안의 장소를 '선택한 장소'·검색칸·결과 목록·사진 제목(직접 고치지 않았을 때만)에 채움. 위치가 없거나 차량 연결 전이면 예전처럼 직접 검색. 실제 TMAP 응답과 휴대폰 화면에서 확인한 뒤 '구현'으로 바꾸기 |

| 뒷좌석 아이 카메라 모니터링 | 계획 | [계획]으로 표시 (Pleos에 차량 카메라 API가 없음) |
