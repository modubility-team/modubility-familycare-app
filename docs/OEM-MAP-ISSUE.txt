Pleos 기본 내비 빈 지도 — 조사 및 문의 초안
2026-10-27 / 아직 해결되지 않음 / 외부에 전송하지 않은 초안

환경
- Windows, Pleos Connect 2.1.0 / Android Automotive API 34
- Navi42 ai.umos.maps.android.navigation.app 3.3.2-rc5-hotfix.3
- NVIDIA RTX 4060 Laptop + Intel UHD, 원래 GPU host 모드

증상
OEM 내비의 기본 지도 배경이 비어 있습니다. 위치 화살표, 경로선, 회전 카드와 UI는 표시됩니다.
우리 앱의 MapLibre/OpenFreeMap 지도와 HTTPS 경로 조회는 같은 에뮬레이터에서 정상 동작합니다.

실제로 확인한 내용
- Android 네트워크 인터넷 검증 상태 및 기본 내비 위치 권한 확인.
- Android LocationManager가 에뮬레이터에서 보낸 GPS 좌표를 받는 것 확인.
- 기본 내비 프로세스 재시작 후에도 재현.
- cold boot 및 GPU host/SwiftShader 비교 모두 빈 지도 재현. 이후 host로 복원.
- 로그에 NMEA checksum mismatch 반복. 에뮬레이터가 생성한 NMEA가 *47로 끝남.
  이 경고가 빈 배경 지도의 직접 원인인지는 입증되지 않았습니다.
- 이전 관찰에서 지도 요청 401 후 토큰 갱신·304 응답이 있었으나 인증 문제가 확정된 것은 아닙니다.
- cache-only 삭제 명령은 완료를 확인하지 못했으므로 캐시 삭제 성공으로 기록하지 않습니다.

공급자 확인이 필요한 질문
1. 이 에뮬레이터 이미지의 OEM 기본 지도는 일반 개발자 환경에서 지원되는 기능인가요?
2. 별도의 지도 서비스 등록/권한/인증 또는 최신 이미지/수정 APK가 필요한가요?
3. 기본 내비 지도 데이터 캐시를 사용자 데이터 손실 없이 복구하는 공식 절차가 있나요?
4. 기본 NMEA 체크섬 오류와 지도 미표시를 해결하는 알려진 이미지 버전이 있나요?
