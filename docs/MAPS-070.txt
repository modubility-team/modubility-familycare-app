Family Care — 지도 사용법·외부 API 규정 / 0.7.0 / 2026-10-27

1. 어디에서 켜나요?
차량 앱: 정차 상태 → 이동 홈 → 내비 바로가기 → 앱 안 지도.
스마트폰 길안내 앱: 이동 탭 또는 장소 탭에서 지도 표시.
케어 앱과 동승자 웹은 기존 상태/요청 화면을 유지합니다.
PC의 앱설치파일 폴더에 최신 차량/길안내/케어 APK를 모았습니다.
친구는 최신 코드를 pull하고 FamilyCare.cmd 4번으로 빌드해도 됩니다.

2. 사용 순서
인터넷이 연결되어 있으면 지도에 실제 도로·건물·지명이 표시됩니다.
손가락으로 이동하고 +/− 버튼이나 두 손가락으로 확대/축소합니다.
기본 화면은 공개 SDK 예제 위치인 서울 42dot 주변입니다. 내 현재 위치가 아닙니다.
차량: 지도를 눌러 목적지 선택 → 이름 확인 → 이곳으로 길 안내 요청.
Pleos가 반환한 실제 활성 경로와 목적지 이름·좌표까지 맞아야 확인 완료로 표시합니다.
스마트폰: 지도 누르기 → 장소 화면에 이름·위도·경도 자동 입력 → 저장 또는 차량에 제안.
차량 제안은 연결 및 역할 권한이 있어야 보낼 수 있고 운전자가 정차 후 승인합니다.
지도만 보는 데 차량 연결/QR은 필요 없습니다. 지도 인터넷 연결은 필요합니다.

3. 이번에 구현한 범위
MapLibre Native Android 12.2.0 + OpenFreeMap Liberty 온라인 벡터 지도.
지도 표시·이동·확대/축소·장소 선택·핀·좌표 입력·기존 Pleos 내비 연동.
이 지도 자체에 경로선·실시간 교통·회전 지시·자동 GPS 추적은 아직 없습니다.
경로 계산/길 안내 요청은 Pleos NaviHelper 3.0.5를 통해 기존 차량 내비가 처리합니다.
외부 지도 앱 검색은 기존대로 별도 실행되며 검색 결과를 자동으로 가져오지 않습니다.
실물 휴대폰/실차 주행과 실제 목적지 도착은 이번 에뮬레이터 검증 범위 밖입니다.
차량 앱의 상세 지도/입력은 주행 제한 또는 제한 상태 미확인 때 숨깁니다.

4. 공모전 API 제한 확인 결과
공식 이용약관 제7조 2항은 코드·라이브러리·데이터 등의 적법한 권리 확보를 요구합니다.
제7조 7항은 오픈소스 라이선스 준수와 출처 표시를 요구합니다.
가이드·FAQ·출품 공지에서 모든 외부 API를 일괄 금지하는 조항은 찾지 못했습니다.
이는 특정 지도 서비스에 대한 주최 측의 개별 승인을 받았다는 뜻은 아닙니다.
제출 자료에 사용 SDK/API와 출처를 쓰고, 최신 공지와 공급자 이용 조건을 다시 확인합니다.
Pleos API 권한 선언 및 공급자 권한 검토는 별도로 적용됩니다.
MapLibre/지도 도입을 이유로 GPS·마이크·카메라 권한을 추가하지 않았습니다.

5. 비용·키·출처·네트워크
현재 OpenFreeMap 공개 인스턴스는 계정/API 키 없이 사용합니다.
호출 URL: https://tiles.openfreemap.org/styles/liberty
지도의 고지: OpenFreeMap / © OpenMapTiles / © OpenStreetMap contributors.
고지 링크를 지도 아래 표시하고 MapLibre BSD-2-Clause 전문을 앱의 오픈소스 고지에 포함했습니다.
지도·스타일·글꼴·스프라이트는 공급자 서버에서 HTTPS로 받습니다.
조회한 지도 영역에 해당하는 타일 요청과 접속 IP가 공급자/CDN에 전달됩니다.
가족 프로필·동승자 메시지·차량 신호·연결 토큰은 지도 공급자에게 전송하지 않습니다.
GPS 현재 위치나 위치 이동 이력을 수집하지 않습니다. 선택 장소는 기존 앱 저장/제안 기능에 사용합니다.
공개 지도 서버는 무중단/가용성을 보증하지 않습니다. 네트워크 실패 시 재시도 안내가 나옵니다.
지도 대량 다운로드·오프라인 지역 저장 기능은 만들지 않았습니다.
OpenFreeMap 공급자 약관상 통합 이용자는 만 18세 이상이어야 합니다.
