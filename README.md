## 1. 앱 이름 및 한 줄 소개

**WithME(위드미)** — 동승자가 휴대폰으로 요청하고 운전자가 승인하는 방식으로 차량 조작·길안내를 나누고, 아이·반려동물·초보운전 등 가족 구성에 맞춰 이동을 돌보는 Pleos 차량 앱입니다.

세 개의 앱이 함께 동작합니다.

| 앱 | 설치 위치 | 역할 |
| --- | --- | --- |
| WithME (제출 APK) | Pleos 차량 (에뮬레이터) | 지도·길안내, 요청 승인, 가족 구성·케어, 주행 피드백, 음성 명령 |
| WithME 내 차 | 차주 휴대폰 | 차량 상태 확인, 정차 중 공조 설정, 가족 권한 관리, 픽업용 차량 위치 공유 |
| WithME 가족 | 동승자·가족 휴대폰 | 좌석별 권한 요청, 온도 등 조절 요청, 장소 제안·투표, 픽업 대기, 상황별 케어, 반려동물·추억 |

### 주요 기능

- **동승자 연결과 권한 요청**: 차량 화면의 QR로 휴대폰 앱을 연결합니다. 동승자가 좌석·기능·허용 범위를 골라 운전자에게 요청하고, 운전자가 승인한 범위 안에서만 온도·바람, 시트·열선, 문·창문, 길안내를 조절할 수 있습니다. 결과는 `적용 대기 → 반영 완료 / 적용 안 됨 / 결과 미확인`으로 보여 줍니다.
- **가족 길안내**: TMAP 지도와 자동차 경로를 씁니다. 동승자의 장소 제안·가족 투표·픽업 요청을 운전자가 승인하면 원래 목적지를 유지한 채 경유지로 추가합니다.
- **타기 전 픽업**: 차주가 픽업용 차량 위치 공유를 켜면, 기다리는 가족이 다가오는 차량을 지도로 보고 자기 대기 위치(가게·출입구)를 보냅니다. 운전자는 음성으로 경유지에 넣습니다.
- **음성 명령**: 운전자가 `말하기`를 누르고 "강남역으로 안내해 줘", "가족이 보내준 데 잠깐 찍고 가자", "화장실 찾아 줘"처럼 말하면 목적지 안내·경유지 추가·주변 검색을 합니다. 후보가 여럿이면 번호로 고르고, 애매하거나 부정하는 말은 실행하지 않습니다.
- **가족 이동 기준 경로 (0.20.9)**: WithME 가족에서 '빠른 도착·방향 전환 적게·화장실·반려견 산책·쉬어 갈 장소'를 골라 보내면 차량이 TMAP 경로 후보를 비교합니다. ‘목적지·경유지 변경’ 권한을 받은 가족이 보내면 안내를 멈추지 않고 경로를 바로 바꾼 뒤 음성으로 알려 줍니다. 화장실·휴게소 같은 경유지는 P단 정차 중에만 자동으로 넣고, 주행 중에는 운전자가 음성으로 추가합니다.
- **상황별 케어와 지정 휴게소 (0.20.10 · 남은 경로 검색 0.20.15)**: '아이가 잠들었어요' 같은 상황을 켜면 가족의 일반 요청을 운전자 대신 동승 보호자가 먼저 받습니다(30초 안에 확인하지 않으면 운전자에게). 가족이 경로 앞쪽 휴게소를 지정하면 차량 내비에 경유지로 전달되고, 차량과 휴대폰에 '지정 휴게소 도착까지 N분'이 내비 예상 시간으로 표시됩니다. 휴게소는 차량의 남은 경로 전체에서 앞쪽에 있는 곳만 가까운 순서로 찾아 주고, 운전자가 승인하면 최종 목적지와 안내는 그대로 두고 경유지로 추가합니다.
- **주행 중 안전 제한**: 주행 제한 상태에서는 지도·회전 안내·안전 알림만 남기고 상세 화면·QR·입력을 숨깁니다. 주요 안내는 한국어 음성으로 알려 줍니다.
- **가족 구성과 운전 피드백**: 아이·어르신·임산부·반려동물·초보운전자 구성을 저장·전환하고 모드를 추천합니다. 속도·조향 변화로 가속·감속·조향 횟수를 집계하고, 주행 시간에 따라 휴식을 제안합니다.
- **반려동물·실내 확인**: 온도·배터리·문/창문 상태와 확인 타이머를 보여 주고, 데이터가 오래되면 '미확인'으로 표시합니다. 휴대폰 앱에서는 선택적으로 IP 카메라 화면을 볼 수 있습니다. 차량 앱에는 영상 화면을 넣지 않았습니다(Pleos 내비게이션 앱 가이드).
- **하차 후 뒷좌석 확인과 도착 알림**: 운전석 문 열림과 이동 종료 시 뒷좌석을 직접 확인하도록 안내하고, 목적지에 도착하면 백그라운드 알림을 켠 가족 휴대폰에 '차량이 목적지에 도착했어요'를 보냅니다.
- **추억 기록 (사진 카드 0.20.12 · 장소 자동 채우기 0.20.13)**: 사진의 촬영 위치·시간으로 차량 지도와 가족 지도의 그 자리에 추억 사진을 남기고, 최근 이동 기록을 기기에 저장합니다. 차량 지도에서는 P단 정차 중일 때만(길안내 중 휴게소 포함) 제목이 붙은 큰 사진 카드(지도 폭의 약 22%)로 보여 주고, 주행 중이거나 P단이 아니면 목적지 표시와 같은 크기(48dp)의 동그란 사진으로 줄이고 누를 수 없게 합니다. 카드를 누르면 원본 사진을 크게 보고 이전/다음으로 넘겨 볼 수 있으며, 같은 장소의 사진이나 지도를 축소해 서로 겹치는 사진은 한 카드에 'N장'으로 묶습니다. 사진에 촬영 위치가 있으면 그 위치의 주소와 근처 장소 이름을 TMAP으로 찾아 장소 검색칸·선택한 장소·사진 제목을 자동으로 채웁니다(0.20.13, 직접 고치거나 다른 장소를 고를 수 있음). 촬영 시간은 사진 정보에서 읽고, 없으면 공유하는 시각으로 남깁니다. 내 차 앱과 WithME 가족 앱은 공유된 사진을 각자 휴대폰에도 보관해, 노트북을 다시 켜거나 다시 연결하면 보관한 사진을 차량과 다른 앱에 자동으로 다시 공유합니다(0.20.11 휴대폰, 끌 수 있음).
- **외부 연결·태블릿 (시연 도구)**: Cloudflare 임시 주소로 다른 Wi-Fi·LTE에서도 휴대폰을 연결하고, 태블릿에 차량 화면을 띄워 터치·GPS를 전달할 수 있습니다.

### 시스템 구성

```
[휴대폰: 내 차 / WithME 가족] ── 같은 Wi-Fi(http) 또는 외부 연결(https) ──▶ [노트북 연결 서버  companion/server.py :8765]
                                                                              │  adb reverse
[Pleos 에뮬레이터: 차량 앱 com.familycare.navigation] ◀────────────────────────┘
노트북: TMAP 키 보관·지도 API 중계, 음성 문장 뜻 해석(E5 모델), 시연 보조 화면 http://127.0.0.1:8770/
```

노트북 한 대가 '자동차(에뮬레이터) + 연결 서버' 역할을 합니다. 휴대폰은 이 노트북에 접속해 차량과 대화합니다.

### 2-1. 준비물

| 준비물 | 조건 |
| --- | --- |
| Windows 노트북 | Windows 10/11 64비트, Intel/AMD CPU, BIOS 가상화 켜짐, RAM 16 GB 권장, 여유 공간 30 GB |
| Android 휴대폰 | Android 9 이상, 1~3대. 한 대에 '내 차'와 'WithME 가족'를 같이 깔아도 됩니다 |

### 2-2. 처음 한 번: 노트북 설치

1. **프로그램 3개 설치**
   - [Android Studio](https://developer.android.com/studio/install): 첫 실행 마법사는 Standard.
   - [Temurin JDK 17](https://adoptium.net/temurin/releases/?version=17&os=windows&arch=x64): Windows x64 `.msi`를 기본값으로 설치. Android Studio 안의 JDK는 쓰지 않으니 꼭 따로 설치합니다.
   - [Python 3.12.10 (64-bit)](https://www.python.org/downloads/windows/): 설치 첫 화면 맨 아래 `Add python.exe to PATH`를 체크하고 `Install Now`. 3.14 같은 최신판이 아니라 3.12를 받습니다.
2. **Android SDK 항목**: Android Studio 첫 화면 → `More Actions` → `SDK Manager`
   - `SDK Platforms`: Android 15 (API 35)
   - `SDK Tools` (`Show Package Details` 체크): Build-Tools 35.0.0, Android Emulator, Platform-Tools, Command-line Tools
3. **Pleos 차량 이미지**: SDK Manager → `SDK Update Sites` → `+`
   - URL: `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml`
   - `SDK Platforms` → Android 14 (API 34) 펼치기 → `Pleos Connect system image` 설치 → Android Studio 재시작
4. **가상 차량(AVD) 만들기**: `Device Manager` → `+` → Automotive → `Pleos Connect v2.1.0` → API 34 이미지
   - 이름: `FamilyCare_Pleos`, Boot: `Cold boot`, RAM: `4 GB`
   - 이름에 'pleos'가 들어간 AVD는 하나만 둡니다. 미리 켜 둘 필요는 없습니다.
5. **코드 받기와 TMAP 키**
   - 이 저장소를 받습니다: `git clone` 또는 GitHub `Code` → `Download ZIP` → 압축 풀기 (예: `C:\FamilyCare`). OneDrive와 동기화되는 폴더는 피합니다.
   - 저장소 맨 위의 `tmap.local.example.json`을 같은 폴더에 복사해 이름을 `tmap.local.json`으로 바꾸고 `app_key`에 본인 TMAP 앱 키를 넣습니다. `enabled`와 `map_sdk_enabled`는 `true`로 둡니다.
   - 이 파일은 `.gitignore`로 저장소에 올라가지 않습니다.
6. **`01_FirstSetup.cmd` 더블클릭**: 창을 닫지 말고 끝까지 기다립니다(처음 10~30분).
   - Python 패키지, 음성 이해 모델 실행환경, TMAP 지도 SDK, Android 라이브러리를 준비하고 앱 4개를 빌드합니다.
   - **성공 확인**: `Setup complete. Close this window and run 02_StartDemo.cmd.`
   - 빨간 `SETUP INCOMPLETE: (이유)`가 나오면 RUN-GUIDE 14장에서 같은 문장을 찾습니다.
   - 자동으로 설치 위치를 못 찾으면 `familycare.local.example.json`을 `familycare.local.json`으로 복사해 경로를 적습니다.

### 2-3. 시연 켜기

1. 노트북과 휴대폰을 **같은 Wi-Fi**에 연결합니다.
2. 그 Wi-Fi를 **개인 네트워크**로 바꿉니다: Windows 설정 → 네트워크 및 인터넷 → Wi-Fi → 연결된 Wi-Fi 속성 → 네트워크 프로필 유형 `개인 네트워크`.
3. **`00_한번에켜기.cmd`** 를 더블클릭합니다. (단계별로 켜려면 `02_StartDemo.cmd`)
   - 휴대폰용 네트워크가 여러 개면 휴대폰과 같은 Wi-Fi의 번호를 고릅니다. 휴대폰이 다른 Wi-Fi나 LTE를 쓰면 `0`을 고르면 외부 연결을 자동으로 켭니다.
   - 처음 실행할 때 **Windows 방화벽 창(Python)** 이 뜨면 `개인 네트워크`만 체크하고 `액세스 허용`을 누릅니다. 이 창을 취소하면 휴대폰이 노트북에 접속하지 못합니다.
4. 몇 분 뒤 다음 세 가지가 보이면 준비 끝입니다.

| 화면 | 위치 | 내용 |
| --- | --- | --- |
| 차량 에뮬레이터 창 | 노트북 | 차량 앱 `WithME`이 켜진 차량 화면. **이 창은 닫지 않습니다** |
| 시연 보조 화면 | 노트북 브라우저 `http://127.0.0.1:8770/` | 가상 주행, 휴대폰 연결 QR, 외부 연결 |
| 명령 창 | 노트북 | `준비 완료!`와 휴대폰 앱 설치 주소 (`02`로 켰다면 `Ready: http://127.0.0.1:8770/`) |

처음 실행하면 바탕화면에 `WithME 시연 켜기` / `WithME 시연 끄기` 버튼이 생깁니다. 다음부터는 이 버튼만 누르면 됩니다.

### 2-4. 휴대폰 앱 설치

| 누구 휴대폰 | 설치할 파일 | 휴대폰에 보이는 앱 이름 |
| --- | --- | --- |
| 차주(운전자) | `02-FamilyCare-navigation-debug.apk` | **WithME 내 차** |
| 동승자·가족 | `03-FamilyCare-care-debug.apk` | **WithME 가족** |
| (설치하지 않음) | `01-FamilyCare-vehicle-debug.apk` | 차량용. 시연을 켤 때 에뮬레이터에 자동 설치됩니다 |

설치 방법 (둘 중 하나)

- **휴대폰 크롬에서 받기 (가장 쉬움)**: 시연이 켜진 상태에서 휴대폰 크롬 주소창에 직접 입력합니다. `<노트북 주소>`는 명령 창에 나온 `http://192.168.x.x:8765`의 숫자입니다.
  - 내 차: `http://<노트북 주소>:8765/install/owner.apk`
  - WithME 가족: `http://<노트북 주소>:8765/install/family.apk`
  - 다운로드 → 열기 → `출처를 알 수 없는 앱 설치` 허용 → 설치. Play 프로텍트 경고가 뜨면 `세부정보` → `무시하고 설치`.
- **USB로 옮기기**: `04_OpenApks.cmd`를 실행하면 `dist\apk` 폴더가 열립니다. 파일을 휴대폰 '다운로드' 폴더에 복사해 설치합니다.

`기존 패키지와 충돌`이 뜨면 다른 PC에서 만든 앱이 깔려 있는 것입니다. 기존 앱을 지우고 다시 설치합니다.

### 2-5. QR로 휴대폰 연결 (필수)

휴대폰 앱은 QR을 찍어야 차량과 연결됩니다. QR은 두 곳에서 볼 수 있고, 어느 쪽을 찍어도 됩니다.

| QR이 나오는 곳 | 여는 방법 |
| --- | --- |
| **A. 노트북 시연 보조 화면** (권장) | 브라우저 `http://127.0.0.1:8770/` → `같은 Wi-Fi · 휴대폰 앱 연결` 카드 |
| **B. 차량 화면** (실제 차처럼) | 차량 앱 왼쪽 메뉴 `요청` → `동승자 연결` 카드 → (처음이면 `동승자 연결` → 동의) → `QR 보기` → 위쪽 `소유자 / 가족 / 손님 / 상태 확인` 중 선택. 주행 중에는 QR이 숨겨지니 P단 정차 중에 엽니다 |

어떤 QR을 어느 앱으로 찍는지가 중요합니다.

| QR 종류 | 찍는 휴대폰 → 열리는 앱 | 할 수 있는 일 |
| --- | --- | --- |
| **소유자** (보조 화면 `소유자 · 내 차`) | 차주 휴대폰 → **내 차** | 차량 관리, 정차 중 공조, 가족 권한 관리, 픽업용 위치 공유. 차주에게만 보여 줍니다 |
| **가족** (보조 화면 `동승자 · WithME 가족`) | 동승자 휴대폰 → **WithME 가족** | 권한 요청, 조절 요청, 장소 제안·투표, 픽업, 상황별 케어, 추억 |
| 손님 | WithME 가족 | 한마디 요청과 차량 상태 보기만 |

연결 순서

1. 휴대폰이 노트북과 **같은 Wi-Fi**인지 확인합니다. 확실히 하려면 모바일 데이터를 잠시 끕니다.
2. 휴대폰 **기본 카메라**로 QR을 찍고, 화면에 뜬 주소를 엽니다. 주소는 `http://192.168.x.x:8765/...`처럼 노트북의 Wi-Fi 주소로 시작해야 합니다.
3. 열린 웹페이지 아래쪽 **`설치된 휴대폰 앱으로 열기`** 를 눌러 펼친 뒤, 나온 버튼(`소유자 · 내 차 앱 열기` 또는 `동승자 · WithME 가족 열기`)을 누릅니다.
4. 앱이 열리면 **`정보 확인하고 연결`** 을 누릅니다.
5. **성공 확인**: 앱 오른쪽 위 버튼이 `연결됨`으로 바뀝니다.

알아 둘 점

- 주소가 `127.0.0.1`로 시작하면 노트북 전용 주소라 휴대폰에서 열리지 않습니다. 네트워크 선택을 다시 하거나 외부 연결을 씁니다.
- 다른 앱의 QR을 찍으면 연결하지 않고 맞는 앱으로 넘기는 버튼을 보여 줍니다.
- 시연을 다시 켜면 QR이 바뀝니다. 예전 QR은 쓰지 않습니다.
- 연결은 최대 2시간입니다. 지나면 시연 보조 화면의 `차량 연결 복구` → 새 QR로 다시 연결합니다.

#### 같은 Wi-Fi를 쓸 수 없을 때 (외부 연결)

학교·카페 같은 공용 Wi-Fi이거나 휴대폰이 LTE만 될 때는, 시연 보조 화면 오른쪽 `다른 Wi-Fi · LTE · 5G로 연결` 카드 → `외부 연결 시작` → 준비되면 나오는 **외부 소유자 / 외부 동승자 QR**을 찍습니다(`00_한번에켜기.cmd`에서 `0`을 골랐다면 자동으로 켜집니다). 이후 순서는 위와 같습니다. 주소는 `https://….trycloudflare.com`이고 다시 시작하면 바뀝니다.

### 2-6. 동승자 권한 받기 (필수)

WithME 가족로 차량을 조절하거나 경로를 바꾸려면, 먼저 동승자가 권한을 요청하고 운전자가 차량에서 승인해야 합니다. 승인은 **차량이 P단 정차 중일 때만** 됩니다.

**동승자 휴대폰 (WithME 가족)**

1. 아래쪽 탭 **`권한`** 을 누릅니다.
2. **1 좌석**: 내 좌석(예: 조수석)과 이름(예: 엄마)을 고릅니다.
3. **2 기능**: 분류를 펼쳐 쓸 기능을 체크합니다. `이 분류 모두 추가`로 한꺼번에 고를 수 있습니다.
4. **3 확인**: 고른 항목을 확인하고 **`운전자에게 N개 권한 요청`** 을 누릅니다. 위쪽에 `권한을 요청했어요`가 뜹니다.

**차량 화면**

5. 오른쪽 아래에 `동승자 요청이 도착했어요` 카드가 뜹니다 → `요청 확인` (또는 왼쪽 메뉴 `요청`).
6. `받은 요청`에서 항목과 허용 범위(예: 온도 18~28°C)를 확인합니다. 필요 없는 항목은 체크를 빼거나 범위를 좁힐 수 있습니다.
7. **`선택한 권한 승인`** 을 누릅니다. 휴대폰 홈의 `차량 조절 권한` 줄에 `승인 완료`가 보이면 끝입니다.

기능별로 필요한 권한

| 해 보려는 기능 | 승인받을 권한 (분류 → 항목) |
| --- | --- |
| 조수석 온도 조절 | 온도·바람 → 내 좌석 설정 온도 |
| 장소 제안, 가족 기준으로 경로 바로 바꾸기 | 길안내 → 목적지·경유지 변경 |
| 상황별 케어, 지정 휴게소, 보호자 알림 | 가족·반려동물 케어 → 상황별 케어와 보호자 알림 (보호자 휴대폰도 같은 권한) |
| 반려동물 확인 타이머 | 가족·반려동물 케어 → 반려동물 확인 타이머 |

권한은 이번 차량 연결이 끝날 때까지 유지됩니다. 픽업 대기 위치 보내기와 한마디 요청은 권한 없이도 됩니다.

### 2-7. 주행 상황 만들기

에뮬레이터에는 실제 도로가 없으므로, 시연 보조 화면이 위치와 주행 상태를 만들어 줍니다.

1. **현재 위치**: 시연 보조 화면 `1. 지도에서 현재 위치와 목적지 선택` → `현재 위치 고르기` → 지도 클릭 또는 검색 → `선택한 현재 위치 적용` (자동으로 P단 정차).
2. **이동 시작**: 차량 화면 아래 `이동 시작` → `확인하고 이동 시작`. 안내를 시작하면 이 버튼이 숨겨지므로 먼저 누릅니다. 이걸 해야 휴대폰에 '함께 이동 중'과 남은 시간·거리가 나옵니다.
3. **목적지**: 차량 화면 `어디로 갈까요?` → 검색 → 결과 선택 → `경로 찾기` → `안내 시작 / 재개`. (보조 화면 `목적지 고르기` → `선택한 목적지로 길찾기`도 됩니다.)
4. **주행**: 보조 화면 `2. 차량 앱의 경로로 GPS 재생` → 속도(20/40/80/120 km/h) → **`GPS 주행 시작 / 재개`**. 차량이 경로를 따라 움직이고, 차량 화면은 주행 중 제한 화면으로 바뀝니다.
5. **정차**: `P단 정차 / 안내 일시정지`. 권한 승인·QR·확인 타이머처럼 정차 중에만 되는 기능을 볼 때 씁니다.

**음성 명령을 쓰려면** 에뮬레이터 오른쪽 도구막대 `⋯` → `Microphone` → `Virtual microphone uses host audio input`을 켭니다. `00_한번에켜기.cmd`는 이 설정을 자동으로 켜고, 안 되면 노란 `마이크:` 안내를 띄웁니다. Windows 설정 → 개인정보 및 보안 → 마이크 → 데스크톱 앱의 마이크 사용도 켜져 있어야 합니다. 차량 화면 아래 `음성 명령` → `말하기`를 누른 뒤 말합니다.

### 2-8. 기능별로 따라 해 보기

2-5(연결)와 2-6(권한)을 마친 뒤 해 봅니다. '주행 중'은 2-7의 GPS 재생 중, 'P단'은 정차 중을 뜻합니다.

| 기능 | 순서 | 확인할 결과 |
| --- | --- | --- |
| 조수석 온도 조절 | WithME 가족 홈 `운전자에게 요청` → `시원하게` 또는 `따뜻하게` (0.5°C씩) | 휴대폰 위 `조수석 21°C · 반영 완료`, 차량 아래쪽 조수석 온도 변경 |
| 타기 전 픽업 | ① 차주: 내 차 앱 `가족` 탭 → `타기 전 픽업` → `픽업용 차량 위치 공유 켜기` ② 기다리는 가족: WithME 가족 홈 `타기 전 픽업` → `내 현재 위치 확인` → 내 이름, 가게·상가와 출입구(예: 카페 앞) 입력 → `이 위치에서 기다린다고 보내기` ③ 주행 중 운전자: `음성 명령` → `말하기` → "동승자 픽업해서 가자" | 차량에 `동승자 요청이 도착했어요` → 최종 목적지는 그대로 경유지 추가. 기다리는 가족 지도에 다가오는 차량 표시. 탑승 후 내 차 앱 `탑승 완료` |
| 장소 제안 + 음성 경유 | WithME 가족 `요청` 탭 `목적지·경유지 제안` → 검색 → 결과 선택 → `경유지` → `차량에 장소 제안` → 주행 중 운전자: "가족이 보내준 데 잠깐 찍고 가자" | 경유지 추가, 최종 목적지 유지 |
| 음성 목적지 | 운전자: `음성 명령` → `말하기` → "강남역으로 안내해 줘" | 후보가 여럿이면 번호를 읽어 줌 → "두 번째" |
| 가족 이동 기준 경로 | WithME 가족 홈 `가족 경로 기준` → 기준 체크(예: 방향 전환 적게) → `차량의 경로 비교에 전달` | ‘목적지·경유지 변경’ 권한이 있으면 몇 초 뒤 경로가 바뀌고 음성 안내, 안내 패널에 `가족 기준(…) · +0.4 km / +3분 (예상)`. 이미 맞으면 `지금 경로 유지` |
| 상황별 케어 + 지정 휴게소 | WithME 가족 홈 `상황별 케어` → `아이가 잠들었어요` → `일반 가족 요청을 받을 보호자` 선택 → `쉬어 갈 휴게소 지정`에 자동으로 뜨는 남은 경로의 휴게소 중 선택(차량 안내 중일 때) → `이 설정으로 케어 시작` → 주행 중이면 운전자가 "가족이 보내준 데 잠깐 찍고 가자" | 차량 안내 카드 `아이가 잠들었어요 · 지정 휴게소 도착까지 N분`, `일반 요청 → 보호자` |
| 보호자에게 먼저 전달 | 케어 중 다른 가족 휴대폰 홈 `음악 줄이기` | 차량에는 팝업이 뜨지 않고, 보호자 휴대폰 위쪽 `보호자에게 도착한 가족 요청` 카드 → `내가 확인했어요` (30초 안에 확인하지 않으면 운전자에게) |
| 반려동물 케어 | WithME 가족 `반려동물` 탭 → 온도·배터리·문 상태 확인 → P단 정차 중 `직접 확인 타이머`에서 시간 선택 → `확인 타이머 시작` | 남은 시간과 상태, 데이터가 오래되면 `미확인` |
| 추억 사진 | WithME 가족 홈 `사진 한 장, 오늘의 추억` → `추억 사진 선택` → `사진 선택` → 제목·장소 확인(위치가 있는 사진이면 주소·근처 장소·제목이 자동으로 채워짐, 촬영 시간 입력 없음) → `이 사진을 가족 지도에 공유` | P단 정차 중이면(길안내 중이어도) 차량 지도의 촬영 위치에 제목이 붙은 큰 사진 카드. 카드를 누르면 원본 사진을 크게 보고 `다음 ›`으로 넘김. 주행 중이거나 P단이 아니면 작은 동그란 사진으로만 표시 |
| 도착 알림 | 휴대폰 `연결됨` → `알림·보호자 설정` → 백그라운드 알림 켜기 → 차량이 목적지 도착 | 차에 타지 않은 가족 휴대폰에도 도착 알림 |

음성 명령 예시 문장은 [docs/usage/53_자연어음성경유_0.20.5.txt](docs/usage/53_자연어음성경유_0.20.5.txt)에 더 있습니다.

### 2-9. 끄기

**`03_StopAll.cmd`** (또는 바탕화면 `WithME 시연 끄기`)를 실행합니다. 시연 보조, 차량 에뮬레이터, 연결 서버를 차례로 끕니다. 에뮬레이터 창을 직접 닫지 마세요.

### 제출 APK만 설치해서 확인할 때

```bat
05_DeveloperMenu.cmd  → 2 (Pleos 에뮬레이터 시작)
adb install apk\모두빌리티_WithME_release.apk
05_DeveloperMenu.cmd  → 6 (휴대폰 Wi-Fi 서버, 창 유지)
```

`adb`는 `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`에 있습니다. 에뮬레이터에서 `WithME`을 실행합니다. 지도와 동승자 연결 QR은 연결 서버(위 6번)가 켜져 있어야 동작합니다. QR 연결부터는 2-5와 같습니다.

`02_StartDemo.cmd`는 개발용 서명의 같은 앱을 설치하므로, release 앱이 깔린 상태에서는 설치가 거절됩니다. 02로 돌아가기 전에 `adb uninstall com.familycare.navigation`으로 release 앱을 지우세요.

### 자주 막히는 곳

| 증상 | 해결 |
| --- | --- |
| 휴대폰에서 QR 주소가 안 열림 | 같은 Wi-Fi인지, Wi-Fi가 '개인 네트워크'인지, 방화벽 창에서 허용했는지 확인. 주소가 `127.0.0.1`이면 네트워크를 다시 고르거나 외부 연결 사용 |
| `ERROR: Could not choose the phone network automatically` | `05_DeveloperMenu.cmd` → 2 → 창 닫기 → 다시 05 → 6 → 휴대폰과 같은 Wi-Fi 번호 선택(창 유지) → `02_StartDemo.cmd` |
| 지도가 회색이거나 검색이 안 됨 | `tmap.local.json` 키 확인: `py -3.12 scripts\check_tmap.py --live` |
| 권한 승인 버튼이 안 눌림 | 차량이 주행 중입니다. 보조 화면 `P단 정차 / 안내 일시정지` 후 승인 |
| 음성 명령이 안 들림 | 에뮬레이터 Microphone 설정(부팅마다), Windows 마이크 권한 확인 |
| 2시간 뒤 연결 끊김 | 보조 화면 `차량 연결 복구` → 휴대폰은 새 QR로 연결 |
| 앱 설치 시 `기존 패키지와 충돌` | 다른 PC에서 만든 앱을 지우고 이 PC의 APK로 설치 |

나머지 오류 문장은 RUN-GUIDE 14장 표에서 찾을 수 있습니다.

### 구현 범위와 한계

기능별 구현·계획 구분은 [docs/FEATURE-STATUS.md](docs/FEATURE-STATUS.md)에 있습니다.

- Pleos 에뮬레이터와 노트북 연결 서버로 시연합니다. 실차 주행은 검증하지 않았습니다.
- 현대/기아 공식 앱, 차량 소유권 인증, Bluelink 원격 시동과는 연결하지 않았습니다. 차량 조작은 Vehicle SDK가 지원하는 항목에 한정됩니다.
- 휴대폰과 노트북의 같은 Wi-Fi 연결은 시연용 http입니다. 휴대폰 release 빌드는 https 외부 연결만 허용합니다.
- 경유지는 한 번에 한 곳까지 지원합니다. 음성 명령은 버튼을 누른 뒤에만 듣고, 범용 대화형 AI가 아닙니다.
- 방향 전환 수는 조회한 경로 후보끼리의 비교이며 멀미 예방 효과를 뜻하지 않습니다. 휴게소의 실제 시설·영업 여부는 직접 확인해야 합니다.
- 아이·반려동물을 차에 혼자 두어도 안전하다는 보장을 하지 않습니다. 차량 전원·앱·서버가 멈추면 확인도 멈춥니다.
- 외부 IP 카메라와 태블릿은 선택 기능이며, 심사 현장에서 쓰려면 주최 측 확인이 필요합니다.

### 개인정보·보안

- API 키는 저장소와 APK에 넣지 않습니다. 노트북의 `tmap.local.json`에만 두고, 승인된 연결에만 실행 중 전달합니다.
- 연결 서버는 연결 상태를 메모리에만 둡니다. 연결 링크는 시간이 지나면 만료되고, 서버를 다시 켜면 새 QR이 필요합니다.
- 소유자 QR에는 차량 관리 권한이 있으니 차주에게만 보여 줍니다.
- 휴대폰 앱은 연결 정보를 Android Keystore로 암호화해 보관합니다.
- 음성 문장은 외부 AI 서버로 보내지 않고, 노트북에서 메모리로만 처리합니다.
- 공유된 추억 사진은 내 차·WithME 가족 앱이 각 휴대폰의 앱 전용 저장소에 최근 30장까지 보관하고, 다시 연결된 차량에만 다시 공유합니다. 추억 탭의 '이 휴대폰에 보관' 스위치를 끄면 보관한 사진을 지웁니다.
- 추억 사진의 촬영 위치로 주소와 장소 이름을 찾을 때는 그 좌표만 노트북 서버를 거쳐 TMAP에 보내고, 응답은 저장하지 않습니다. 사진을 고르기 전에 안내합니다.
