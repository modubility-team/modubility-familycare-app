1. 지도에서 현재 위치와 목적지 선택

시연 연결은 최대 2시간입니다. 복구하면 이동을 다시 준비하며, 휴대폰은 새 QR로 연결하세요. 입력한 검색어와 선택한 지도 위치는 유지됩니다.

검색을 누르면 검색어와 지도 중심 위치를 TMAP에 보냅니다. 지도 클릭만으로도 장소를 지정할 수 있어요.

파랑: 차량 GPS · 초록: 선택한 현재 위치 · 주황: 선택한 목적지

현재 위치: 지도에서 선택하세요.

목적지: 지도에서 선택하세요.

현재 위치 적용 시 P단 정차 → 기존 경로 해제 → 차량 GPS 수신을 확인합니다. 길찾기는 국내 TMAP 자동차 도로 지원 범위에서 제공됩니다. 바다·출입 불가 지점·해외 등 경로를 구할 수 없는 곳은 오류를 표시합니다.

PC 위치 선택 지도: OpenStreetMap · 앱 지도, 검색, 길찾기: TMAP.

2. 차량 앱의 경로로 GPS 재생

차량이나 휴대폰에서 제안한 목적지를 운전자가 승인해도 같은 경로로 재생됩니다. 화면을 닫거나 차량 연결이 끊기면 정차합니다. 실제 차량 자동운전 기능은 아닙니다.

태블릿용 앱 다운로드

탭 연결 상태 확인 중

앱 설치 → 연결 → ‘탭 GPS 시작’ → 정확한 위치 허용. 실내 자동 주행으로 돌아올 때는 ‘GPS 중지’를 누르세요.

차량 화면과 터치는 탭에서, 음성 입력·출력은 노트북에서 동작합니다. GPS는 탭 앱이 열린 동안에만 전달합니다. 연결 링크는 화면 조작 권한을 포함하니 시연자에게만 보여 주세요.

카메라 연결 · IP 주소 변경

여분의 안드로이드폰에서 IP Webcam 실행 → 같은 Wi-Fi → 서버 시작. 표시된 주소를 입력하세요.

설정된 카메라 주소: 없음

IP가 바뀌면 이 칸만 수정하세요. http://는 생략해도 됩니다.

연결하면 소유자·가족 앱에서 화면을 볼 수 있어요. 카메라 앱의 클라우드 기능은 끄세요. 우리 서버는 영상을 저장하지 않으며 같은 Wi-Fi의 HTTP로 전달합니다.

주소를 입력하고 연결하면 바로 화면을 확인합니다.

1초 간격 화면 확인입니다. 반려동물의 건강·안전을 자동 판정하지 않습니다. 외부 장치의 심사 현장 사용은 주최 측 확인이 필요합니다.

앱에서 확인하는 순서

  1. 내 차 → 가족에서 동승자 구성을 설정합니다.
  2. WithME 가족 → 요청에서 온도·장소를 제안합니다. 차량에서 정차 후 승인합니다.
  3. GPS 주행 중 휴식 요청 → 차량의 작은 알림과 음성을 확인합니다.
  4. WithME 가족 → 반려동물에서 타이머와 카메라를 확인합니다.
  5. 추억 → 실제 사진 선택 → 공유합니다.
  6. 정차 → 이동 종료 → 뒷좌석 확인과 이동 기록을 봅니다.
